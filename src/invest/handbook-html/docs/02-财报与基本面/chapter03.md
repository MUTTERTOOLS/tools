### 第 3 章 资产负债表

> **本章一句话**：读懂企业的家底结构，识别资产水分与负债风险。
> **学习目标**：
> 1. 能说出货币资金、应收账款、存货、商誉的正常与异常特征
> 2. 区分经营性负债与金融性负债
> 3. 掌握识别资产负债表"水分"的五种方法

#### 3.1 资产端重点科目：货币资金、应收账款、存货

**货币资金**：
- 包括：库存现金、银行存款、其他货币资金
- **正常特征**：与经营规模匹配，有合理利息收入
- **异常信号**：
  - 货币资金很多但利息收入极低 → 可能资金被占用或虚构（存贷双高）
  - 货币资金多但同时大举借债 → 不合逻辑（除非有特定用途限制）

**应收账款**：
- 定义：卖了货但还没收到的钱
- **正常特征**：增速与营收增速基本同步
- **异常信号**：
  - 应收增速 > 营收增速×1.5 → 客户付款变慢或提前压货
  - 应收账款周转天数 > 90 天 → 回款慢，坏账风险上升
  - 账龄结构中 1 年以上占比提升 → 回收难度加大

**存货**：
- 定义：还没卖出去的货（原材料、在产品、产成品）
- **正常特征**：与营收规模匹配，周转稳定
- **异常信号**：
  - 存货增速 > 营收增速 → 可能滞销或备货过度
  - 存货周转天数 > 90 天（制造业） → 周转慢，跌价风险
  - 产成品占比突然提升 → 销售不畅

#### 3.2 资产端重点科目：固定资产、在建工程、无形资产、商誉

**固定资产**：
- 定义：厂房、设备等长期使用的资产
- **关注点**：折旧政策（年限越长，当期利润越高）、产能利用率

**在建工程**：
- 定义：正在建设、尚未转固的资产
- **异常信号**：连续 3 年不转固 → 可能推迟转固以少提折旧、虚增利润（一票否决项）

**无形资产**：
- 定义：专利、商标、土地使用权等
- **关注点**：摊销政策、是否存在减值风险

**商誉**：
- 定义：收购时支付的对价超过被收购方可辨认净资产公允价值的部分
- **风险**：商誉减值会直接冲减利润
- **警戒线**：商誉/净资产 > 30% → 高风险
- **规则**：每年必须做减值测试，但不需要摊销（容易藏雷）

#### 3.3 负债端：经营性负债 vs 金融性负债

**经营性负债**（通常无息）：
- 应付账款：欠供应商的货款
- 预收账款/合同负债：客户提前付的钱（越多越好，说明产品紧俏）
- 应付职工薪酬：欠员工的工资

**金融性负债**（通常有息）：
- 短期借款：1 年内要还的银行贷款
- 长期借款：1 年后到期的银行贷款
- 应付债券：发行的债券

**关键洞察**：
- 经营性负债占比高 → 对上下游议价能力强（占用别人资金）
- 金融性负债占比高 → 利息压力大，抗风险能力弱

#### 3.4 所有者权益：实收资本、资本公积、未分配利润

**实收资本**：股东实际投入的本金
**资本公积**：股本溢价等（如 IPO 时发行价高于面值的部分）
**未分配利润**：历年累积的、还没分给股东的利润

**重要关系**：
```
净资产 = 所有者权益 = 实收资本 + 资本公积 + 盈余公积 + 未分配利润 + 其他
```

**ROE（净资产收益率）** = 净利润 ÷ 净资产，衡量股东投入资本的回报率。

#### 3.5 合并报表 vs 母公司报表

**合并报表**：把上市公司及其控股子公司的财务数据合并在一起（抵消内部交易）
**母公司报表**：仅上市公司本部的财务数据

**阅读规则**：
- **主要看合并报表**：反映整个集团的经营状况
- 母公司报表辅助看：了解本部情况，特别是分红能力（分红来自母公司可供分配利润）

#### 3.6 资产负债表"水分"识别五法

1. **应收账款水分**：账龄长、集中度低、与营收背离
2. **存货水分**：周转慢、库龄长、跌价准备不足
3. **固定资产水分**：折旧年限过长、产能利用率低、在建工程长期不转固
4. **商誉水分**：收购溢价过高、被收购方业绩不达预期
5. **货币资金水分**：存贷双高、利息收入异常低、受限资金未披露

**例 3-1｜康美药业存贷双高**：
- 2018 年三季报：货币资金 342 亿，短期借款 257 亿
- 质疑：既然有 342 亿现金，为什么要借 257 亿付利息？
- 后续：2019 年承认货币资金虚增 299 亿

**要点小结**
- 货币资金异常：存贷双高、利息收入低
- 应收账款异常：增速远超营收、周转天数>90 天
- 存货异常：增速超营收、周转慢、产成品占比提升
- 商誉/净资产>30% 为高风险
- 在建工程连续 3 年不转固是一票否决项
- 主要看合并报表

**行动判据（If-Then）**
- 如果商誉/净资产 > 30% → 那么直接排除，不浪费时间
- 如果在建工程连续 3 年不转固 → 那么一票否决
- 如果应收增速 > 营收增速×1.5 → 那么查附注看账龄和客户集中度

**本章练习**
1. 选一家制造业公司，计算其应收账款周转天数和存货周转天数，与同行业对比。
2. 找一家有高商誉的公司，查看其历年商誉减值情况，计算商誉/净资产比例。
3. 对比某公司的合并报表和母公司报表，找出差异最大的三个科目并分析原因。
