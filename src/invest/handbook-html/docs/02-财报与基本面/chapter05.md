### 第 5 章 现金流量表

> **本章一句话**：现金为王，读懂企业的造血能力和资金链安全。
> **学习目标**：
> 1. 能解释为什么现金流量表最难造假
> 2. 掌握六种现金流模式的含义
> 3. 理解自由现金流的概念和计算方法

#### 5.1 为什么现金流量表最难造假

**原因**：
1. 现金进出银行有第三方记录，难以伪造
2. 现金流量表与资产负债表、利润表存在勾稽关系，容易交叉验证
3. 操纵现金流成本高（需要真实资金流转）

**注意**：虽然最难造假，但不是完全不能造假。常见手法包括：
- 期末临时借钱充实现金流，期初再还回去
- 将投资活动现金流出包装成经营活动
- 通过关联方交易虚构现金流

#### 5.2 经营活动现金流

**定义**：企业日常经营活动产生的现金流入和流出

**计算公式（间接法）**：
```
经营现金流净额 = 净利润 + 折旧摊销 + 营运资本变动 + 其他调整
```

**关键指标**：
- **净现比** = 经营现金流净额 ÷ 净利润
  - >1.2：优秀（利润含金量高）
  - 0.8-1.2：健康
  - 0.5-0.8：关注
  - <0.5：危险（利润可能虚构）

- **收现比** = 销售商品提供劳务收到的现金 ÷ 营业收入
  - >1.1：良好（部分预收款）
  - 1.0 左右：正常
  - <1：应收增加，回款变慢

#### 5.3 投资活动现金流

**定义**：企业购建或处置长期资产、对外投资产生的现金流

**典型模式**：
- **扩张期**：投资现金流为负（花钱建厂、买设备、并购）
- **成熟期**：投资现金流接近零或小幅为正（维持性资本开支）
- **收缩期**：投资现金流为正（变卖资产）

**关注点**：
- 资本开支（CAPEX） = 购建固定资产等支付的现金
- **自由现金流** = 经营现金流 - 资本开支（见 5.5 节）

#### 5.4 筹资活动现金流

**定义**：企业借款、还款、增发、回购、分红产生的现金流

**典型模式**：
- **融资期**：筹资现金流为正（借钱或增发）
- **还债期**：筹资现金流为负（还债或分红）

**关注点**：
- 如果经营现金流为负、投资现金流为负、筹资现金流为正 → 靠输血维持，危险
- 如果经营现金流为正、筹资现金流为负 → 自我造血并回馈股东，健康

#### 5.5 自由现金流（FCF）

**定义**：企业经营产生的、扣除维持和发展业务所需资本开支后、可自由分配给股东的现金。

**计算公式**：
```
自由现金流 = 经营活动现金流净额 - 资本开支
```

**意义**：
- 自由现金流是企业真实可支配的现金
- 可用于分红、回购、还债、再投资
- 巴菲特最看重的指标之一："一家公司的价值等于其未来自由现金流的折现"

**例 5-1｜自由现金流计算**：
某公司 2023 年数据：
- 经营现金流净额：10 亿
- 购建固定资产支付现金：3 亿
- 自由现金流 = 10 - 3 = 7 亿

这 7 亿可以用于：
- 分红 3 亿
- 回购股票 2 亿
- 还债 1 亿
- 留存 1 亿用于未来投资

#### 5.6 六种现金流模式

**三种健康模式**：
1. **+, -, -**（奶牛型）：经营造血、投资扩张、适度还债 → 最理想
2. **+, +, -**（收缩型）：经营造血、变卖资产、还债分红 → 成熟期或转型期
3. **+, -, +**（激进扩张型）：经营造血、大幅投资、同时融资 → 高速成长期，需监控资金链

**三种危险模式**：
1. **-, -, +**（输血型）：经营失血、投资扩张、靠融资续命 → 烧钱模式，危险
2. **-, -, -**（全面失血型）：经营失血、投资扩张、还在还债 → 资金链随时断裂
3. **-, +, -**（败家型）：经营失血、变卖资产、还债 → 坐吃山空

**例 5-2｜乐视网的现金流模式**：
2015-2016 年乐视模式：-, -, +
- 经营现金流：负（生态化反没赚到钱）
- 投资现金流：负（疯狂投资造车、体育、手机）
- 筹资现金流：正（不断借钱、增发）

结局：2017 年资金链断裂，退市。

**要点小结**
- 现金流量表最难造假，因为有银行流水验证
- 净现比>1.2 优秀，<0.5 危险
- 收现比>1.1 良好，<1 应收增加
- 自由现金流=经营现金流 - 资本开支，是巴菲特最看重的指标
- 六种模式中"+,-,-"最理想，"-,-,+"最危险
- 乐视网是典型的输血型模式最终崩盘

**行动判据（If-Then）**
- 如果净现比<0.5 → 那么深入查利润质量和应收存货
- 如果连续三年自由现金流为负 → 那么评估其扩张是否能产生回报
- 如果模式是"-,-,+"且融资渠道收窄 → 那么直接排除，避免踩雷

**本章练习**
1. 选一家公司，计算其近 5 年的净现比和自由现金流，画出趋势图。
2. 找出三种健康模式和三种危险模式的代表公司各一家，对比其股价长期表现。
3. 用自由现金流模型估算一家公司的内在价值（假设永续增长率 3%，折现率 10%）。
