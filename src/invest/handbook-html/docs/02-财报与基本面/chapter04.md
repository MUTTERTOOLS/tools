### 第 4 章 利润表

> **本章一句话**：层层剥开利润的外衣，识别真实盈利能力。
> **学习目标**：
> 1. 能复述从营收到净利润的完整计算链条
> 2. 理解毛利、营业利润、净利润的本质区别
> 3. 掌握扣非净利润的意义和使用场景

#### 4.1 从营收到净利润：利润的层层剥壳

**完整链条**：
```
营业收入
- 营业成本
= 毛利润
- 税金及附加
- 销售费用
- 管理费用
- 研发费用
- 财务费用
+ 其他收益
+ 投资收益
+ 公允价值变动收益
= 营业利润
+ 营业外收入
- 营业外支出
= 利润总额
- 所得税
= 净利润
- 少数股东损益
= 归母净利润
```

**关键洞察**：每一层都可能藏猫腻，必须逐层分析。

#### 4.2 营业收入：确认时点与口径

**收入确认原则**：控制权转移时确认（新收入准则）

**常见操纵手法**：
- 提前确认收入：货还没发出就确认
- 延后确认收入：货已发出但不确认（平滑利润）
- 虚构收入：伪造合同、发货单、发票

**验证方法**：
- 收入增速 vs 经营现金流增速：应该大致同步
- 收入增速 vs 应收账款增速：应收不应远超收入
- 收入增速 vs 同行业：偏离过大需解释

#### 4.3 营业成本与毛利

**毛利率** = （营业收入 - 营业成本）÷ 营业收入

**意义**：
- 反映产品竞争力和定价权
- 毛利率高且稳定 = 护城河深
- 毛利率突然提升：可能是产品结构优化，也可能是成本资本化

**异常信号**：
- 毛利率远高于同行且无合理解释 → 可能虚构收入或低估成本
- 毛利率波动大 → 定价权弱或成本传导不畅

#### 4.4 三费：销售费用、管理费用、研发费用

**销售费用**：广告费、销售人员工资、运输费等
- 销售费用率 = 销售费用 ÷ 营收
- 高销售费用率：可能是品牌驱动型（如白酒），也可能是获客困难

**管理费用**：管理人员工资、办公费、折旧等
- 管理费用率 = 管理费用 ÷ 营收
- 趋势应稳中有降（规模效应）

**研发费用**：研发投入
- 研发费用率 = 研发费用 ÷ 营收
- 科技企业通常>10%，传统企业 3-5%
- **注意**：研发费用可以资本化（计入资产）或费用化（计入当期费用），资本化会提升当期利润但增加未来摊销压力

**财务费用**：利息支出 - 利息收入 + 汇兑损益
- 财务费用率为正 → 利息支出大于收入（正常）
- 财务费用率为负 → 利息收入大于支出（现金充裕）

#### 4.5 营业利润 vs 利润总额 vs 净利润

**营业利润**：主业经营赚的钱（最核心）
**利润总额**：营业利润 + 营业外收支（含政府补助、资产处置等一次性收益）
**净利润**：利润总额 - 所得税

**关键规则**：分析盈利能力时，优先看营业利润，因为它反映主业的持续性。

#### 4.6 扣非净利润与 EPS

**扣非净利润**：扣除非经常性损益后的净利润

**非经常性损益包括**：
- 政府补助
- 资产处置收益
- 投资收益（非主业）
- 公允价值变动收益
- 其他一次性收益或损失

**意义**：扣非净利润反映主业的真实盈利能力，排除了一次性因素干扰。

**EPS（每股收益）** = 归母净利润 ÷ 总股本

**用途**：计算市盈率（PE = 股价 ÷ EPS）

**例 4-1｜扣非的重要性**：
某公司 2023 年数据：
- 净利润：5 亿
- 扣非净利润：2 亿
- 差额 3 亿来自：出售子公司股权收益 2.5 亿 + 政府补助 0.5 亿

**分析**：主业只赚了 2 亿，3 亿是一次性收益，不可持续。如果用 5 亿净利润给估值，会高估。

**要点小结**
- 利润表是层层剥壳的过程，从营收到归母净利润共 7 层
- 毛利率反映产品竞争力，应稳定且与同行可比
- 三费中研发费用资本化需警惕
- 营业利润比净利润更能反映主业盈利能力
- 扣非净利润排除一次性因素，是估值的核心依据
- EPS 用于计算 PE，但要用扣非 EPS 更准确

**行动判据（If-Then）**
- 如果净利润 >> 扣非净利润 → 那么利润主要来自一次性收益，估值要打折扣
- 如果毛利率远高于同行且无合理解释 → 那么深入查收入确认和成本核算
- 如果研发费用大量资本化 → 那么调整为全部费用化重新计算利润

**本章练习**
1. 选一家公司，计算其近 5 年的毛利率、净利率、扣非净利润占比，画出趋势图。
2. 找一家净利润和扣非净利润差异巨大的公司，分析差异来源。
3. 对比两家同行业公司的三费结构，思考为什么有差异。
