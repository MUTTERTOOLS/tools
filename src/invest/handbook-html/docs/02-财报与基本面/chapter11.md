### 第 11 章 成长能力与趋势

> **本章一句话**：方向比位置重要，成长的质量比速度更重要。
> **学习目标**：
> 1. 理解三种增长类型（内生、外延、财务技巧）
> 2. 掌握基数效应和增速交叉验证方法
> 3. 建立"方向比位置重要"的分析框架

#### 11.1 营收增长率

**公式**：营收增长率 = （本期营收 - 上期营收）÷ 上期营收 × 100%

**意义**：
- 反映公司业务扩张速度
- 持续高增长 = 市场需求旺盛或份额提升
- 负增长 = 市场萎缩或竞争力下降

**标准**：
- >30%：高速成长（通常是小公司或新业务）
- 15-30%：中速成长
- 5-15%：稳健增长（成熟公司正常水平）
- <5%：低速增长或停滞
- <0%：萎缩

**注意**：增长率必须结合基数看。10 亿基数增长 30% 比 100 亿基数增长 10% 更难。

#### 11.2 净利润增速

**公式**：净利润增速 = （本期净利润 - 上期净利润）÷ 上期净利润 × 100%

**与营收增速的关系**：
- 净利润增速 > 营收增速 → 净利率提升（规模效应或成本下降）
- 净利润增速 < 营收增速 → 净利率下降（竞争加剧或成本上升）
- 两者背离过大需警惕（可能有一次性因素）

**关键洞察**：短期看营收，长期看利润。没有利润增长的营收增长不可持续。

#### 11.3 经营现金流增速

**公式**：经营现金流增速 = （本期经营现金流 - 上期经营现金流）÷ 上期经营现金流 × 100%

**为什么重要**：
- 检验利润增长的质量
- 经营现金流增速应大致同步于净利润增速
- 长期背离预示风险

**三者关系**：
- 理想状态：营收增速 ≈ 净利润增速 ≈ 经营现金流增速
- 危险信号：营收和利润增长，但经营现金流负增长

#### 11.4 增长的三种类型

**类型 1：内生增长（最优质）**
- 驱动因素：产品销量增加、单价提升、市场份额扩大
- 特征：营收、利润、现金流同步增长
- 可持续性：强
- 代表：贵州茅台（量价齐升）、海天味业（渠道下沉）

**类型 2：外延增长（并购驱动）**
- 驱动因素：收购兼并并表
- 特征：营收突然跳增，但商誉增加、整合风险
- 可持续性：取决于并购质量
- 风险：商誉减值、文化冲突、协同效应不达预期

**类型 3：财务技巧增长（最危险）**
- 驱动因素：会计变更、一次性收益、放宽信用政策
- 特征：利润增长但现金流恶化
- 可持续性：无
- 风险：迟早回归真实水平，甚至反噬

**例 11-1｜三种增长对比**：
- 公司 A（内生）：营收 +20%，净利 +25%，经营现金流 +22% → 优质增长
- 公司 B（外延）：营收 +50%（并购），净利 +30%，商誉 +10 亿 → 需观察整合效果
- 公司 C（技巧）：营收 +15%，净利 +40%，经营现金流 -10% → 危险信号

#### 11.5 基数效应

**定义**：增长率受前期基数影响，基数越低越容易实现高增长。

**例子**：
- 第 1 年：净利润 100 万
- 第 2 年：净利润 500 万 → 增速 400%（看起来惊人）
- 第 3 年：净利润 800 万 → 增速 60%（依然很高）
- 第 4 年：净利润 1000 万 → 增速 25%（开始放缓）
- 第 5 年：净利润 1100 万 → 增速 10%（回归常态）

**关键洞察**：
- 小公司容易实现高增速，但难以持续
- 大公司增速放缓是自然规律
- 不要简单线性外推高增速

#### 11.6 增速交叉验证

**原则**：单一指标的增长不可信，需要多个指标交叉验证。

**验证矩阵**：

| 指标组合 | 含义 | 判断 |
|---------|------|------|
| 营收 +、利润 +、现金流 + | 全面健康增长 | 可信 |
| 营收 +、利润 +、现金流 - | 增长质量存疑 | 查应收存货 |
| 营收 +、利润 - | 增收不增利 | 查毛利率和费用率 |
| 营收 -、利润 + | 收缩中盈利 | 可能是一次性收益或裁员降本 |
| 三者皆 - | 全面衰退 | 规避 |

**例 11-2｜某公司增速分析**：
2020-2023 年数据：
- 营收增速：+25%、+18%、+10%、+5%（持续放缓）
- 利润增速：+30%、+15%、+8%、+12%（波动）
- 现金流增速：+20%、-5%、-15%、-20%（持续恶化）

分析：
- 营收增速持续放缓 → 成长见顶
- 利润增速波动 → 可能有非经常性因素
- 现金流持续恶化 → 增长质量差，可能是应收堆积

结论：该公司处于成长末期，需谨慎。

#### 11.7 方向比位置重要

**核心原则**：趋势方向比当前绝对值更重要。

**为什么**：
1. 股市是预期的游戏，趋势决定未来
2. 当前位置低但趋势向上 > 当前位置高但趋势向下
3. 拐点是最有价值的信号

**要点小结**
- 营收、利润、现金流增速应同步，背离需警惕
- 增长分三类：内生（最优）、外延（中性）、财务技巧（危险）
- 基数效应导致小公司容易高增长但难持续
- 用增速交叉验证矩阵判断增长质量
- 趋势方向比当前绝对值更重要
- 拐点是最有价值的信号

**行动判据（If-Then）**
- 如果营收和利润增长但现金流负增长 → 那么深入查应收和存货
- 如果增速连续 3 个季度放缓 → 那么重新评估成长逻辑是否还在
- 如果 ROE 趋势向下即使绝对值仍高 → 那么谨慎，可能基本面在恶化

**本章练习**
1. 选一家成长股，计算其近 5 年营收、利润、现金流增速，判断属于哪种增长类型。
2. 找一家增速拐点公司，分析拐点出现的原因和后续股价表现。
3. 对比两家同行业公司，一家高位下滑、一家低位上升，思考哪家的估值应该更高。
