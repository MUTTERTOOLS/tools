### 第 7 章 杜邦分析

> **本章一句话**：用杜邦分析法拆解 ROE，识别盈利的真正驱动力。
> **学习目标**：
> 1. 能默写杜邦分析的三因子公式
> 2. 理解三种 ROE 驱动模式的优劣
> 3. 掌握 ROE 提升的"真假"判断方法

#### 7.1 为什么 ROE 是最重要的财务指标

**ROE（Return on Equity，净资产收益率）** = 净利润 ÷ 净资产

**意义**：
- 衡量股东投入资本的回报率
- 巴菲特："如果只能用一个指标选股，我会选 ROE"
- 长期来看，股价涨幅≈ROE（假设估值不变）

**标准**：
- ROE > 15% 连续多年 = 好公司基准
- ROE < 10% = 回报偏低（除非周期性底部）
- ROE > 30% 且不可持续 = 警惕（可能高杠杆或一次性收益）

#### 7.2 杜邦分解：ROE 的三个引擎

**三因子杜邦公式**：
```
ROE = 净利率 × 总资产周转率 × 权益乘数
```

其中：
- **净利率** = 净利润 ÷ 营业收入（盈利能力）
- **总资产周转率** = 营业收入 ÷ 总资产（运营效率）
- **权益乘数** = 总资产 ÷ 净资产（财务杠杆）

**理解**：ROE 可以由三种方式驱动：
1. 卖得贵（高净利率）
2. 卖得快（高周转）
3. 借得多（高杠杆）

#### 7.3 三个引擎详解

**引擎 1：净利率（盈利能力）**
- 驱动因素：产品定价权、成本控制、规模效应
- 代表行业：高端白酒（茅台净利率~50%）、软件 SaaS
- 特点：最可持续的 ROE 驱动方式

**引擎 2：总资产周转率（运营效率）**
- 驱动因素：供应链管理、库存周转、资产利用率
- 代表行业：零售（沃尔玛周转率~2.5）、制造业
- 特点：需要精细化管理，较可持续

**引擎 3：权益乘数（财务杠杆）**
- 驱动因素：借钱经营、放大收益
- 代表行业：银行（权益乘数~10）、房地产
- 特点：风险最高，经济下行时反向放大亏损

#### 7.4 三种 ROE 驱动模式

**模式 1：高净利率驱动（最优）**
- 特征：净利率>20%，周转率中等，杠杆低
- 代表：贵州茅台、片仔癀、海天味业
- 优势：盈利质量高，抗风险能力强
- 风险：护城河被侵蚀（如竞争加剧、替代品出现）

**模式 2：高周转驱动（次优）**
- 特征：净利率低（3-5%），周转率高（>2），杠杆中等
- 代表：沃尔玛、Costco、京东方
- 优势：规模效应强，市场份额稳固
- 风险：需求下滑导致周转放缓、价格战压缩利润

**模式 3：高杠杆驱动（高危）**
- 特征：净利率中等，周转率中等，权益乘数高（>5）
- 代表：银行、房地产、保险公司
- 优势：ROE 看似很高
- 风险：经济下行时不良率上升、资产减值、杠杆反向放大亏损

#### 7.5 不同行业 ROE 结构差异

**消费行业**：高净利率 + 中周转 + 低杠杆
**制造业**：中净利率 + 中高周转 + 中杠杆
**零售业**：低净利率 + 高周转 + 中杠杆
**金融业**：中高净利率 + 低周转 + 高杠杆
**互联网**：早期低净利率 + 中周转 + 低杠杆（追求规模），成熟期高净利率

**关键洞察**：跨行业比较 ROE 绝对值没有意义，必须拆解结构。

#### 7.6 ROE 提升的"真假"

**真提升**：
- 净利率提升：产品涨价、成本下降、规模效应
- 周转率提升：库存管理优化、资产利用率提高
- 适度加杠杆：在安全范围内提升权益乘数

**假提升**：
- 一次性收益推高净利率（如卖资产）
- 减少必要资本开支短期提升周转率（损害长期竞争力）
- 过度加杠杆超出安全边界

**验证方法**：
- 看扣非净利润：排除一次性收益
- 看资本开支：是否牺牲长期投入
- 看资产负债率：是否超过安全线

#### 7.7 杜邦分析的局限

1. **不反映现金流**：ROE 高但自由现金流可能为负
2. **不反映成长性**：ROE 高但可能已见顶
3. **不反映风险**：高杠杆推高的 ROE 隐含巨大风险
4. **周期性强**：周期股 ROE 波动大，不能用单一时点判断

**补充工具**：
- 结合 ROIC（投入资本回报率）：剔除杠杆影响，更纯粹反映经营效率
- 结合自由现金流：验证盈利质量
- 结合行业生命周期：判断 ROE 可持续性

**例 7-1｜某房企 ROE 拆解**：
某房企 2020 年 ROE=25%，拆解：
- 净利率 = 10%
- 周转率 = 0.3
- 权益乘数 = 8.3

分析：
- ROE 主要靠高杠杆（8.3 倍）驱动
- 净利率和周转率都一般
- 风险：一旦销售下滑或融资收紧，高杠杆会反向放大亏损

结局：2021-2022 年房地产行业调控，该公司资金链断裂。

**要点小结**
- ROE=净利率×周转率×权益乘数，三个引擎
- ROE>15% 连续多年是好公司基准
- 高净利率驱动最优，高周转次之，高杠杆最危险
- 跨行业比 ROE 绝对值无意义，必须拆解结构
- ROE 提升要看是否可持续，排除一次性因素
- 杜邦分析不反映现金流和成长性，需结合其他指标

**行动判据（If-Then）**
- 如果 ROE>20% 但主要来自高杠杆 → 那么深入查负债结构和融资环境
- 如果 ROE 提升但扣非净利润没增 → 那么可能是一次性收益，不可持续
- 如果 ROIC<WACC → 那么即使 ROE 高也在毁灭价值

**本章练习**
1. 选三家不同行业的公司，分别拆解其 ROE 的三个因子，对比驱动模式。
2. 找一家 ROE 连续 5 年>20% 的公司，分析其驱动因素是否可持续。
3. 计算某公司的 ROIC 和 WACC，判断其是否在创造价值。
