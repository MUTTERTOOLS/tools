### 第 12 章 商业模式与护城河

> **本章一句话**：从财报数字回到生意本质，理解公司靠什么赚钱以及能否持续。
> **学习目标**：
> 1. 掌握六种经典商业模式及其财务特征
> 2. 理解巴菲特五种护城河的内涵和识别方法
> 3. 能从财报反推公司的商业模式和护城河

#### 12.1 什么是商业模式

**定义**：商业模式是公司创造价值、传递价值、获取价值的逻辑。

**通俗理解**：
- 靠什么赚钱？（价值创造）
- 怎么把产品/服务卖给客户？（价值传递）
- 怎么把钱收回来？（价值获取）

**商业模式画布九要素**（简化版）：
1. 客户是谁？
2. 解决什么痛点？
3. 提供什么产品/服务？
4. 如何触达客户？
5. 收入来源是什么？
6. 核心资源是什么？
7. 关键业务是什么？
8. 成本结构如何？
9. 竞争优势在哪里？

#### 12.2 六种经典商业模式

**模式 1：制造销售型**
- 代表：美的集团、格力电器、富士康
- 特征：采购原料→生产加工→销售产品
- 财务特征：固定资产占比高、存货周转中等、毛利率 20-40%
- 关键成功因素：规模效应、成本控制、渠道管理

**模式 2：品牌溢价型**
- 代表：贵州茅台、爱马仕、苹果
- 特征：强大品牌支撑高定价
- 财务特征：高毛利率（50%+）、高净利率、预收款多
- 关键成功因素：品牌建设、品质控制、稀缺性营造

**模式 3：平台撮合型**
- 代表：阿里巴巴、美团、滴滴
- 特征：连接供需双方，收取佣金或广告费
- 财务特征：轻资产、高毛利、网络效应
- 关键成功因素：用户规模、双边网络效应、转化率

**模式 4：订阅服务型**
- 代表：Netflix、Adobe、微软 Office 365
- 特征：用户按周期付费，持续获得服务
- 财务特征：高续费率、稳定现金流、前期获客成本高
- 关键成功因素：产品粘性、转换成本、持续创新

**模式 5：金融杠杆型**
- 代表：银行、保险、券商
- 特征：用别人的钱赚钱，赚取利差或管理费
- 财务特征：高杠杆（权益乘数>5）、ROE 较高、周期性
- 关键成功因素：风控能力、资金成本、监管套利

**模式 6：资源垄断型**
- 代表：长江电力、中国神华、盐湖股份
- 特征：控制稀缺资源，坐地收钱
- 财务特征：高毛利率、稳定现金流、资本开支大
- 关键成功因素：资源禀赋、政策许可、进入壁垒

#### 12.3 巴菲特的护城河框架

**护城河定义**：阻止竞争对手抢走公司利润的结构性优势。

**五种护城河**：

**1. 无形资产**
- 包括：品牌、专利、政府许可、特许经营权
- 例子：茅台（品牌）、恒瑞医药（专利）、上海机场（特许经营）
- 财务体现：高毛利率、高定价权

**2. 转换成本**
- 定义：客户换供应商的成本很高
- 例子：企业软件（替换系统成本高）、医疗器械（医生使用习惯）
- 财务体现：高续费率、低客户流失率、稳定现金流

**3. 网络效应**
- 定义：用户越多，产品价值越大
- 例子：微信（社交网络）、淘宝（电商平台）、Visa（支付网络）
- 财务体现：赢家通吃、高市占率、边际成本低

**4. 成本优势**
- 定义：能以更低成本提供相同产品
- 来源：规模效应、独特工艺、资源优势
- 例子：沃尔玛（采购规模）、海螺水泥（石灰石矿山）
- 财务体现：毛利率高于同行、价格战中有优势

**5. 有效规模**
- 定义：市场太小，只能容纳一两家玩家
- 例子：某些细分化工品、区域垄断企业
- 财务体现：稳定盈利、增长有限、分红率高

#### 12.4 护城河的财务映射

**从财报读护城河**：

| 护城河类型 | 财务特征 |
|-----------|---------|
| 品牌 | 毛利率>50%、预收款多、销售费用率低 |
| 转换成本 | 续费率>90%、客户流失率<10%、应收账款少 |
| 网络效应 | 市占率>50%、边际成本递减、研发费用率高 |
| 成本优势 | 毛利率高于同行 10pp+、存货周转快 |
| 有效规模 | 营收增长慢但稳定、分红率高、负债率低 |

**例 12-1｜从财报读茅台的护城河**：
- 毛利率 90%+ → 品牌溢价极强
- 预收款（合同负债）常年百亿 → 经销商先打款后拿货
- 销售费用率<5% → 不需要大量营销就有需求
- 存货（基酒）越放越值钱 → 独特的时间壁垒

结论：茅台拥有极宽的品牌护城河。

#### 12.5 护城河的宽度、深度与消亡信号

**宽度**：护城河能保护多大范围的业务
- 宽护城河：保护整个公司（如茅台）
- 窄护城河：只保护部分业务（如某产品线有专利）

**深度**：护城河能抵御多强的竞争
- 深护城河：竞争对手几乎无法突破（如微信的社交网络）
- 浅护城河：可能被资本或技术突破（如某些互联网补贴战）

**消亡信号**：
1. 毛利率持续下降 → 定价权丧失
2. 市占率持续下滑 → 竞争优势被侵蚀
3. 销售费用率大幅上升 → 需要更多投入维持地位
4. 核心技术人才流失 → 创新能力下降
5. 替代品出现且快速渗透 → 护城河被绕过

#### 12.6 没有护城河不等于不能买

**重要澄清**：护城河理论适合长期价值投资，但不是唯一策略。

**没有护城河的公司也可能值得投资**：
1. **周期反转**：行业底部、公司成本低、等待周期回升
2. **困境反转**：一次性利空导致低估，问题解决后恢复
3. **成长早期**：护城河尚未形成，但成长空间大
4. **事件驱动**：并购、重组、政策变化等带来机会

**关键**：明确你的投资策略，匹配相应的选股标准。

#### 12.7 从财报读出商业模式

**实战方法**：

1. **看收入结构**：
   - 产品销售 vs 服务收入 vs 授权收入
   - 单一客户依赖度（前五大客户占比）

2. **看成本结构**：
   - 原材料占比高 → 制造业
   - 人工成本占比高 → 服务业
   - 研发费用占比高 → 科技业

3. **看资产结构**：
   - 固定资产占比高 → 重资产模式
   - 轻资产、高现金 → 平台或软件模式

4. **看现金流特征**：
   - 先款后货（预收款多）→ 强势地位
   - 先货后款（应收多）→ 弱势地位

**例 12-2｜对比两家公司商业模式**：
- 公司 A：毛利率 35%、固定资产占比 40%、应收周转 60 天 → 传统制造业
- 公司 B：毛利率 70%、固定资产占比 5%、预收款多 → 软件 SaaS 模式

**要点小结**
- 商业模式回答"靠什么赚钱、怎么卖、怎么收钱"
- 六种经典模式：制造销售、品牌溢价、平台撮合、订阅服务、金融杠杆、资源垄断
- 五种护城河：无形资产、转换成本、网络效应、成本优势、有效规模
- 护城河会在财报中留下痕迹（毛利率、周转率、现金流等）
- 护城河会消亡，需持续跟踪消亡信号
- 没有护城河的公司也可能有其他投资机会

**行动判据（If-Then）**
- 如果无法用一句话说清公司靠什么赚钱 → 那么不买，先研究清楚
- 如果毛利率连续 3 年下降 → 那么警惕护城河被侵蚀
- 如果发现替代品快速渗透 → 那么重新评估护城河宽度

**本章练习**
1. 选一家公司，用商业模式画布九要素分析其商业模式。
2. 判断该公司拥有哪些护城河，宽度深度如何。
3. 找出三家不同商业模式的公司，对比其财务特征差异。
