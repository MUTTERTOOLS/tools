第一篇

系统思维——从随机交易到系统化交易

核心目标：建立"系统化交易"的认知框架，理解为什么90%的散户亏损，以及一套完整交易系统长什么样。

第1章为什么你需要一套交易系统

散户亏损的终极原因：不是看不懂K线，是没有系统

大多数散户的亏损，不是技术问题，是结构问题。你可能学了K线形态、均线系统、基本面分析，甚至读了十几本投资书，但每次交易的决策路径都不一样——今天靠均线，明天听消息，后天看财报。你的知识是散的，你的操作是随机的。

随机交易的本质：每一次决策都是即兴发挥。就像一个厨师，今天做红烧肉、明天做披萨，但从来不做菜谱、不记用量、不总结哪个菜受欢迎——他永远无法复制成功，也无法避免失败。

⚠️ 致命认知
"我懂技术分析/基本面/宏观，所以我能赚钱"——这是散户最大的错觉。知识≠系统，散装知识不闭环等于没学。正期望值系统+0%执行率=确定亏损。

随机交易 vs 系统交易：三个维度的本质区别

维度随机交易系统交易
决策依据感觉/消息/灵感规则清单，逐一核对
买入后行为买了再想"什么时候卖"买入前已写好出场规则
亏损后反应情绪化——加仓摊平/报复性交易/割肉离场系统化——止损触发→执行→复盘→不改规则
长期结果不确定，靠运气确定的可控范围，靠概率
可改进性无法改进（不知道错在哪）可迭代（记录→复盘→优化）

交易系统是什么：把"艺术"变成"工程"

交易系统是一套定义"买什么、何时买、买多少、何时卖、错了怎么办"的完整规则集。

工程思维 vs 艺术思维的关键区别：

  • 工程思维：图纸→施工→质检→验收→维护。每一步有标准，每一步可追溯，每一步可改进。
  • 艺术思维：灵感→创作→完成。无法复制，无法量化，无法迭代。
  • 交易系统 = 工程思维应用到交易。你的交易应该是施工，不是创作。

好系统的三个标准

🔑 好系统的三个标准

① 可执行：规则清晰到无歧义——"当均线金叉时买入"比"趋势好的时候买入"好，因为"好"无法定义，"金叉"可以判断。

② 可回测：历史数据可验证——你能在过去的数据上跑一遍，看看这套规则过去表现如何。

③ 可迭代：有优化机制——发现缺陷可以修改，修改后有验证流程，不会越改越乱。

系统不能保证盈利，但能保证"可控"

这是交易系统最重要的认知：系统不保证赚钱，但保证你亏得明明白白、赚得有据可查。

  • 没有系统：亏了不知道为什么，赚了也不知道为什么，下次还是靠运气。
  • 有系统：亏了知道是哪个环节出了问题（入场条件太松？止损太紧？仓位太大？），可以针对性改进。
  • 可控 = 可改进 = 长期可盈利。这就是系统化交易的终极价值。
💡 类比
系统就像导航：导航不能保证你不堵车，但保证你知道自己在哪、该往哪走、走错了怎么纠偏。没有导航 = 在陌生城市瞎逛。
📏 第1章 If-Then 规则
当我的交易决策没有对照规则清单时，我将停止交易——没有规则依据的操作一律不做
当我发现自己在"凭感觉"操作时，我将退出交易软件，打开系统规则文档重新确认
当我亏损后第一反应是"我要赚回来"时，我将立即暂停交易至少1天——这是报复性交易的危险信号

系统的"闭环"

闭环 = 执行→记录→复盘→优化→再执行。这是系统化交易的生命线。

  • 执行：按规则操作
  • 记录：把每笔交易的决策过程写下来
  • 复盘：分析做对了什么、做错了什么
  • 优化：修改有缺陷的规则（每次只改一个变量）
  • 再执行：用优化后的规则继续操作
⚡ 最常见的系统"断环"

断环1：只有买入没有卖出规则——买了再说，跌了不知道怎么办。

断环2：只有规则没有复盘机制——规则写好了但从不检查是否有效。

断环3：有复盘但不改规则——发现问题但不行动，复盘变成了自我批评。

交易成本：被忽视的利润杀手

很多新手完全忽略了交易成本对利润的侵蚀。我们来算一笔账：

成本项费率收取方式10万全仓一笔
佣金万2.5-万3双向50-60元（买卖各一次）
印花税千1卖出单边100元
过户费万0.1（沪市）双向2元
滑点约0.1-0.3%隐性100-300元
合计--约250-460元/笔
⚠️ 成本杀伤力

10万资金每月交易10次（每次全仓）→年交易成本约2000-3000元 → 占资金2-3%。

如果你的系统年化收益预期是10%，交易成本就吃掉了20-30%的利润。"减少交易频率=直接增加利润"——这是最简单的提高收益的方法。

📏 第2章 If-Then 规则
当我设计交易系统时，我将确保六大组件（定位→选股→入场→仓位→出场→复盘）全部存在，缺一不闭环
当我的系统没有复盘机制时，我将先停下手设计复盘规则——没有复盘的系统不是系统
当我计算期望值时，我将扣除交易成本——名义期望值为正但扣除成本后为负的系统不可行

系统设计——六大组件逐个构建

第3章组件一：自我定位——系统的地基

为什么定位是第一步

照搬别人的系统 = 系统崩盘的第一大原因。一个上班族照搬全职交易者的短线系统，结果因为没时间盯盘，止损总是慢半拍，每次亏损都比计划大20%。一个50万资金的人照搬10万资金的高频系统，结果流动性不够，滑点吃掉了利润。

你的系统必须匹配你——你的资金、时间、性格、风险承受力。定位错了，后面的设计再精妙也是空中楼阁。

四维定位法

维度关键问题对系统的影响

定位后的"半年锁定"规则

⚡ 半年锁定规则

选定定位后，至少锁定6个月不切换风格。理由：

  • 任何系统都需要足够的数据样本（至少100笔）来评估
  • 频繁切换=永远在"试错期"，永远无法积累统计样本
  • "这周学趋势，下周学波段"=最昂贵的学费缴纳方式

💡 小资金的优势

资金量小不是劣势——小资金流动性好、船小好调头、交易成本占比可控。巴菲特说过："小资金可以做到大资金做不到的收益率。"所以别急着加钱，先把系统做好。

第4章组件二：选股规则——买什么

选股规则的目标：从4000只缩小到10只

A股有5000+只股票，你的自选池里只需要10-30只。选择越少，决策质量越高。选股规则就是一个漏斗，把4000只过滤到你真正会操作的范围。

风格筛选层：按你的系统类型筛选

💡 三种主流选股风格

① 主线赛道法：跟踪当前市场主线（AI/新能源/消费等），从主线板块中选龙头或弹性标的。

② 基本面筛选法：ROE>15%、毛利率>30%、营收增速>15%、负债率<60%等硬指标，从财务数据中筛选。【调用财报手册筛选方法】

③ 技术面筛选法：趋势向上+量价配合+形态完成，从技术形态中筛选。【调用裸K手册势位形分析】

观察池管理：每日盘后筛选→加入自选→仅在自选内操作

观察池（Watchlist）是你的"候选池"——每天盘后用选股规则扫描一遍，把符合条件的加入自选。只在自选池里操作，杜绝盘中临时选股。

⚡ "不在自选池里就不买"

盘中看到一只股票突然拉升，你的第一反应可能是"追！"。但如果你之前没有研究过它，你不知道它的基本面、不知道合理的入场位、不知道止损该设在哪——这笔交易从一开始就是赌博。

铁律：不在自选池里就不买。错过的机会永远比做错的交易便宜。

第5章组件三：入场规则——什么时候买

入场规则的铁律：多条件同时满足才开仓

好的入场规则是多条件AND逻辑——趋势AND形态AND量能AND大盘环境，少一条就放弃。差的入场规则是OR逻辑——"均线金叉OR放量OR感觉不错"就买，条件越多越容易买到假信号。

🔑 入场铁律

少一条就放弃——宁可错过100个机会，也不做1个条件不全的交易。错过不亏钱，做错才亏钱。

第6章组件四：仓位规则——买多少

仓位管理的系统化设计：从"感觉"到"算法"

散户最常见的仓位决策："这只看起来不错，买个三分之一仓吧"——这是感觉仓位，没有数学依据。系统化仓位是算法仓位：用公式反推，每笔交易的风险精确可控。

单笔风险上限法（固定分数法）

核心公式：买入股数 = 单笔风险上限金额 ÷ 每股风险

🧮 ATR仓位计算器

--
💡 示例

总资金10万，单笔风险1.5%=1500元。入场价30元，止损价28元，每股风险=2元。买入股数=1500÷2=750股，仓位金额=750×30=22500元（占总资金22.5%）。

波动率仓位法（ATR法）

ATR（Average True Range）衡量股票的日常波动幅度。波动大的少买，波动小的多买，使每笔交易面对的波动风险一致。

止损位 = 入场价 - N × ATR（N通常取2-3）。ATR大的股票止损距离远，仓位自然更小。

⚡ 何时选波动率法 vs 固定分数法？

固定分数法：你已经确定了止损价（技术位止损），用每股风险反推仓位。

波动率法：你没有明确的技术位止损，用ATR倍数设置止损，再反推仓位。

新手建议：先用固定分数法，因为止损价更直观。进阶后再用ATR法。

分批建仓与金字塔加仓

分批建仓：底仓50% → 确认后加仓30% → 趋势延续再加20%。每次加仓都有独立的止损位。

金字塔加仓：盈利后才能加仓，每次加仓量递减（如底仓1000股→加仓600股→再加仓300股）。加仓后的止损统一上移至保本位。

⚠️ 绝对禁止

亏损后加仓摊平 = 最危险的仓位错误。这是马丁格尔策略——亏损后加倍下注，期望一次翻盘。短期可能"解套"，长期必然爆仓。新手永远用反马丁格尔（盈利后加仓）。

第7章组件五：出场规则——什么时候卖

出场规则必须在买入前写好

这是系统化交易最重要的纪律之一：在你还没买入的时候，你的大脑最冷静。买入后，持仓盈亏会扭曲你的判断——赚了舍不得卖，亏了不愿止损。所以出场规则必须在买入前就写好，写在交易计划单上。

🔑 铁律

没有出场规则就不开仓。买入前写好：止损价、止盈目标、移动止盈规则。写在纸上，下单时照做。

止损设计

止损类型设置方法适用场景优缺点
固定比例入场价×(1-止损%)新手首选简单但忽略个股波动差异
技术位支撑位/均线/供需区域下方有技术分析基础最合理，但需技术判断

止盈设计

止盈类型方法适用场景
分批止盈目标1减仓50%→目标2减仓30%→留20%移动止盈中线波段
移动止盈盈利后止损线上移：每涨5%，止损上移3%趋势跟踪
信号止盈出现反向信号（如放量滞涨/均线死叉）时退出技术面驱动

盈亏比设计：为什么R:R≥2:1是入场前提

R = 初始风险（入场价-止损价）。如果目标盈利≥2R，盈亏比就是2:1。这意味着即使胜率只有40%，你也能盈利：

期望值 = 40%×2R - 60%×1R = 0.8R - 0.6R = 0.2R（正期望值）

如果盈亏比只有1:1，胜率40%→期望值 = 40%×1R - 60%×1R = -0.2R（负期望值），长期必亏。

止损被触发后的处理

止损被触发后，最危险的冲动是报复性交易——"我要赚回来"。这是亏损加速器。

⚠️ 报复性交易：亏损后最危险的冲动

心理机制：亏损→杏仁核激活→"我要赢回来"→加大仓位/频繁交易→亏损加速→更大的亏损→更强烈的报复→恶性循环。

系统级阻断方案：连续亏损3笔后，系统自动暂停1-3天——把规则写进系统，不靠意志力。详见风控心理手册。

止损后区分假突破 vs 趋势反转

  • 假突破止损：价格短暂跌破支撑后快速回升，你的止损被"猎杀"了。这种情况可以再入场——趋势逻辑没变，只是止损设在了太拥挤的位置。下次可以把止损再放宽一些。
  • 趋势反转止损：价格跌破支撑后持续下行，趋势逻辑已被证伪。这种情况不再入场——方向已变，等新的趋势信号。

第9章回测——用历史数据验证系统

为什么要回测

不验证的系统 = 未测试的飞机。你会坐一架从未试飞过的飞机吗？同样，你不应该用一套从未回测过的系统去实盘交易。回测不是万能的，但回测差 = 系统有缺陷，这是确定的。

手动回测方法

新手不需要昂贵的回测软件。手动翻图回测是最直观、最便宜的方法：

  1. 选一只流动性好的股票，时间跨度2-3年
  2. 打开K线图，从左到右逐日浏览
  3. 每次你的入场条件满足时，记录"入场价、止损价、目标价"
  4. 继续往后翻，看这笔交易最终是止损还是止盈
  5. 记录50笔交易后，统计胜率、盈亏比、期望值
💡 手动回测的核心价值

手动回测不仅验证规则，更重要的是让你深入理解规则在不同行情下的表现。你会发现哪些条件经常产生假信号、哪些过滤条件最有效——这是自动回测软件给不了的直觉。

回测的核心指标

指标计算方法健康值警告值
胜率盈利笔数/总笔数>35%<25%（除非盈亏比很高）
盈亏比平均盈利/平均亏损>2.0<1.5
利润因子总盈利/总亏损>1.5<1.2
最大回撤峰值到谷底最大跌幅<20%>30%
期望值胜率×均盈-败率×均亏>0≤0

回测的陷阱：曲线拟合（过拟合）

⚠️ 曲线拟合 = 回测越完美越可疑

如果你调整参数让回测结果"完美"——胜率80%、利润因子5.0、最大回撤5%——这几乎一定是过拟合。你把历史数据的噪音当成了信号，实盘必然失效。

检验方法：用回测未使用的数据做样本外测试。如果样本外表现大幅下降，说明过拟合了。

回测结论的正确解读

  • 回测好 ≠ 实盘好：回测没有滑点、没有情绪、没有流动性问题
  • 回测差 = 系统有缺陷：如果历史数据上都不赚钱，实盘更不会
  • 合理预期：实盘表现通常是回测的60-80%。如果回测期望值是0.3R，实盘可能是0.18-0.24R

第10章系统评估指标——用数字判断系统好坏

期望值计算器

🧮 期望值计算器

--

胜率：高胜率≠好系统

新手最关心胜率，但胜率只是期望值方程的一半。40%胜率+2.5:1盈亏比 vs 60%胜率+0.8:1盈亏比，前者期望值更高。

R倍数：以风险单位衡量盈亏

R = 你的初始风险（入场价-止损价）。盈利2R意味着你赚了2倍初始风险的钱。R倍数的好处是标准化——不同股票、不同仓位大小的盈亏可以用同一个标尺衡量。

R倍数含义评价
+3R及以上赚了3倍以上初始风险优秀交易
+2R赚了2倍初始风险好交易（盈亏比2:1）
+1R赚了1倍初始风险刚好达标
-1R亏了初始风险止损执行正常
-2R及以上亏了2倍以上初始风险止损未执行！必须复盘

交易成本调整后的期望值

名义期望值 - 每笔交易成本 = 实际期望值。

示例：每笔交易成本约0.3%（佣金+印花税+滑点）。如果你的名义期望值是0.2R（R=3%），即0.6%，扣除0.3%成本后实际期望值只剩0.3%。如果名义期望值本身就不高，交易成本可能把正期望值变成负的。

⚡ 交易成本敏感性

高频交易者（每月>20笔）对交易成本极敏感。中线交易者（每月2-4笔）影响较小。在系统设计阶段就把交易成本算进去——如果扣除成本后期望值为负，要么提高盈亏比，要么降低频率。

  • 计算名义期望值：____ | 估算每笔交易成本：____%
  • 实际期望值 = 名义期望值 - 交易成本 = ____ | 正还是负？

第11章模拟盘练习——系统验证的第一步

模拟盘的目标：验证系统可执行性

模拟盘不是用来"赚模拟钱"的——模拟钱毫无意义。模拟盘的真正目标是验证你的系统是否可执行：

  • 规则是否清晰到无歧义？（如果模拟盘里你都在犹豫，实盘更会犹豫）
  • 条件是否太多导致信号太少？（一个月连一个信号都没有的系统不实用）
  • 止损/止盈规则是否可操作？（到了止损位你真的会"卖"吗？）

模拟盘的正确用法

🔑 模拟盘铁律

完全按真实系统操作——用真实资金量、真实仓位计算、真实止损止盈规则。唯一的区别是钱是虚拟的。如果模拟盘里你"随便玩"，那模拟盘的验证价值为零。

模拟盘的局限性

模拟盘最大的缺陷：没有真实亏损的恐惧。模拟止损就是点一下按钮，没有"真金白银没了"的心理冲击。所以模拟盘能验证系统的"逻辑可行性"，但无法验证"心理可承受性"——这就是为什么必须经过实盘。

🔑 模拟盘毕业 = 两个条件同时满足

① 连续50笔执行率>90%（5笔以内偏离规则）

② 期望值为正（胜率×平均盈利 - 败率×平均亏损 > 0）

两个条件缺一不可：执行率高但期望值为负=系统有缺陷；期望值为正但执行率低=心理问题未解决。

第12章小仓位实盘——心理验证的关键一步

为什么必须经过实盘

模拟盘能验证逻辑，但只有真金白银的亏损才能验证你的心理承受力。很多在模拟盘中执行完美的规则，到了实盘就变形——止损下不去手、盈利急着跑、加仓摊平……这些都是心理问题，不是系统问题。

小仓位原则

🔑 "亏了不心疼"原则

小仓位的标准：即使全部亏损，你的生活质量不受影响。建议用总资金的5-10%做小仓位期。10万资金用5000-10000元做实盘验证，每笔亏损不超过100-200元。

第14章正常仓位实盘——积累经验与优化

从小仓位到正常仓位的过渡标准

小仓位毕业≠可以立即满仓操作。过渡标准：

  • 小仓位期（51-100笔）执行率>80% ✅
  • 实际期望值（扣除成本后）为正 ✅
  • 情绪干扰记录后半段比前半段减少50%以上 ✅

三个条件同时满足，可以逐步增加仓位：5%→10%→15%→按系统规则正常仓位。每增加一个台阶，至少运行20笔确认执行率不下降。

正常仓位期（101-300笔）的核心目标

积累统计样本——100笔交易才能初步判断系统的统计特征（胜率/盈亏比的稳定性），300笔才能形成较可靠的结论。

参数微调：基于100+笔数据的统计调整

当你积累了100笔以上的数据，你可以开始基于统计微调参数：

  • 胜率低于预期→入场条件是否太松？增加过滤条件
  • 盈亏比低于预期→止盈目标是否太保守？或止损太紧被频繁震出？
  • 执行率下降→规则是否太复杂？简化
⚡ 每次只改一个变量

如果你同时改了入场条件和止损参数，你永远不知道哪个改动产生了效果。每次只改一个变量→回测→模拟→小仓位确认→推广。

信心建立：从"怀疑系统"到"信任系统"

正常仓位期最大的心理挑战是信任——当系统连续亏损时，你是否还能继续执行？答案是：看数据。

  • 如果100笔中连续亏损5笔，但总期望值仍为正→继续执行
  • 如果期望值从正变负→暂停，评估系统是否失效

正常仓位期的最大风险：过度自信

⚠️ 过度自信 = 系统崩溃的前兆

连续盈利几笔后，最容易犯的错误：放松纪律——"今天规则不满足但感觉不错，买吧"、"止损不用那么紧，再等等"。赚钱时的偏离规则比亏钱时更危险，因为它给你"我比系统更聪明"的错觉。

复盘的三个层次

层次频率核心问题输出
每笔复盘每笔交易当天做对了什么/做错了什么经验教训+规则修正建议

每笔复盘三问

🔑 每笔复盘三问

① 我做对了什么？——哪些决策符合规则，产生了好结果

② 我做错了什么？——哪些决策偏离了规则，为什么偏离

③ 规则需要修改吗？——如果同一条件连续3次失败，该条件可能需要修改

注意：复盘是修补系统，不是自我批评。"我做错了"不是"我很蠢"，而是"这条规则不够清晰"或"我在这类行情下容易偏离"——找出问题，修改系统，下次不再犯。

"连续3次失效"规则

如果同一条件在3笔交易中连续失效，说明该条件可能有问题：

  • 止损连续3次被震出→止损可能设太紧，加宽1个ATR试试
  • 入场信号连续3次假突破→入场条件可能太松，增加1个过滤条件
  • 某板块连续3笔亏损→该板块可能已过气，暂时从观察池移除
⚡ 3次失效≠立即推翻系统

连续3次失效是"提示信号"，不是"死刑判决"。先分析原因——是规则问题还是市场环境变化？再决定是调参数还是换规则。切忌一次亏损就推翻系统。

原因正常概率波动（连亏是随机的）市场结构变化导致逻辑失效
期望值滚动100笔仍为正滚动100笔转为负
应对继续执行，可适当降低仓位暂停，评估系统逻辑是否仍成立

系统失效的五个信号

⚠️ 系统失效的五个红灯信号

① 连续亏损超过历史最大连亏×1.5——比如历史最大连亏6笔，现在连亏10笔还没停

② 滚动100笔期望值转负——不是偶尔亏损，而是持续亏损

③ 胜率和盈亏比同时大幅下降——不是盈亏比低了但胜率还在，而是双降

④ 市场状态发生根本性变化——如从趋势市变为长期震荡市，趋势系统必然失效

⑤ 最大回撤超过预设上限——如预设最大回撤20%，现在已亏25%+

"暂停"而不是"放弃"

触及失效信号时，正确的做法是暂停操作→评估系统，而不是立即放弃换新系统。很多交易者在系统正常回撤期就放弃，结果刚放弃系统就恢复了——这是最常见的"黎明前离场"。

坚持系统的纪律

🔑 关注过程而非结果

执行率 > 胜率——按规则做了即使亏了也是对的，没按规则做了即使赚了也是错的。

原因：按规则亏损是系统成本（概率波动的正常结果），不按规则赚钱是运气（不可复制，且强化了坏习惯）。

系统验证期铁律

给系统至少3-6个月的实盘验证期，期间只做小仓位，不做大调整。频繁切换系统 = 永远在试错期 = 永远无法积累统计样本。

📏 第16章 If-Then 规则
当连续亏损超过历史最大连亏×1.5时，我将暂停操作，用2-3天评估系统逻辑是否仍成立
当滚动100笔期望值转负时，我将暂停系统，回测+分析原因→修改→重新验证
当我在正常回撤期想放弃系统时，我将检查执行率和期望值——执行率高+期望值正=继续执行
当系统运行不满3个月时，我将不做大调整——数据不够，判断不准

第17章系统迭代——怎么改才不会越改越差

迭代的基本原则：每次只改一个变量

这是系统迭代的第一铁律。如果你同时改了入场条件和止损参数，效果变好了——你不知道是哪个改动贡献的。效果变差了——你也不知道该撤回哪个。

🔑 迭代五步流程

改→回测→模拟→小仓位实盘→确认→推广

每一步都是验证——回测验证逻辑、模拟验证可执行性、小仓位验证心理、确认后推广到正常仓位。跳步 = 未验证的修改进入实盘 = 危险。

参数优化 vs 规则优化

类型示例风险频率
参数优化（微调）止损从5%改为6% | 均线从20日改为30日低（逻辑不变）可较多
规则优化（结构变化）增加1个入场过滤条件 | 更换止损类型中（逻辑部分改变）谨慎
推翻重建放弃趋势系统→改用均值回归系统高（全新系统）极少

过度优化的陷阱

过度优化 = 在历史数据上调参数让回测结果"完美"。特征：

  • 参数精度过高（如止损5.73%而不是5%或6%）
  • 参数数量过多（5个以上可调参数）
  • 回测利润因子>3、胜率>60%、最大回撤<10%
  • 样本外表现大幅下降
⚠️ 过度优化的判断标准

如果你的系统有N个可调参数，回测样本数至少需要N×50笔交易。3个参数的系统至少需要150笔回测样本。如果样本不够，参数优化结果不可靠。

系统的"半衰期"

任何系统都会随市场变化而衰减——这就是"半衰期"。趋势系统在震荡市中衰减，价值系统在泡沫期衰减。系统不是一劳永逸的，定期评估和迭代是必需的。

典型的半衰期：短线系统6-12个月，中线系统1-2年，长线系统2-5年。

系统切换决策树

当你的趋势系统在长期震荡市中持续失效：

  1. 逻辑是否仍然有效？→ 是→调参数（降低仓位/收紧止损）→否→继续
  2. 市场状态是否已根本性改变？→ 是→考虑切换到适配当前状态的系统→否→暂停等待市场回归
  3. 切换前提：新系统必须经过完整回测+模拟盘验证，不能直接实盘切换
  4. 切换节奏：旧系统逐步减仓→新系统逐步建仓→过渡期至少1-2个月
⚡ 一个交易者最多同时有效运行两套系统

超过两套=管理不过来=每套的执行率都下降。先做好一套，再考虑第二套。

📏 第17章 If-Then 规则
当我想修改系统时，我将每次只改一个变量，走完"改→回测→模拟→小仓位→确认"五步
当我发现回测结果"过于完美"时，我将用样本外数据验证——过拟合的回测实盘必然失效
当我想切换到新系统时，我将先用回测+模拟验证新系统，再过渡1-2个月，不直接实盘切换
当我同时想运行3套以上系统时，我将精简为2套——超过2套=管理不过来

第18章常见系统设计误区

误区1：堆砌指标

新手最爱做的事：加入均线、MACD、KDJ、RSI、布林带……指标越多，条件越难同时满足，信号越少。就算满足了，你也不知道哪个指标真正有效。

正确做法：每类功能选1个指标——趋势1个（如均线）、动量1个（如RSI）、量能1个（如成交量）。3个指标足矣。

误区2：只有买入没有卖出

"会买的是徒弟，会卖的是师傅"——如果你只有买入规则，没有出场规则，那你的系统只有半环。买入后的一切都是即兴发挥。

误区3：盈利后随意修改规则

"短期赚钱就放宽条件"——这是最隐蔽的误区。赚钱后放宽条件，看似更灵活，实际上是降低了系统的保护屏障。等你遇到亏损期，宽松条件会让你亏更多。

误区4：忽略大盘环境

个股信号再好，大盘暴跌也亏。系统必须包含大盘环境过滤——这是"天气判断"，决定你今天出不出门。

误区5：止损设太紧

止损太紧=被正常波动频繁震出。如果你发现自己经常"刚止损就涨回来"，说明止损设在了太拥挤的位置。正确做法：止损设在关键支撑位下方+1个ATR的空间。

误区6：不止损死扛

把"投资"变成"赌博"——不止损的唯一理由是"我相信它会回来"。但它可能不回来。止损是保险，不是惩罚。交了保费（止损），你才能继续在市场上活着。

误区7：频繁切换系统

"这周学趋势，下周学波段"=永远在试错期=永远没有统计样本。任何系统至少需要100笔实盘数据才能初步评估。

误区8：把运气当能力

牛市赚钱不等于系统有效。2014-2015年人人都是股神，但2015年下半年大多数人都亏回去。检验系统的唯一标准：扣除交易成本后的长期期望值是否为正。

⚠️ 八大误区一句话总结

堆指标=信号枯竭 | 没出场=半环系统 | 盈利改规则=拆保护罩 | 忽略大盘=逆天而行 | 止损太紧=频繁被猎 | 不止损=赌徒 | 频切换=永远试错 | 牛市赚钱=运气非能力

📏 第18章 If-Then 规则
当我的系统超过5个指标时，我将精简为3个以内——每类功能1个，够用就行
当我的系统没有大盘环境过滤时，我将立即加入——没有天气判断不出门
当我想在盈利后放宽规则时，我将回想这个误区——放宽规则=拆保护罩
当我想切换系统时，我将问自己：当前系统至少运行了100笔吗？没有就继续坚持

第19章经典交易系统案例拆解

海龟交易法：最著名的系统化交易案例

1983年，理查德·丹尼斯用一套完全系统化的交易规则，培训了一群"海龟"交易员，证明了交易可以被系统化教授。海龟系统的核心规则：

组件规则
选股流动性好的期货品种（后扩展到股票）
入场20日突破（价格突破近20日最高价时做多）
仓位ATR法（波动大的少买，波动小的多买）
止损入场价-2×ATR
止盈10日反向突破退出
加仓每盈利0.5×ATR加仓1个单位，最多4个单位（金字塔加仓）

历史绩效：1983-1988年，海龟团队年化收益率约80%，但最大回撤也超过30%。

优缺点：优点是逻辑清晰、完全系统化、长期正期望值；缺点是胜率低（约35-40%）、需要极大的心理承受力（连续亏损7-10笔是常态）、在震荡市中表现差（频繁假突破）。

A股本土化：用沪深300成分股回测海龟系统——在2007/2015等大牛市表现优异，但在2016-2018震荡市中频繁假突破，年化收益仅3-5%。海龟系统在A股的趋势市有效，震荡市水土不服。

双均线交叉系统：最简单的趋势跟踪

组件规则
入场短期均线（5日）上穿长期均线（20日）时做多
出场短期均线下穿长期均线时平仓
止损入场价-3%或均线交叉退出
仓位固定分数法

优缺点：极简，新手友好；但信号滞后（均线本身滞后）、震荡市频繁假信号。适合趋势明显的行情。

突破回踩系统：中线波段经典

组件规则
选股趋势向上+箱体整理>15天
入场突破箱体上沿→缩量回踩箱体上沿→放量收阳时入场
止损箱体中轨下方
止盈目标1=突破幅度×1，目标2=×1.5

失败案例：2019-2021趋势系统在2022-2024的失效

⚠️ 系统失效真实案例

背景：一套"均线金叉+放量突破+ATR止损"的趋势跟踪系统，在2019-2021年（核心资产牛市）表现优异：年化25%、胜率48%、盈亏比2.8:1。

失效：2022-2024年市场转为长期震荡+黑天鹅（俄乌/美联储加息/疫情反复），趋势信号频繁假突破。胜率降至28%、盈亏比降至1.2:1、期望值转负。

原因：趋势系统在趋势市赚钱、在震荡市亏钱——这是系统本质决定的，不是参数问题。

应对：①识别市场状态变化（趋势→震荡）→②降低仓位→③暂停系统→④考虑切换到均值回归系统→⑤新系统验证后过渡。

从经典系统中学习的正确姿势

学逻辑，不照搬参数。海龟的20日突破在A股可能需要改成15日或30日——参数要匹配你的市场、你的风格、你的资金量。但"趋势突破+ATR仓位+金字塔加仓"的逻辑框架是通用的。

📏 第19章 If-Then 规则
当我学习经典系统时，我将学逻辑框架而非照搬参数——参数匹配自己的市场、风格、资金量
当我的趋势系统在震荡市中持续亏损时，我将判断市场状态是否已根本性改变——是则考虑切换系统
当我回测经典系统时，我将在A股数据上验证——海外有效的系统不一定适合A股

第20章多系统并行——从单一系统到投资组合化

为什么要多系统

单一系统只适应一种市场状态——趋势系统在震荡市失效，震荡系统在趋势市跑输。多系统并行 = 分散市场状态风险：趋势系统+震荡系统同时运行，无论市场处于什么状态，总有一套在赚钱。

多系统的组合逻辑

维度系统A系统B互补效果
风格趋势跟踪均值回归趋势市赚A，震荡市赚B
周期短线（2-10天）中线（2-8周）不同节奏的信号互不干扰
市场状态牛市系统熊市/震荡系统全天候覆盖

系统之间的资金分配

按历史绩效和当前市场状态分配：

  • 趋势市→趋势系统分70%，震荡系统分30%
  • 震荡市→震荡系统分70%，趋势系统分30%
  • 不确定→各50%

多系统的管理复杂度

⚡ 系统越多越需要纪律

多系统的风险不是"系统冲突"，而是"管理不过来"。每套系统都需要独立的选股、入场、出场、复盘——2套系统的工作量是1套的2倍以上。新手建议：先做好一套系统，再考虑第二套。

从"交易者"到"系统管理者"的角色转变

当你运行2套以上系统时，你的角色从"交易者"变成了"系统管理者"——你不再执行每一笔交易，而是管理系统的运行状态、资金分配、定期评估。这是一个重要的认知跃迁。

📏 第20章 If-Then 规则
当我的第一套系统运行不满300笔时，我将不考虑第二套——先做好一套
当我运行多系统时，我将最多同时运行2套——超过2套=管理不过来
当我分配多系统资金时，我将按当前市场状态分配——适配当前状态的系统分更多

第21章长期盈利的终极秘密

长期盈利 = 正期望值系统 + 严格执行 + 足够时间

这三者缺一不可：

  • 正期望值系统：胜率×平均盈利 - 败率×平均亏损 > 0（扣除交易成本后）。没有正期望值，再好的执行也是确定亏损。
  • 严格执行：执行率>85%。正期望值系统+0%执行率=确定亏损。系统设计得再好，不执行等于没有系统。
  • 足够时间：概率需要大样本才能显现。100笔交易才能初步判断，300笔才能形成可靠结论。短期亏损不代表系统无效，短期盈利也不代表系统有效。

为什么大多数人知道却做不到

执行是最大的瓶颈。知道"该止损"和"真的止损"之间隔着一个杏仁核——0.3秒的恐惧反应就能让你放弃规则。这就是为什么需要系统：系统代替意志力。条件单自动止损、连续亏损自动暂停——把规则写进"硬件"，不靠"软件"（意志力）。

从"靠系统赚钱"到"靠系统活着"

🔑 生存优先于盈利

巴菲特第一条规则：不要亏钱。第二条：记住第一条。

系统化交易的终极价值不是让你赚多少，而是让你在市场上活着——活着才有机会赚。死扛不止损的人可能在牛市赚很多，但一次大熊市就清零。系统保证你的亏损永远在可控范围内。

向市场学习的具体方法

每周观察一个新现象→记录→验证→纳入系统或排除。例如：

  • "最近主力资金总是尾盘拉升"→观察10次→验证是否可量化→纳入入场条件或排除
  • "某板块的龙头总是先于板块启动"→观察→验证→纳入选股规则

市场是活的，系统也要是活的。但迭代要有纪律——每次只改一个变量，改后验证。

Python绩效统计脚本

以下脚本可复制使用，输入交易日志CSV，输出核心绩效指标：

import pandas as pd
import numpy as np

# 读取交易日志CSV（需含字段：入场价,止损价,出场价,方向,盈亏金额）
df = pd.read_csv('trading_log.csv')

# 核心指标计算
wins = df[df['盈亏金额'] > 0]
losses = df[df['盈亏金额'] <= 0]
win_rate = len(wins) / len(df) * 100
avg_win = wins['盈亏金额'].mean()
avg_loss = abs(losses['盈亏金额'].mean())
profit_factor = wins['盈亏金额'].sum() / abs(losses['盈亏金额'].sum())
expectancy = (win_rate/100 * avg_win) - ((100-win_rate)/100 * avg_loss)
max_loss_streak = 0; current = 0
for p in df['盈亏金额']:
    current = current + 1 if p <= 0 else 0
    max_loss_streak = max(max_loss_streak, current)

# R倍数计算
df['R'] = abs(df['入场价'] - df['止损价'])
df['R_multiple'] = df['盈亏金额'] / df['R']

print(f"胜率: {win_rate:.1f}%")
print(f"盈亏比: {avg_win/avg_loss:.2f}:1")
print(f"利润因子: {profit_factor:.2f}")
print(f"期望值: {expectancy:.2f}元/笔")
print(f"最大连续亏损: {max_loss_streak}笔")
print(f"最大R倍数盈利: {df['R_multiple'].max():.1f}R")
print(f"最大R倍数亏损: {df['R_multiple'].min():.1f}R")
