# 五册手册重写规范与全局口径（v2.0）

> 本文件是五册手册重写的唯一基准。任何册的内容与本文件冲突时，以本文件为准。
> 原版备份位于 `backup-v1/`，重写时以原版的知识点为素材来源，但章节结构、表达方式、组织顺序均按本规范重新设计。

## 1. 系列定位与读者画像

- **系列名**：《投资者教育手册系列》（全五册）
- **目标读者**：初入股市的新人——刚开户、无系统金融知识、可能连K线都没看过。
- **系列总目标**：从零开始，最终能独立完成「宏观环境判断 → 财报选股排雷 → 图表分析 → 交易计划 → 风控执行 → 复盘迭代」的全链路闭环。
- **写作基调**：
  - 由浅入深：每个概念先给定义，再给生活化比喻，再给市场例子，最后给可量化判据。
  - 专业准确：术语首次出现必须定义（中文为主，英文缩写括注）；所有判据必须可检验，禁止模糊表达（如单独使用"无人区"必须先量化定义）。
  - 通俗易懂：多用比喻和案例，但比喻之后必须回到精确定义。
  - 不承诺收益：所有数字均为示例或经验校准，需注明"示例数据"或"经验值，需自行回测验证"。
- **市场背景**：以 A 股现货为主线（不能做空、T+1、主板涨跌停 10%/创业板科创板 20%），不引入期货期权作为主要工具（仅在风控册简要介绍对冲概念）。

## 5. ECharts 使用规范

- 使用 ```echarts 围栏代码块，内容为**可直接运行的 option JSON**（无 import、无外部依赖、无函数，series data 全部为字面量数组）。
- 允许组件：title / legend / tooltip / xAxis / yAxis / series（line、bar、candlestick、pie、heatmap、scatter、funnel、graph、radar）/ markLine / markArea / dataZoom / grid。
- K线图（candlestick）：data 元素为 `[open, close, lowest, highest]`；A股红涨绿跌：`itemStyle: { color: '#ef5350', color0: '#26a69a', borderColor: '#ef5350', borderColor0: '#26a69a' }`。

- 所有示意数据必须合理、自洽（如 K 线 high≥max(open,close)、low≤min(open,close)），并在图题或说明中标注"示例数据"。
- 全部中文标签；坐标轴名称完整；关键阈值用 markLine 标出并带标签。

## 6. 全局统一口径（五册必须完全一致，不得各自为政）

### 6.1 风险与资金类
| 条目 | 统一口径 |
|---|---|
| 单笔风险上限 | ≤2%（铁律）；新手期 1% |
| 信号分级仓位 | C级=标准仓的1/3，B级=1/2，A级=标准仓 |
| 大盘环境三态 | 多头=指数在20日均线上方且均线上行；震荡=20日均线附近反复；空头=20日均线下方且均线下行 |
| 总仓位上限 | 多头≤80%、震荡≤50%、空头≤20%且不开新仓；新手期任何环境≤50% |
| 单票 / 单板块 / 现金 | 单票≤20%（新手≤15%）；单板块≤20%；现金≥30% |
| 分层风控 | 单笔1-2% → 单日3-5%（当日停止）→ 单周8-10%（暂停1-3天）→ 单月10-15%（降仓至≤30%）→ 回撤预警10%（减仓至≤50%）→ 清盘线20%（全面停止） |
| 连亏阶梯 | 3笔→仓位减半；5笔→暂停1-3天；7笔→暂停1周；10笔→全面停止+系统评估 |
| 三条资金红线 | ①不借钱炒股 ②不用生活必需资金 ③月亏损超月收入10%必须暂停 |
| 止损公式 | 止损=入场逻辑失效位 ± 1个ATR（14周期）；宽度1-1.5个ATR；绝不设在锚点价位（前高/前低/影线端点/整数位）上 |
| 盈亏比门槛 | ≥2:1 才入场；入场前计算 |
| 仓位公式 | 股数=(总资金×风险比例)÷(入场价-止损价)；实际仓位=min(风险反推仓位, 上限约束仓位) |
| 凯利 | f*=(bp-q)/b；实际用半凯利 |
| 加仓 | 禁止马丁格尔；金字塔加仓仅盈利后、每次递减、加仓后止损上移保本位 |
| 盈利保护 | +3%→止损移保本；+5%→移至+2%；+10%→移至+5%；+20%以上→移动止盈 |
| 分批止盈 | 目标1（≥2:1）减仓50% → 目标2 减仓25% → 剩余25%移动止盈 |

### 6.2 技术分析类
| 条目 | 统一口径 |
|---|---|
| 量比 | 当日每分钟均量 ÷ 过去5日每分钟均量；>1放量、<1缩量；确认K线量比≥1.5；突破量比≥1.5为真、<1.2存疑 |
| 震荡市占比 | A股约60%时间处于震荡 |
| 关键位数量 | 每只股票标注5-8个 |
| 无人区 | 定义为"距最近关键位>2个ATR的区域"（首次出现必须给出该定义） |
| 供需区回测 | 首次最强、二次衰减、三次及以上标记失效 |
| 信号分级 | C级=单K+关键位+顺势（约50%）；B级=双K确认+量价配合（约60%）；A级=三重确认+多周期共振（约70%+）；百分比为示意校准，需自行回测 |
| 收盘确认 | A股盘中信号不算数；收盘前15分钟决策价值最高 |
| 回调分级 | 38.2%浅（强势）、50%正常、61.8%深（盈亏比最优）、>78.6%视为结构反转风险 |
| BOS/CHOCH | BOS=趋势方向关键高低点被突破（延续确认）；CHOCH=逆趋势方向关键高低点被突破（反转第一信号，非确认） |
| Pin Bar | 实体≤整根1/3 + 影线≥2倍实体；5标准评分，"关键位"为门槛项 |

### 6.3 系统评估类
| 条目 | 统一口径 |
|---|---|
| 期望值 | =胜率×平均盈利-败率×平均亏损；必须扣除交易成本后再判断 |
| 健康值 | 胜率>35%、盈亏比>2.0、利润因子>1.5、最大回撤<20%、期望值>0 |
| 实盘与回测 | 实盘通常为回测的60-80% |
| 毕业标准 | 模拟50笔（执行率>90%且期望值>0）→ 小仓位51-100笔（执行率>80%、情绪干扰减半、期望值>0）→ 正常仓位；仓位台阶5%→10%→15%→正常，每台阶≥20笔 |
| 执行率 | 目标≥85%，底线80% |
| 迭代 | 每次只改一个变量；样本≥参数个数×50笔；系统半衰期：短线6-12月/中线1-2年/长线2-5年；最多并行2套系统 |
| 交易成本 | 佣金约万2.5（双向）、印花税0.05%（卖出单边，2023年8月28日起减半）、过户费0.001%（双向）、滑点约0.1-0.3%；10万元全仓单次往返合计约250-400元（含滑点） |

| 担保 | 担保/净资产>50% → 存疑 |

| 互联网 | LTV/CAC>3健康 |

## 7. 跨册引用规范

- 五册简称：裸K手册、财报手册、宏观手册、系统手册、风控手册。
- 引用格式：`详见《风险管理与交易心理》第6章` 或 `见裸K手册第12章`。
- 系列主线工具「全链路交易计划八步」定义于系统手册第8章，其他册引用时统一称"八步全链路交易计划"：
  ①宏观环境（宏观手册五步法）→②指数结构（裸K手册指数PA）→③板块筛选（宏观手册行业轮动）→④基本面排雷（财报手册十项清单）→⑤PA入场信号（裸K手册势位形）→⑥仓位计算（系统手册单笔风险法）→⑦出场规则（止损/止盈/移动止盈）→⑧复盘准备（交易日志+心理预演）。
- 全局术语表定义于裸K手册附录A（五册共用），含K线价格锚点统一表述：最高价/最低价（影线端点）、实体顶=max(开盘,收盘)、实体底=min(开盘,收盘)。
- 系列中不存在第六册。删除原稿中对《知行鸿沟手册》等不存在手册的引用，其内容（执行瞬间防线）归入风控手册第五篇。

## 8. 时效性更新清单（已核实，必须落实）

1. **北向资金披露机制**：自 2024-08-19 起，沪深股通**不再披露盘中实时买入/卖出成交额**；收市后披露当日成交总额及总成交笔数、ETF成交总额、前十大成交活跃证券名单及其成交总额（按月/年汇总）；单只证券北向投资者合计持有数量改为**每季度第五个交易日**披露上季度末数据。→ 宏观手册第11章"北向资金"必须按新机制改写：从"盯实时净买入"转为"收市后成交总额+季度持仓变化+结合汇率/利差环境综合判断"。
2. **程序化交易新规**：证监会《证券市场程序化交易管理规定（试行）》2024-05-15 发布；沪深北交易所《程序化交易管理实施细则》**2025-07-07 起施行**。高频交易认定标准：单账户每秒申报/撤单合计最高≥300笔，或全日申报/撤单合计最高≥20000笔。四类异常交易行为：瞬时申报速率异常、频繁瞬时撤单、频繁拉抬打压、短时间大额成交。→ 裸K手册"算法时代"章必须更新：监管落地后高频报撤单行为收敛，但关键位附近的止损猎取动机仍在，应对三招（ATR余量+收盘确认+条件单）不变。
3. **印花税**：2023-08-28 起减半至 **0.05%**（卖出单边）。→ 系统手册交易成本计算全部更新（原稿按千1已过时）。
4. **十五五规划**：十五五规划期（2026-2030）已开启，政策主线围绕新质生产力、科技自立自强、高端制造等（以官方文件为准），表述用"十五五规划期"而非"预计"。
5. **注册制与退市**：A股已全面实行股票发行注册制（2023年2月），退市常态化，上市公司5000余家。财报手册排雷部分应体现"退市常态化下排雷权重上升"。
