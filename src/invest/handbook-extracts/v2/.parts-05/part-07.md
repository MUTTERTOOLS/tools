### A.2 仓位反推公式

```
买入股数 =（总资金 × 风险比例）÷（入场价 - 止损价）
实际仓位 = min(风险反推仓位, 上限约束仓位)
上限约束：单票≤20%（新手≤15%）；单板块≤20%；现金≥30%
```

### A.3 分层风控参数速查

| 层级 | 触线条件 | 强制动作 |
|---|---|---|
| 单笔 | 亏1%-2%（新手1%） | 止损出场 |
| 单日 | 累亏3%-5% | 当日停止交易，离开电脑 |
| 单周 | 累亏8%-10% | 暂停1-3天+复盘 |
| 单月 | 累亏10%-15% | 降仓至≤30%+全面评估 |
| 回撤预警 | 从峰值回撤10% | 减仓至≤50%+重估系统 |
| 清盘线 | 从峰值回撤20% | 全面停止交易+系统评估 |

连亏阶梯：3笔→仓位减半；5笔→暂停1-3天；7笔→暂停1周；10笔→全面停止+系统评估。

### A.4 亏损回本不对称表（本册第一超级符号）

| 亏损 | 回本所需涨幅 | 亏损 | 回本所需涨幅 |
|---|---|---|---|
| -10% | +11.1% | -50% | +100% |
| -20% | +25.0% | -60% | +150.0% |
| -30% | +42.9% | -70% | +233.3% |
| -40% | +66.7% | -80% | +400.0% |
| — | — | -90% | +900.0% |

公式：回本涨幅＝亏损幅度÷(1-亏损幅度)。

### A.5 盈亏比与期望值模板

```
盈亏比 = 潜在盈利 ÷ 潜在亏损；≥2:1 才允许入场（入场前计算）
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损（须扣除交易成本后判断）
示例：0.4×3R - 0.6×1R = +0.6R/笔
```

### A.6 三条资金红线（Day 0 生存契约）

1. 永远不借钱炒股（杠杆数学：2倍杠杆跌50%清零、5倍杠杆跌20%清零）；
2. 永远不用生活必需资金炒股；
3. 月亏损超过月收入的10%必须暂停。

## 附录B 情绪管理工具箱

### B.1 情绪温度计四色规则（本册第二超级符号）

| 颜色 | 交易前 | 交易中 | 交易后 |
|---|---|---|---|
| 绿（冷静） | 正常执行 | 正常持有 | 正常复盘 |
| 黄（不安） | 减半仓位/只平仓不开仓 | 只平仓不开仓 | 重点复盘情绪 |
| 橙（冲动） | 禁止开新仓 | 只执行止损 | 暂停1天 |
| 红（失控） | 不交易 | 立即离开电脑 | 暂停3天 |

铁律：入场前标到黄色及以上，该笔交易不允许执行；入场前、持仓中、出场后三时点各标一次。

### B.2 情绪暂停规则速查

| 触发 | 动作 | 恢复 |
|---|---|---|
| 黄色 | 减半操作/只平仓 | 15分钟后复测回绿 |
| 橙色 | 禁止开新仓，只止损 | 30分钟后复测回绿 |
| 红色 | 关闭软件离开电脑 | 次日重新评估 |
| 连亏3笔 | 强制暂停1-3天 | 复盘完成 |
| 单日亏3% | 关闭软件离开30分钟 | 当天不再交易 |
| 盈利后 | 30分钟内不做新决策 | 计时结束 |

### B.3 物理隔离五步

站起来→离开屏幕→冷水洗脸→喝一杯水→回到规则清单（不是回到盘面）。

### B.4 心理预演模板（盘前5分钟）

```
标的：____  持仓：____股  成本：____  止损：____（条件单已设：是/否）
如果涨了：达到目标1（≥2:1）→卖50%；达到目标2→再卖25%；剩余移动止盈
如果跌了：触及止损价→无条件执行（条件单自动）
如果横盘：3个交易日未启动→时间止损评估，默认退出
如果亏了2%：关闭软件→离开30分钟→复盘→当天不做新交易
```

### B.5 每日5分钟正念引导词

坐直闭眼→深呼吸3次→把注意力放在呼吸上→扫描身体（肩膀、心跳、手心），不评判只觉察→走神就轻轻拉回→结束前先读规则清单，再看行情。建议呼吸节律：4秒吸气-7秒屏息-8秒呼气（示例节律，以舒适为准）。

### B.6 条件单设置清单

1. 止损单：入场成交后立即设置（触发价＝入场前写定的止损价）；
2. 止盈单：目标1（减50%）、目标2（减25%）两档；
3. 触发买入单：盘前设置，不在盘中临时下单；
4. 确认触发条件与有效期（注意部分券商条件单当日有效）。

## 附录D 风险与心理自检清单（17项）

**资金安全（5项）**
1. 我没有借钱炒股（无任何杠杆与借款入市）；
2. 我没有使用生活必需资金（房租/学费/养老/应急基金）；
3. 我的总仓位≤50%（新手期任何环境）；
4. 我的单票仓位≤15%（新手期；有经验后≤20%）；
5. 我的现金比例≥30%。

**止损纪律（4项）**
6. 我的每笔持仓都有止损价；
7. 我的止损位合理（入场逻辑失效位±1个ATR，宽度1-1.5个ATR，不在锚点价位上）；
8. 止损触发时我能立即执行、不犹豫；
9. 我从不盘中修改止损价。

**情绪管理（5项）**
10. 我的每笔交易都记录了情绪色标（三时点）；
11. 黄色及以上时我执行了暂停/不执行该笔；
12. 我每天开盘前完成心理预演（If-Then）；
13. 我入场后立即设置了条件单；
14. 连亏3笔时我强制暂停了1-3天。

**心态建设（3项）**
15. 我评估自己时看执行率，而不只看盈亏；
16. 无信号时我能空仓等待，不制造交易；
17. 追求完美买点卖点时，我会提醒自己"够好就行"。

用法：每周日逐项打勾；任何一项不达标，下周只设一个改进重点。

## 附录F 家庭财务与交易资金规划

### F.1 家庭资金四层结构

| 层级 | 内容 | 存放形式 |
|---|---|---|
| 第1层 应急基金 | 3-6个月生活费 | 货币基金/活期，随时可取 |
| 第2层 保险保障 | 医疗险/意外险/重疾险 | 保险，转移极端风险 |
| 第3层 投资资金 | 稳健增值 | 指数基金/债券/理财 |
| 第4层 交易资金 | 主动交易、可能亏光也不影响生活的钱 | 股票账户 |

顺序铁律：**先建满第1、2层，再谈第3、4层；交易资金永远只从第4层来**（对应第6章红线二）。

### F.2 可投资金额公式

```
可投资金额 = 总资产 - 应急基金 - 保险费用 - 未来1-2年大额支出
```

**例 5-F-1**：总资产50万-应急基金6万-保险预留1万-大额支出（购车/装修等）10万＝33万可投资金额。其中交易资金（第4层）＝33万×30%-40%＝约10-13万，其余放第3层低风险投资。

### F.3 交易资金分级管理

| 级别 | 比例 | 用途 | 风险 |
|---|---|---|---|
| 核心层 | 60%-70% | 指数基金/债券/理财 | 低风险 |
| 卫星层 | 30%-40% | 个股交易/行业轮动 | 中高风险 |
| 激进层 | <10% | 短线/期权等高风险操作 | 极高风险，新手不建议 |

### F.4 家庭交易协议模板（要点）

1. 可投资金额由家庭成员双方确认，数字写死；
2. 最大亏损容忍度：交易资金亏损达____%必须暂停（建议与清盘线20%一致）；
3. 单月亏损超过____元必须告知家人（建议=月收入×10%，与红线三一致）；
4. 不向家人隐瞒任何亏损——隐瞒是欺骗的开始，也是关系破裂的开始；
5. 家庭月亏损不超过家庭月收入的10%。
