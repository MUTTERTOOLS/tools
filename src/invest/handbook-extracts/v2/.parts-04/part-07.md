## 第六篇 长期实战——从"有系统"到"靠系统吃饭"

### 第19章 经典交易系统案例拆解

> **本章一句话**：拆解海龟、双均线、突破回踩三套经典系统的"逻辑骨架"，再看一个趋势系统失效的真实感案例——学逻辑，不照搬参数。
> **学习目标**：
> 1. 能完整复述海龟交易法的入场、仓位、止损、止盈、加仓规则；
> 2. 能说出双均线与突破回踩系统的完整规则链；
> 3. 能解释"趋势系统在震荡市失效"的机理与五步应对；
> 4. 能区分"可迁移的逻辑"与"必须本地化的参数"。

#### 19.1 海龟交易法：最著名的系统化交易案例

1983年，交易员理查德·丹尼斯（Richard Dennis）与威廉·埃克哈特（William Eckhardt）打赌"交易能力能否被教授"，公开招募并培训了一批普通人（"海龟"），给他们一套完全系统化的规则。结果证明：**交易可以被系统化教授**。

核心规则（原为期货市场，此处作逻辑演示）：

- **选股/选品种**：流动性好的品种；
- **入场**：20日突破——价格突破近20日最高价时做多；
- **仓位**：ATR法——波动大的少买、波动小的多买（每个"单位"承担相同波动风险）；
- **止损**：入场价 − 2 × ATR；
- **止盈/退出**：10日反向突破（跌破近10日最低价）退出；
- **加仓**：每盈利0.5 × ATR 加1个单位，最多4个单位（金字塔加仓）。

历史绩效与优缺点：1983-1988年海龟团队年化收益率约80%（历史公开报道口径，示意参考），但最大回撤超过30%。**优点**：逻辑清晰、完全系统化、长期正期望值。**缺点**：胜率低（约35%-40%，示意校准），需要极大心理承受力——**连续亏损7-10笔是常态**；震荡市中表现差（频繁假突破）。

A股本土化的经验（以沪深300成分股回测的普遍结论）：在2007、2015等大趋势年份表现优异，但在2016-2018震荡市中频繁假突破，年化收益仅3%-5%（示意校准，需自行回测验证）。**海龟系统在A股趋势市有效，震荡市水土不服**——这正是第20章多系统并行的动机。

#### 19.2 双均线交叉系统：最简单的趋势跟踪

- **入场**：短期均线（5日）上穿长期均线（20日）时做多（金叉）；
- **出场**：短期均线下穿长期均线时平仓（死叉）；
- **止损**：入场价 − 3% 或死叉退出（先到先执行）；
- **仓位**：固定分数法（第6章）。

**优点**：极简、新手友好、规则零歧义。**缺点**：均线本身滞后，信号慢半拍；震荡市频繁假信号（金叉后很快死叉，来回打脸）。适合趋势明显的行情，常作为新手的第一套"练手系统"——它的价值不在赚钱效率，而在训练完整的闭环流程。

#### 19.3 突破回踩系统：中线波段经典

- **选股**：趋势向上 + 箱体整理 >15个交易日；
- **入场**：突破箱体上沿 → 缩量回踩箱体上沿 → 放量收阳时入场（对应第5章突破入场的稳健变体："不追突破，等回踩"）；
- **止损**：箱体中轨下方（加1个ATR余量）；
- **止盈**：目标1 = 突破幅度 × 1，目标2 = 突破幅度 × 1.5。

这套系统是第8章瑞景食品案例的结构原型——回踩关键位 + 收盘确认 + 分批止盈，适合每天只有30分钟的上班族。

#### 19.4 失败案例：2019-2021的趋势系统在2022-2024失效

一套"均线金叉 + 放量突破 + ATR止损"的趋势跟踪系统（示例校准数据）：

- **2019-2021（核心资产牛市）**：年化约25%、胜率48%、盈亏比2.8:1 → 期望值 = 48%×2.8 − 52%×1 = **+0.82R**，表现优异；
- **2022-2024（长期震荡+外部冲击）**：趋势信号频繁假突破，胜率降至28%、盈亏比降至1.2:1 → 期望值 = 28%×1.2 − 72%×1 = **−0.38R**，转负。

原因：趋势系统在趋势市赚钱、在震荡市亏钱，**这是系统本质决定的，不是参数问题**——把20日改成15日或30日，改变不了"震荡市没有趋势可追"的事实。

五步应对（与第16-17章流程一致）：①识别市场状态变化（趋势 → 震荡）→ ②降低仓位 → ③暂停系统 → ④评估切换到均值回归/区间类系统 → ⑤新系统完整验证（回测+模拟+小仓位）后过渡切换，过渡期1-2个月。

#### 19.5 从经典系统中学习的正确姿势

**学逻辑，不照搬参数。**海龟的20日突破在A股可能需要改成15日或30日，参数必须匹配你的市场、你的风格、你的资金量；但"趋势突破 + ATR仓位 + 金字塔加仓"的**逻辑框架**是通用的。拆解任何经典系统时问三个问题：它赚的是什么钱（趋势/震荡/估值回归）？它必然在哪里亏钱？它的仓位与退出规则如何控制风险？

**要点小结**
- 海龟：20日突破入场、ATR仓位、−2ATR止损、10日反向退出、0.5ATR步进加仓；胜率35%-40%，连亏7-10笔是常态。
- 双均线：极简但滞后，震荡市频繁打脸；适合新手练闭环。
- 突破回踩：箱体>15天、等回踩、中轨下止损、1倍/1.5倍箱体高度分批止盈。
- 趋势系统震荡市失效是本质使然，不是参数问题；应对五步：识别→降仓→暂停→评估切换→验证后过渡。
- 学逻辑不抄参数；先问它"必然在哪里亏钱"。

**行动判据（If-Then）**
- 如果想直接照搬某经典系统的参数 → 那么先在自己的市场与标的上回测50笔以上再决定。
- 如果你的趋势系统连续在震荡市亏损且滚动期望值转负 → 那么按五步应对处理，不要只调参数。
- 如果你接受不了30%级别的回撤 → 那么不选择趋势跟踪类系统，改选中线波段或价值类。

**本章练习**
1. 任选本章三套系统之一，按一页纸模板写出它的完整规则（含仓位与出场），标注哪几条你认为需要在A股本地化。
2. 用沪深300指数2019-2021与2022-2024两段行情，肉眼观察"20日突破"信号的密度与成功率差异，体会市场状态对趋势系统的影响。

### 第20章 多系统并行——从单一系统到投资组合化

> **本章一句话**：单一系统只适应一种市场状态，多系统并行是为了分散"市场状态风险"——但一个交易者最多同时运行两套，且第一套不满300笔不考虑第二套。
> **学习目标**：
> 1. 能说出多系统并行的三个互补维度；
> 2. 能按市场状态给出系统间资金分配方案；
> 3. 能解释"交易者→系统管理者"的角色转变意味着什么。

#### 20.1 为什么要多系统

单一系统只适应一种市场状态：趋势系统在震荡市失效，震荡系统在趋势市跑输。**多系统并行 = 分散市场状态风险**——趋势系统与震荡系统同时运行，无论市场处于什么状态，总有一套在正常工作。这与资产组合分散"个股风险"是同一个思想，只不过分散的对象从股票换成了"策略"。

#### 20.2 组合逻辑：三个互补维度

1. **风格互补**：趋势跟踪 + 均值回归 → 趋势市赚前者、震荡市赚后者；
2. **周期互补**：短线（2-10天）+ 中线（2-8周）→ 不同节奏的信号互不干扰；
3. **市场状态覆盖**：趋势市强势系统 + 震荡/弱市防御系统 → 全天候覆盖。

#### 20.3 系统间资金分配（按历史绩效与当前市场状态）

**表 4-20-1｜两系统资金分配示意**

| 当前市场状态 | 趋势系统 | 震荡系统 |
|---|---|---|
| 趋势市 | 70% | 30% |
| 震荡市 | 30% | 70% |
| 不确定 | 50% | 50% |

注意：这里的百分比是**两套系统之间的资金配额**，分配后每套系统内部仍须遵守全部风控口径——单票≤20%（新手≤15%）、单板块≤20%、现金≥30%、单笔风险≤2%（新手1%）、总仓位按大盘三态封顶。多系统不是放宽风控的理由。

#### 20.4 管理复杂度与数量上限

多系统的风险不是"系统冲突"，而是**管理不过来**：每套系统都需要独立的选股、入场、出场、复盘，两套系统的工作量不止两倍（还有切换判断与资金调配）。因此统一口径：**最多同时运行两套系统**。前提条件：

1. 第一套系统实盘满300笔、季度评估健康；
2. 两套系统的执行率都能保持≥85%；
3. 你每天可支配的交易时间翻倍后仍有余量。

任何一条不满足，就先只做一套。

#### 20.5 从"交易者"到"系统管理者"

运行两套以上系统时，你的角色发生变化：不再执着于每一笔交易的输赢，而是管理系统的运行状态、资金分配与定期评估——像一个管理两条产线的厂长。这是一个重要的认知跃迁：**关注的对象从"这笔单"上升为"这套系统"，再上升为"这组系统"**。第21章的长期盈利公式，在这个层面上展开。

**要点小结**
- 多系统分散的是"市场状态风险"，不是个股风险。
- 三个互补维度：风格、周期、市场状态覆盖。
- 分配随状态：趋势市70/30、震荡市30/70、不确定50/50；风控口径不因多系统放宽。
- 最多两套；第一套不满300笔不考虑第二套。
- 角色从交易者升级为系统管理者。

**行动判据（If-Then）**
- 如果第一套系统运行不满300笔 → 那么不考虑第二套。
- 如果想同时运行超过2套系统 → 那么拒绝自己（管理不过来 = 每套执行率都下降）。
- 如果市场状态从趋势转入震荡 → 那么按表4-20-1把配额向震荡系统倾斜，而不是关掉趋势系统。
- 如果两套系统的执行率都跌破85% → 那么暂停弱势的一套，先保执行质量。

**本章练习**
1. 假设你已有一套中线波段系统，设计一套与之互补的第二系统草案：写出它的风格类型、互补维度与资金分配规则。
2. 估算运行两套系统的每日时间开销（选股/盯盘/复盘各多少分钟），对照你的可用时间判断是否现实。

### 第21章 长期盈利的终极秘密

> **本章一句话**：长期盈利 = 正期望值系统 + 严格执行 + 足够时间，三者缺一不可；从100笔到10000笔的四个里程碑，是每个系统化交易者必经的路。
> **学习目标**：
> 1. 能解释长期盈利公式三要素各自的不可替代理由；
> 2. 能说出"系统代替意志力"的两个硬件手段；
> 3. 能复述八轮学习路径与四个里程碑的含义。

#### 21.1 长期盈利公式

> **长期盈利 = 正期望值系统 + 严格执行 + 足够时间**

三者缺一不可：

1. **正期望值系统**：扣除交易成本后，胜率×平均盈利 − 败率×平均亏损 > 0。没有它，执行得再好也是确定亏损——只是亏得更整齐；
2. **严格执行**：执行率≥85%（底线80%）。正期望值系统 + 0%执行率 = 确定亏损；
3. **足够时间**：概率需要大样本才能显现——100笔初步判断，300笔可靠结论。短期亏损不代表系统无效，短期盈利也不代表系统有效。

#### 21.2 为什么大多数人知道却做不到

知道"该止损"和"真的止损"之间，隔着一个杏仁核——约0.3秒的恐惧反应就能让你放弃规则。这就是为什么必须**用系统代替意志力**：

- 条件单自动止损（把止损交给硬件，不给犹豫留时间）；
- 连亏阶梯自动暂停（3笔减半、5笔停1-3天，规则先行于情绪）；
- 盘后修改规则纪律（盘中永远不改规则）。

把规则写进"硬件"，不依赖"软件"（意志力）——意志力是会耗尽的资源，规则不会。

#### 21.3 生存优先于盈利

"第一条规则：不要亏钱；第二条规则：记住第一条。"系统化交易的终极价值不是让你赚多少，而是**让你在市场上活着**——活着才有机会等到属于你的概率兑现。死扛不止损的人可能在牛市赚很多，但一次大熊市就可能清零；系统保证你的任何单笔、单日、单周、单月亏损都被限制在预设范围内（分层风控详见《风险管理与交易心理》第三篇）。

#### 21.4 向市场学习的具体方法

市场是活的，系统也要是活的。方法是固定的四步循环：**观察 → 记录 → 验证 → 纳入或排除**。

- 例1："最近总有资金尾盘拉升" → 观察记录10次 → 验证出现频率与次日表现是否可量化 → 若稳定有效，纳入入场/出场条件；否则排除；
- 例2："某板块龙头总是先于板块启动" → 观察 → 验证 → 若成立，纳入选股规则（观察池排序）。

迭代必须有纪律：每次只改一个变量，改后走完整验证流程（第17章）。

| 100笔 | 建立统计基础 | 初步判断系统的胜率/盈亏比特征；完成模拟+小仓位毕业 |
| 300笔 | 形成可靠结论 | 开始单变量参数微调；可评估第二套系统 |
| 1000笔 | 系统成熟 | 多系统并行；资金与角色的管理者化 |
| 10000笔 | 直觉与系统融合 | "从心所欲不逾矩"——直觉在规则边界内工作 |

#### 21.7 写给系统化交易者的最后一封信

交易系统不是终点，是起点。系统会迭代、会进化、甚至会失效——但**"系统化思维"本身永远不会过时**。当你学会用系统的方式思考交易，你就从"在市场上碰运气的人"变成"在市场上管理概率的人"。前者祈祷行情，后者经营规则；前者被市场筛选，后者与市场共处。

愿你走得慢，但走得远。

**要点小结**
- 长期盈利公式三要素缺一不可；100笔初步判断、300笔可靠结论。
- 用系统代替意志力：条件单、连亏阶梯、盘后改规则。
- 生存优先于盈利；分层风控保证亏损永远可控。
- 向市场学习四步：观察→记录→验证→纳入或排除。
- 八轮路径不可跳轮不可并行；四里程碑100/300/1000/10000笔。

**行动判据（If-Then）**
- 如果连续亏损让你怀疑系统 → 那么先看滚动期望值与执行率，数据说话，不看情绪。
- 如果发现自己靠"咬牙"执行规则 → 那么把该规则改造成硬件（条件单/自动暂停）。
- 如果累计交易未满100笔 → 那么不做任何"系统好不好"的结论性判断。
- 如果完成本册学习 → 那么按八轮路径进入第5册，然后以第8章八步计划开始轮次8。

**本章练习**
1. 写下你的长期盈利三要素现状自评：系统期望值（回测/实盘）、当前执行率、已积累笔数，并写出最短的一块短板与补法。
2. 建立"市场观察笔记"：本周记录1个你观察到的市场现象，注明需要观察多少次才进入验证环节。
