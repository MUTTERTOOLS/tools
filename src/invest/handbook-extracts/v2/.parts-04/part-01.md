## 第一篇 系统思维——从随机交易到系统化交易

### 第1章 为什么你需要一套交易系统

> **本章一句话**：散户亏损的终极原因不是看不懂K线，而是没有系统——把每一次交易从"即兴发挥"变成"照单施工"，是长期存活的前提。
> **学习目标**：
> 1. 能说出随机交易与系统交易在决策依据、亏损后反应、可改进性上的三点本质区别；
> 2. 能复述交易系统的定义（买什么、何时买、买多少、何时卖、错了怎么办）；
> 3. 能用"可执行、可回测、可迭代"三标准检验一套规则是否算系统。

#### 1.1 散户亏损的终极原因：不是技术，是结构

很多新人把亏损归咎于"技术没学好"：K线看得不够准、指标用得不够熟。但观察足够多的账户就会发现，真正的问题是**结构性**的——知识是散的，操作是随机的，每次交易的决策路径都不一样：今天靠均线，明天听消息，后天看财报。

这就像一个厨师从不用菜谱、不记用量、不做总结：同一道菜，这次咸了下次淡了，他永远无法复制成功，也无法定位失败。随机交易的本质，就是**每一次决策都是即兴发挥**。

由此产生一个致命错觉："我懂技术分析/基本面/宏观，所以我能赚钱。"这是散户最大的错觉之一。**知识不等于系统，散装知识不闭环等于没学。**更残酷的等式是：

**正期望值系统 + 0%执行率 = 确定亏损。**

哪怕你找到了一套理论上能赚钱的规则，只要执行不出来，结果仍然是零。

#### 1.2 随机交易 vs 系统交易：三个维度的本质区别

**表 4-1-1｜随机交易与系统交易对比**

| 维度 | 随机交易 | 系统交易 |
|---|---|---|
| 决策依据 | 感觉、消息、灵感，每次不同 | 规则清单，逐项核对 |
| 买入后行为 | 买了再想什么时候卖 | 买入前已写好出场规则 |
| 亏损后反应 | 情绪化加仓摊平、报复性交易、或恐慌割肉 | 止损触发 → 执行 → 复盘 → 不改规则 |
| 长期结果 | 不确定，靠运气 | 确定的可控范围，靠概率 |
| 可改进性 | 无法改进（没有记录，无从总结） | 可迭代：记录 → 复盘 → 优化 |

注意最后一行：可改进性。随机交易者的每一笔亏损都白亏了——没有记录就没有复盘，没有复盘就不可能改进。系统交易者的亏损则是"学费"，因为每一笔都被记录、被归因、被用于改进。

#### 1.3 交易系统是什么：把"艺术"变成"工程"

**交易系统（Trading System）**：一套完整定义了"买什么、何时买、买多少、何时卖、错了怎么办"的规则集。五个问题缺一不可，其中"错了怎么办"是最容易被新手忽略、却最能决定生死的一条。

换个说法：把工程思维应用到交易。盖楼的流程是图纸 → 施工 → 质检 → 验收 → 维护，每一步有标准、可追溯、可改进。**你的交易应该是施工，不是创作。**创作追求灵感，施工追求可重复；灵感不可复制，规则可以。

#### 1.4 好系统的三个标准

1. **可执行**：规则清晰无歧义。"均线金叉时买入"优于"趋势好的时候买入"——前者可以明确判断（5日均线上穿20日均线），后者每个人理解不同。判据：把规则交给另一个按字面执行的人，他的操作应和你一致。
2. **可回测**：能用历史数据验证过去的表现。一条无法用历史数据检验的规则（如"感觉市场情绪好转时买入"）不是系统规则，是心情描述。
3. **可迭代**：发现缺陷可以修改，修改后有验证流程（回测 → 模拟 → 小仓位），不会越改越乱。

#### 1.5 系统不能保证盈利，但能保证"可控"

必须说清楚：**没有任何系统能保证盈利。**市场的本质是概率，任何系统都会有亏损期。系统的价值在于"可控"：

- 亏了，知道是哪个环节出了问题——入场条件太松？止损太紧？仓位太大？可以针对性改进；
- 不会出现"一次失误、全盘清零"的极端情况，因为单笔风险、总仓位都有上限（详见《风险管理与交易心理》第6章与本册第6章）；
- 你始终知道自己在哪、该往哪走、走错了怎么纠偏——就像导航，它不能保证不堵车，但保证你不会迷路。

**可控 = 可改进 = 长期可盈利。**这是本册全部内容的逻辑起点。

**要点小结**
- 散户亏损的终极原因是结构问题（无系统），不是技术问题。
- 随机交易五维全面落后于系统交易，其中"可改进性"是分水岭。
- 交易系统 = 买什么、何时买、买多少、何时卖、错了怎么办的完整规则集。
- 好系统三标准：可执行、可回测、可迭代。
- 系统不保证盈利，但保证可控；正期望值系统 + 0%执行率 = 确定亏损。

**行动判据（If-Then）**
- 如果决策时没有对照规则清单 → 那么停止交易，先回到系统文档。
- 如果发现自己在"凭感觉"操作 → 那么退出交易软件，重读系统规则。
- 如果亏损后第一反应是"我要赚回来" → 那么立即暂停交易至少1天（这是报复性交易的危险信号，详见《风险管理与交易心理》第13章）。

**本章练习**
1. 回顾你最近5笔交易（无论模拟还是实盘），逐笔写下当时的决策依据，统计其中几笔能对应到明确规则。若少于3笔，说明你目前处于随机交易状态。
2. 用"可执行、可回测、可迭代"三标准，检验你现在正在使用的任何一条"规则"，写出它不合格的地方。

### 第2章 交易系统全景地图：六组件闭环

> **本章一句话**：完整交易系统由"定位、选股、入场、仓位、出场、复盘"六大组件构成闭环，缺一环就是漏水的桶；交易成本是从桶底悄悄漏走的第一桶水。
> **学习目标**：
> 1. 能按顺序说出六大组件及每个组件回答的问题；
> 2. 能识别三种最常见的"断环"并说明后果；
> 3. 能按最新标准计算一次往返的交易成本（佣金、印花税、过户费、滑点）。

#### 2.1 自驾游比喻：一次完整的旅行

把建立交易系统想象成计划一次自驾游：

- 选择车型 = **自我定位**（我是什么类型的交易者？轿车跑高速，越野车走山路，选错车型全程难受）；
- 选择目的地 = **选股规则**（买什么）；
- 选路线、定出发时机 = **入场规则**（何时买）；
- 控制油门 = **仓位规则**（买多少，油门踩到底=满仓，弯道也全速=重仓追高）；
- 刹车与停车 = **出场规则**（何时卖，没有刹车的车不能上路）；
- 保养维修 = **复盘规则**（系统跑了一段时间，好不好？哪里该修？）。

缺任何一环，自驾游都会出问题。交易也一样。

#### 2.2 六大组件与闭环

**闭环（Closed Loop）**的定义：**执行 → 记录 → 复盘 → 优化 → 再执行**。这是系统化交易的生命线。优化时只修改有缺陷的规则，且每次只改一个变量（第17章展开）。

三种最常见的"断环"：

1. **断环1：只有买入没有卖出规则。**买了再说，跌了不知道怎么办——这是新手账户的第一死因。
2. **断环2：只有规则没有复盘机制。**从不检查系统是否有效，规则好不好全凭印象。
3. **断环3：有复盘但不改规则。**复盘变成自我批评大会，情绪发泄完了，系统原封不动。

不闭环的系统 = 漏水的桶，水（利润）从缺口流走。

#### 2.3 核心术语速释

这些术语将贯穿全书，此处先给一句话定义，第10章详细展开：

- **期望值（Expectancy）** = 胜率 × 平均盈利 − 败率 × 平均亏损；每笔交易平均能赚（或亏）多少。
- **盈亏比（Risk-Reward Ratio）** = 平均盈利 ÷ 平均亏损；系统要求 ≥2:1 才入场。
- **R倍数（R Multiple）**：以初始风险R为单位衡量盈亏。盈利2R = 赚了2倍初始风险。
- **利润因子（Profit Factor）** = 总盈利 ÷ 总亏损；>1.5 可用，>2.0 优秀。
- **最大回撤（Maximum Drawdown）**：资金曲线从峰值到谷底的最大跌幅。
- **回测（Backtest）**：用历史数据模拟系统的过去表现。
- **曲线拟合（Curve Fitting，过拟合）**：参数被过度优化以迎合历史数据，样本外或实盘表现通常显著衰减。
- **ATR（Average True Range，平均真实波幅）**：衡量股票波动率的指标，用于止损与仓位设计。

#### 2.4 交易成本：被忽视的利润杀手

交易成本由四部分构成，按现行标准（2023年8月28日起印花税减半后）：

**表 4-2-1｜A股交易成本构成（现行标准）**

| 成本项 | 标准 | 收取方式 |
|---|---|---|
| 佣金 | 约万2.5（0.025%） | 买卖双向 |
| 印花税 | 0.05% | 卖出单边（2023年8月28日起由0.1%减半） |
| 过户费 | 0.001% | 买卖双向 |
| 滑点 | 约0.1%-0.3% | 隐性成本，下单价与实际成交价之差 |

**例 4-2-1｜10万元全仓单次往返成本**：
- 佣金：100000 × 0.025% × 2 = 50元
- 印花税：100000 × 0.05% = 50元
- 过户费：100000 × 0.001% × 2 = 2元
- 不含滑点合计 ≈ 102元（占往返金额约0.102%）
- 加滑点（按0.15%-0.3%计，150-300元）→ **合计约250-400元**，占10万元资金约0.25%-0.40%。

**成本敏感性**：10万元资金，每月交易10次全仓（按全仓往返口径计算成本率，单次往返约0.25%-0.40%；每月累计往返金额约等于一次全仓，即单笔平均持仓约一成），若滑点控制在0.1%-0.15%，月成本约200-250元，**年成本约占资金的2%-3%**；若滑点放大到0.3%，年成本将升至约4%-5%。若年化收益预期为10%，仅此一项就吃掉两到五成的利润——**减少交易频率 = 直接增加利润**，这是最简单的提高收益的方法。更极端的情形：如果每月10次都是真·全仓往返（年往返金额约1200万元），年成本高达资金的30%-48%，任何系统都无法承受——这就是"过度交易是利润头号杀手"的数学依据。

**要点小结**
- 六大组件：定位 → 选股 → 入场 → 仓位 → 出场 → 复盘，缺一环即不闭环。
- 闭环 = 执行 → 记录 → 复盘 → 优化 → 再执行；三种断环各有死法。
- 期望值、盈亏比、R倍数、利润因子、最大回撤是评估系统的五大核心指标。
- 现行往返成本（含滑点）约占往返金额的0.25%-0.40%；频率越高，成本侵蚀越狠。

**行动判据（If-Then）**
- 如果设计系统时发现六大组件缺一 → 那么先补上再谈其他；没有复盘机制就先停下，设计复盘规则。
- 如果计算期望值时未扣除交易成本 → 那么重新计算；名义期望值为正但扣成本后为负的系统不可行。
- 如果每月交易超过10次 → 那么先核算年成本占资金比例，再问自己：这些交易是系统信号，还是手痒？
