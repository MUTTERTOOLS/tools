## 第三篇 系统组装与验证——从散件到闭环

### 第8章 组装完整交易系统——一页纸模板、八步全链路计划与瑞景食品案例

> **本章一句话**：把六大组件串成一条决策链，装进"一页纸系统 + 八步全链路交易计划"两个模板，并用"瑞景食品"案例从零走到一笔完整交易的每一个数字。
> **学习目标**：
> 1. 能复述六大组件的串联顺序与输入输出关系；
> 2. 能默写一页纸交易计划模板与八步全链路模板的字段，并说出每一步调用哪一册的方法；
> 3. 能独立完成一次"实际仓位 = min(风险反推仓位, 上限约束仓位)"的完整计算；
> 4. 能用八步模板为自己的自选池股票写一份完整交易计划。

本章是全系列的枢纽章：八步全链路交易计划在此定义，其余四册引用时统一称"八步全链路交易计划"（定义出处即本章）。请务必动手填写，至少完成一次端到端练习。

#### 8.1 六大组件如何串联成决策链

六个组件不是并列的清单，而是一条流水线——**每个环节的输出是下一个环节的输入**：

```
定位（我是什么风格）
  → 选股（在这个风格下买什么）
    → 入场（候选股何时满足信号）
      → 仓位（这笔允许亏多少 → 反推买多少）
        → 出场（止损位其实先于仓位算出，因为公式分母依赖它）
          → 复盘（结果回流，修正上面每一个环节）
```

特别注意箭头上的隐藏依赖：**仓位计算的分母是"入场价−止损价"，所以出场规则（止损位）必须在仓位之前确定**。串联一次，你就明白为什么"先想好怎么卖，再决定买多少"。

#### 8.2 标准交易计划模板（一页纸版本）

开仓前必须填完以下字段，任何一项空白 = 不许下单：

- 交易标的：____（代码+名称）
- 交易方向：做多（A股现货仅能做多）
- 入场条件：①____ ②____ ③____ ④____（全部满足才入场）
- 入场价：____元
- 止损价：____元（理由：____失效位 + ATR余量）
- 目标价1：____元（盈亏比____:1 → 减仓50%）
- 目标价2：____元（→ 再减仓25%）
- 移动止盈规则：剩余25%仓位，每涨____% 止损上移____%
- 仓位：____股 / ____元 / 占总资金____%
- 大盘环境：多头 / 震荡 / 空头 → 允许 / 不允许开仓
- 时间止损：持有____个交易日未达目标1 → 重新评估

**系统的"一页纸"原则**：好系统应该能写在一页纸上。如果你写了10页，只有两种可能：要么条件太多（堆砌指标，见第18章误区1），要么规则太模糊（"适当买入"不是规则）。一页纸 = 规则精简到无冗余 = 可执行。

#### 8.3 八步全链路交易计划模板（全系列主线工具）

在"一页纸计划"之上，八步模板把宏观、指数、板块、基本面全部纳入，形成从环境到执行的完整链条。每一步标注调用哪一册哪一章：

| 步骤 | 内容 | 调用来源 |
|---|---|---|
| ① 宏观环境 | 当前经济周期阶段、是否支持权益、总仓位上限参考 | 《宏观经济分析》第21章 五步法 |
| ② 指数结构 | 沪深300与20日均线关系 → 大盘三态（多头/震荡/空头） | 《裸K与价格行为》第25章 指数PA |
| ③ 板块筛选 | 当前周期与资金面利好的板块 | 《宏观经济分析》第18章 行业轮动 |
| ④ 基本面排雷 | 十项排雷清单 + 五个一票否决 + 估值位置 | 《财报与基本面》第18章、第23章 |
| ⑤ PA入场信号 | 势位形三步决策：趋势、关键位、信号形态与分级 | 《裸K与价格行为》第11-12章 |
| ⑥ 仓位计算 | 单笔风险法：股数 = 风险金额 ÷ 每股风险，取min(风险反推, 上限约束) | 本册第6章 |
| ⑦ 出场规则 | 止损、目标1、目标2、移动止盈、时间止损 | 本册第7章 |
| ⑧ 复盘准备 | 交易日志15字段预填 + 盘前心理预演 | 本册第13章；《风险管理与交易心理》第16章 |

使用纪律：**每笔交易逐一填写八步，跳步 = 系统断环 = 漏水。**新手可把①③做成月度更新（宏观与板块变化慢），②⑤⑥⑦每笔更新，但表格必须每笔完整呈现。

#### 8.4 全链路填写示范——"瑞景食品"端到端案例

以下为虚构案例，全部数字为示例数据，用于演示完整流程，不构成任何投资建议。

**背景**：2025年三季度，投资者小王，总资金20万元，已完成八轮学习中的前四轮，处于小仓位实盘阶段，单笔风险预算按1.5%（其自我定位表允许值，未超过2%铁律）。

**第①步 宏观环境（调用《宏观经济分析》第21章五步法）**：
- PMI 50.3，位于荣枯线上方且连续2个月回升（>50扩张区间）；
- CPI 2.1%，处于2%-3%的友好区间；
- M2同比+8.5%，社融存量同比增速企稳回升，货币环境偏宽松；
- 美林时钟定位：**复苏期 → 利好股票**；
- 结论：宏观支持权益配置，信号灯体系绿灯偏多，仓位可中等偏上（具体上限仍由第②步的指数结构决定）。

**第②步 指数结构（调用《裸K与价格行为》第25章指数PA）**：
- 沪深300日线处于上升趋势：高点抬高（HH）、低点抬高（HL），回踩20日均线后收回均线上方，20日均线上行；
- 判定：**多头** → 总仓位上限 ≤80%，全部入场规则可用。

**第③步 板块筛选（调用《宏观经济分析》第18章行业轮动）**：
- 复苏期历史规律利好可选消费与必选消费；
- 近5个交易日消费板块资金净流入为正，板块指数强于沪深300；
- 结论：把选股漏斗对准消费板块（同时检查单板块 ≤20% 约束）。

**第④步 基本面排雷（调用《财报与基本面》第18章、第23章）**：
- 瑞景食品：ROE 18%（行业均值12%）、毛利率42%、净现比1.1（>0.8健康）、资产负债率35%；
- 十项排雷清单逐项通过，无一票否决项；大股东无质押，近三年业绩承诺兑现率100%；
- 估值：PE 22倍，处于近5年PE百分位约25%（偏低区域）；PEG = 0.8（<1）；
- 结论：排雷通过，估值不贵，进入技术面选时。

**第⑤步 PA入场信号（调用《裸K与价格行为》第11-12章势位形）**：
- 势：日线上升趋势，周线均线多头排列，月线自底部回升（多周期共振）；
- 位：价格回踩前期筹码密集区上沿（支撑区域约28.5元），该位置距前高空间充足；
- 形：支撑位出现Pin Bar长下影线拒绝下破，次日收盘确认；
- **入场触发条件 = 放量突破Pin Bar高点，触发价28.8元**（当日量比≥1.5）。

**第⑥步 仓位计算（本册第6章）**——这是本案例的关键一步，完整展示"上限约束"：

1. 风险预算：20万 × 1.5% = **3000元**；
2. 每股风险：入场价28.8 − 止损价27.5 = **1.3元**；
3. 风险反推股数：3000 ÷ 1.3 ≈ **2300股**，对应金额 ≈ 66240元，占总资金 ≈ **33%**；
4. 上限检查：33% > 单票上限20%，**触发约束**；
5. 上限约束仓位：20万 × 20% = 40000元，40000 ÷ 28.8 ≈ 1388股，按100股整数倍取整 = **1300股**，金额37440元，占总资金 **18.7%**；
6. **实际仓位 = min(33%, 18.7%) = 18.7%（1300股）**；
7. 实际单笔风险 = 1300 × 1.3 = **1690元 ≈ 0.85%** < 1.5%预算。

**上限约束让实际风险低于风险预算，这是安全的方向。**风险预算回答"最多亏多少"，上限约束只会让它更小，永远不会放大风险。本例若没有20%上限，2300股会在止损时亏掉3000元；有了上限，最坏亏损锁定在1690元。

同时检查并行约束：现有持仓约45%，45% + 18.7% = 63.7% < 多头上限80%，通过；消费板块合计占比未超20%，通过；现金剩余约36% ≥ 30%，通过。

**第⑦步 出场规则（本册第7章）**：
- 止损价：27.5元（筹码密集区下沿失效位，且非整数锚点价；止损亏损 = 1300 × 1.3 = 1690元，约占总资金0.85%）；
- 目标1：33元（前期高点，每股盈利4.2元，**盈亏比 = 4.2 ÷ 1.3 ≈ 3.2:1** ≥ 2:1）→ 到达后减仓50%（650股，落袋盈利 = 650 × 4.2 = **2730元**，并将止损上移至29元，保本+微利）；
- 目标2：36元（箱体高度测量目标位，每股盈利7.2元 ≈ 5.5R）→ 再减仓25%（325股，落袋盈利 = 325 × 7.2 = **2340元**，止损上移至32元）；
- 剩余25%（325股）执行移动止盈；
- 时间止损：持有15个交易日未达目标1 → 重新评估持仓逻辑。

**第⑧步 复盘准备（本册第13章 + 风控手册第16章）**：
- 交易日志15字段预填前7项（日期、标的、方向、入场价、止损价、目标价、仓位）；
- 盘前心理预演：想象止损触发时的动作——"27.5元到了就卖，1690元是我预付的保费"；
- 盈亏结构一览（全部可手工验算）：

#### 8.5 三套案例对比：同一模板，三种填法

同一个八步模板，因定位不同而参数迥异。以下三套均为虚构示例，用于说明"系统必须匹配定位"：

**表 4-8-1｜三套系统案例对比（示例）**

| 要素 | 上班族·中线波段 | 全职·短线波段 | 价值投资者 |
|---|---|---|---|
| 资金/时间 | 10万；每日30分钟 | 30万；全职盯盘 | 50万；每周1-2小时 |
| 选股范围 | 沪深300成分 + 消费/医药 | 全市场 + 主线赛道 | ROE>15% + 高分红 + 低PE |
| 入场模式 | 均线回踩 + 放量收阳确认 | 突破 + 量能 + 板块配合 | 估值百分位<30% + 基本面拐点 |
| 单笔风险 | 1.5%，持3-5只 | 1%，持2-3只 | 2%，持5-8只 |
| 止损方式 | 8%或技术位止损 | 3%或2×ATR | 15%或基本面证伪 |
| 止盈方式 | 目标1减50% + 移动止盈 | 目标1减60%，快速止盈 | 估值百分位>70%减仓 |
| 持仓周期 | 2-8周 | 2-10天 | 3-12个月 |

观察要点：短线系统用更小的单笔风险对冲更高的频率与滑点；价值系统用更宽的止损换取更长的持仓周期。参数没有对错，只有匹配与否——把全职短线那行直接抄给上班族，就是第3章说的"系统崩盘第一大原因"。

**要点小结**
- 组件串联是流水线：定位→选股→入场→（出场止损）→仓位→复盘；止损位先于仓位确定。
- 一页纸计划模板11个字段，空白即不下单；一页纸原则 = 精简到无冗余。
- 八步全链路：①宏观（宏观手册第21章）②指数结构（裸K手册第25章）③板块（宏观手册第18章）④排雷（财报手册第18/23章）⑤PA信号（裸K手册第11-12章）⑥仓位（本册第6章）⑦出场（本册第7章）⑧复盘准备（本册第13章+风控手册第16章）。
- 实际仓位 = min(风险反推, 上限约束)；上限约束方向永远安全。
- 瑞景食品案例：1300股、18.7%、止损亏1690元（0.85%）、目标1减50%落袋2730元、盈亏比3.2:1。

**行动判据（If-Then）**
- 如果交易计划单有任何字段空白 → 那么不下单，补齐后再评估。
- 如果风险反推仓位超过上限 → 那么按上限买入，记录实际风险低于预算。
- 如果想跳过八步中的某一步（如"宏观太麻烦不看了"）→ 那么记住跳步 = 断环，宁可不做这笔。
- 如果八步中第①③步超过一个月未更新 → 那么本周末更新后再开新仓。

**本章练习**
1. 用附录A的交易计划单模板，为你的自选池中一只股票填写完整一页纸计划（可以暂不执行）。
2. 重算瑞景食品案例：若止损改为27.0元（每股风险1.8元），风险反推股数与上限约束结果各是多少？实际风险多少？（答案：反推约1666股≈4.8万元占24%，仍超20%上限；上限下仍为1300股，实际风险1300×1.8=2340元≈1.17%。）

### 第9章 回测——用历史数据验证系统

> **本章一句话**：回测不能保证实盘赚钱，但回测差一定说明系统有缺陷——用手动翻图法先跑50笔，把明显不行的系统挡在实盘门外。
> **学习目标**：
> 1. 能独立完成手动翻图回测的五步流程；
> 2. 能说出五项回测核心指标的健康值与警告值；
> 3. 能识别曲线拟合（过拟合）并用样本外测试检验；
> 4. 能正确解读"实盘通常为回测的60%-80%"的含义。

#### 9.1 为什么要回测

不经验证就上实盘的系统 = 未经测试就起飞的飞机。**回测不是万能的，但"回测差 = 系统有缺陷"是确定的**：如果一套规则在历史数据（没有滑点、没有情绪、完美执行）上都不赚钱，实盘只会更差。

回测的三个作用：①过滤掉明显负期望值的规则；②让你在实盘前就见过系统的连亏期长什么样（心理建设）；③为第10章的评估指标提供第一组数据。

#### 9.2 手动翻图回测五步法（新手不需要昂贵软件）

1. **选标的与区间**：选一只流动性好的股票（最好是你自选池里的），时间跨度2-3年，覆盖至少一段上涨、一段下跌、一段震荡；
2. **逐日浏览**：打开K线图从左到右浏览，模拟时间流逝——只看"今天及之前"，不许偷看右边；
3. **记录信号**：每次入场条件全部满足时，记录入场价、止损价、目标价；
4. **推演结果**：继续往右翻，看这笔交易先触及止损还是先触及目标，记录出场价与盈亏；
5. **统计汇总**：累计50笔后，统计胜率、盈亏比、期望值（公式见第10章）。

手动回测的核心价值是**建立直觉**：你会亲眼看到哪些条件经常产生假信号、哪些过滤条件最有效、连亏6笔时资金曲线是什么样子——这是自动回测软件给不了的体验。

#### 9.3 回测核心指标与健康值（全系列统一口径）

**表 4-9-1｜回测指标健康值对照**

| 指标 | 计算 | 健康 | 警告 |
|---|---|---|---|
| 胜率 | 盈利笔数 ÷ 总笔数 | >35% | <25%（除非盈亏比很高） |
| 盈亏比 | 平均盈利 ÷ 平均亏损 | >2.0 | <1.5 |
| 利润因子 | 总盈利 ÷ 总亏损 | >1.5 | <1.2 |
| 最大回撤 | 资金曲线峰到谷最大跌幅 | <20% | >30% |
| 期望值 | 胜率×平均盈利−败率×平均亏损 | >0 | ≤0 |

#### 9.4 曲线拟合（过拟合）陷阱

**曲线拟合（Curve Fitting）**：反复调整参数，让回测结果"完美"——本质是把历史数据中的噪音当成了信号。过拟合的系统在样本外或实盘表现通常显著衰减。

警惕信号：回测胜率>70% 且利润因子>3 且最大回撤<10%——三者同时出现时，"运气好"的概率远小于"参数拟合"的概率。

检验方法：**样本外测试（Out-of-Sample Test）**——保留一段回测未使用的数据（如最近1年），用定稿的规则跑一遍。若样本外表现大幅下降（如利润因子从2.5掉到1.1），即为过拟合，参数需要简化。

#### 9.5 回测结论的正确解读

- **回测好 ≠ 实盘好**：回测没有滑点、没有情绪、没有流动性问题，实盘三项全有；
- **回测差 = 系统有缺陷**：负期望值系统坚决不进实盘，修改规则后重新回测；
- **合理预期**：**实盘表现通常是回测的60%-80%**。回测期望值0.3R，实盘预期按0.18-0.24R规划；按回测上限规划资金与预期，是新手失望情绪的主要来源。

**要点小结**
- 手动翻图五步：选标的区间→逐日浏览→记录信号→推演结果→统计汇总（≥50笔）。
- 五项指标健康值：胜率>35%、盈亏比>2.0、利润因子>1.5、最大回撤<20%、期望值>0。
- 过拟合检验靠样本外测试；"三项全优"的回测结果优先怀疑拟合。
- 实盘按回测的60%-80%预期规划。

**行动判据（If-Then）**
- 如果系统未经回测 → 那么不进入实盘，先完成至少50笔手动回测。
- 如果回测结果"过于完美"（胜率>70%且利润因子>3）→ 那么怀疑过拟合，用样本外数据验证。
- 如果回测期望值为负 → 那么修改规则后重新回测，负期望值系统坚决不进实盘。

**本章练习**
1. 选定一只自选池股票，完成20笔手动回测记录（入场价/止损价/目标价/结果），先跑通流程。
2. 对第1题的数据计算胜率与盈亏比，对照表4-9-1判断各指标处于健康区还是警告区。

### 第10章 系统评估指标——期望值、R倍数、利润因子

> **本章一句话**：评估系统只看一组数字——期望值（必须扣除交易成本）、胜率、盈亏比、利润因子、最大回撤，其中期望值是唯一的"总开关"。
> **学习目标**：
> 1. 能用期望值公式计算并解释一套系统的长期盈利能力；
> 2. 能用R倍数标准化记录每笔盈亏，并识别-2R异常；
> 3. 能计算成本调整后的实际期望值，并据此判断系统是否可行。

#### 10.1 期望值：系统的"总开关"

> **期望值 = 胜率 × 平均盈利 − 败率 × 平均亏损**

期望值回答一个问题：这套系统每交易一笔，平均赚（或亏）多少。**期望值 ≤ 0 的系统，交易得越多亏得越多**——执行率再高、心态再好，都改变不了这个数学事实。

**例 4-10-1｜两个系统的期望值对比**（胜率与盈亏比为示意校准，需自行回测验证）：
- 系统甲：胜率40%，平均盈利2.5R，平均亏损1R → 期望值 = 40%×2.5 − 60%×1 = **+0.4R**；
- 系统乙：胜率60%，平均盈利0.8R，平均亏损1R → 期望值 = 60%×0.8 − 40%×1 = **+0.08R**。

高胜率的系统乙期望值反而更低。**高胜率 ≠ 好系统**，胜率只是期望值方程的一半；评估系统必须胜率与盈亏比一起看，单独谈胜率没有意义。

#### 10.2 R倍数：统一标尺

**R倍数（R Multiple）**：以初始风险R为单位的盈亏度量，R = 入场价 − 止损价（做多）。

**例 4-10-2**：入场30元、止损28元，R = 2元。盈利4元出场 → **+2R**；止损28元出场 → **−1R**；若亏到26元才卖 → **−2R**。

R倍数的好处是**标准化**：不同股票、不同仓位大小的盈亏，都可以放在同一标尺下比较。10万元账户赚4000元和100万元账户赚4万元，只要都是+2R，就是同样质量的交易。

**表 4-10-1｜R倍数评价表**

| R倍数 | 评价 |
|---|---|
| +3R及以上 | 优秀交易 |
| +2R | 好交易（达成盈亏比2:1） |
| +1R | 刚好达标 |
| −1R | 正常止损，执行合格 |
| −2R及以上 | **止损未执行！必须复盘** |

−2R是系统断环的信号：它说明止损没有被执行，风险敞口脱离了预算。任何一笔−2R都值得单独复盘（见第13章）。

#### 10.3 利润因子与最大回撤

- **利润因子 = 总盈利 ÷ 总亏损**：>1.5 可用，>2.0 优秀，<1.2 警告。例：总盈利18000元、总亏损10000元 → 利润因子1.8。
- **最大回撤**：资金曲线从峰值到谷底的最大跌幅。它衡量的是"你最难熬的一段路有多长"，直接决定你能否坚持到系统兑现期望值。健康 <20%，警告 >30%。回本不对称：回撤20%需要上涨25%回本，回撤50%需要上涨100%回本（详见《风险管理与交易心理》附录A回本不对称表）。

#### 10.4 成本调整后的实际期望值

统一口径：**期望值必须扣除交易成本后再判断。**

> **实际期望值 = 名义期望值 − 每笔交易成本**

**例 4-10-3**：某笔交易仓位占总资金约30%（往返金额约为总资金的30%），按第2章成本口径，单次往返成本率约0.25%-0.40%，折合占总资金约0.08%-0.12%；若名义期望值0.2R（R = 3%总资金，即0.6%），扣除约0.1%成本后实际期望值约0.5%——仍为正，但被削掉六分之一。若名义期望值只有0.1R（0.3%），同样成本下实际只剩约0.2%，滑点稍大（0.3%成本率）就逼近归零。

**交易成本敏感性**：高频风格（每月>20笔）对成本极敏感，成本可能吞掉全部名义利润；中线风格（每月2-4笔）影响较小。**在系统设计阶段就把成本算进去**——扣除成本后期望值为负，只有两条出路：提高盈亏比（放大R），或降低交易频率（减少成本次数）。

#### 10.5 评估节奏

- 每笔：记录R倍数与执行情况（第13章日志）；
- 每周：统计胜率、平均R、利润因子、执行率（第13章周复盘）；
- 每季：完整输出系统健康报告（附录A模板），滚动100笔期望值是核心观察项。

**要点小结**
- 期望值 = 胜率×平均盈利 − 败率×平均亏损；≤0 的系统越交易越亏。
- 高胜率 ≠ 好系统；40%胜率+2.5:1 盈亏比优于 60%胜率+0.8:1。
- R倍数是统一标尺；−2R = 止损未执行 = 必须复盘。
- 利润因子>1.5 可用；最大回撤<20% 健康；回本不对称让回撤代价大于同等涨幅。
- 期望值必须扣成本后再判断；成本敏感时只有两条出路：提高盈亏比或降低频率。

**行动判据（If-Then）**
- 如果实际期望值（扣除成本后）为负 → 那么暂停系统，提高盈亏比或降低频率后重新评估。
- 如果出现−2R以上的亏损 → 那么立即复盘止损执行情况。
- 如果滚动100笔期望值转负 → 那么进入第16章的系统失效评估流程。
- 如果只看胜率就下结论"系统不错" → 那么补算盈亏比与期望值再说话。

**本章练习**
1. 用你的回测或实盘数据（至少20笔），计算胜率、平均盈利（R）、平均亏损（R）、期望值、利润因子五项指标。
2. 估算你的平均单笔成本占总资金比例，从名义期望值中扣除，判断实际期望值是否仍为正。
