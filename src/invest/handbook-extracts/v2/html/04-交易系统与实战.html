    第一篇 系统思维——从随机交易到系统化交易

    第1章 为什么你需要一套交易系统

    本章一句话：散户亏损的终极原因不是看不懂K线，而是没有系统——把每一次交易从"即兴发挥"变成"照单施工"，是长期存活的前提。
    学习目标：
    1. 能说出随机交易与系统交易在决策依据、亏损后反应、可改进性上的三点本质区别；
    2. 能复述交易系统的定义（买什么、何时买、买多少、何时卖、错了怎么办）；
    3. 能用"可执行、可回测、可迭代"三标准检验一套规则是否算系统。

    1.1 散户亏损的终极原因：不是技术，是结构

    很多新人把亏损归咎于"技术没学好"：K线看得不够准、指标用得不够熟。但观察足够多的账户就会发现，真正的问题是结构性的——知识是散的，操作是随机的，每次交易的决策路径都不一样：今天靠均线，明天听消息，后天看财报。

    这就像一个厨师从不用菜谱、不记用量、不做总结：同一道菜，这次咸了下次淡了，他永远无法复制成功，也无法定位失败。随机交易的本质，就是每一次决策都是即兴发挥。

    由此产生一个致命错觉："我懂技术分析/基本面/宏观，所以我能赚钱。"这是散户最大的错觉之一。知识不等于系统，散装知识不闭环等于没学。更残酷的等式是：

    正期望值系统 + 0%执行率 = 确定亏损。

    哪怕你找到了一套理论上能赚钱的规则，只要执行不出来，结果仍然是零。

    1.2 随机交易 vs 系统交易：三个维度的本质区别

    表 4-1-1｜随机交易与系统交易对比

    | 维度 | 随机交易 | 系统交易 | |---|---|---| | 决策依据 | 感觉、消息、灵感，每次不同 | 规则清单，逐项核对 | | 买入后行为 | 买了再想什么时候卖 | 买入前已写好出场规则 | | 亏损后反应 | 情绪化加仓摊平、报复性交易、或恐慌割肉 | 止损触发 → 执行 → 复盘 → 不改规则 | | 长期结果 | 不确定，靠运气 | 确定的可控范围，靠概率 | | 可改进性 | 无法改进（没有记录，无从总结） | 可迭代：记录 → 复盘 → 优化 |

    注意最后一行：可改进性。随机交易者的每一笔亏损都白亏了——没有记录就没有复盘，没有复盘就不可能改进。系统交易者的亏损则是"学费"，因为每一笔都被记录、被归因、被用于改进。

    1.3 交易系统是什么：把"艺术"变成"工程"

    交易系统（Trading System）：一套完整定义了"买什么、何时买、买多少、何时卖、错了怎么办"的规则集。五个问题缺一不可，其中"错了怎么办"是最容易被新手忽略、却最能决定生死的一条。

    换个说法：把工程思维应用到交易。盖楼的流程是图纸 → 施工 → 质检 → 验收 → 维护，每一步有标准、可追溯、可改进。你的交易应该是施工，不是创作。创作追求灵感，施工追求可重复；灵感不可复制，规则可以。

    1.4 好系统的三个标准

  • 可执行：规则清晰无歧义。"均线金叉时买入"优于"趋势好的时候买入"——前者可以明确判断（5日均线上穿20日均线），后者每个人理解不同。判据：把规则交给另一个按字面执行的人，他的操作应和你一致。
  • 可回测：能用历史数据验证过去的表现。一条无法用历史数据检验的规则（如"感觉市场情绪好转时买入"）不是系统规则，是心情描述。
  • 可迭代：发现缺陷可以修改，修改后有验证流程（回测 → 模拟 → 小仓位），不会越改越乱。

    • 1.5 系统不能保证盈利，但能保证"可控"

    必须说清楚：没有任何系统能保证盈利。市场的本质是概率，任何系统都会有亏损期。系统的价值在于"可控"：

  • 亏了，知道是哪个环节出了问题——入场条件太松？止损太紧？仓位太大？可以针对性改进；
  • 不会出现"一次失误、全盘清零"的极端情况，因为单笔风险、总仓位都有上限（详见《风险管理与交易心理》第6章与本册第6章）；
  • 你始终知道自己在哪、该往哪走、走错了怎么纠偏——就像导航，它不能保证不堵车，但保证你不会迷路。
    • 可控 = 可改进 = 长期可盈利。这是本册全部内容的逻辑起点。 要点小结
  • 散户亏损的终极原因是结构问题（无系统），不是技术问题。
  • 随机交易五维全面落后于系统交易，其中"可改进性"是分水岭。
  • 交易系统 = 买什么、何时买、买多少、何时卖、错了怎么办的完整规则集。
  • 好系统三标准：可执行、可回测、可迭代。
  • 系统不保证盈利，但保证可控；正期望值系统 + 0%执行率 = 确定亏损。
    • 行动判据（If-Then）
  • 如果决策时没有对照规则清单 → 那么停止交易，先回到系统文档。
  • 如果发现自己在"凭感觉"操作 → 那么退出交易软件，重读系统规则。
  • 如果亏损后第一反应是"我要赚回来" → 那么立即暂停交易至少1天（这是报复性交易的危险信号，详见《风险管理与交易心理》第13章）。
    • 本章练习
  • 回顾你最近5笔交易（无论模拟还是实盘），逐笔写下当时的决策依据，统计其中几笔能对应到明确规则。若少于3笔，说明你目前处于随机交易状态。
  • 用"可执行、可回测、可迭代"三标准，检验你现在正在使用的任何一条"规则"，写出它不合格的地方。

    第2章 交易系统全景地图：六组件闭环

    本章一句话：完整交易系统由"定位、选股、入场、仓位、出场、复盘"六大组件构成闭环，缺一环就是漏水的桶；交易成本是从桶底悄悄漏走的第一桶水。
    学习目标：
    1. 能按顺序说出六大组件及每个组件回答的问题；
    2. 能识别三种最常见的"断环"并说明后果；
    3. 能按最新标准计算一次往返的交易成本（佣金、印花税、过户费、滑点）。

    2.1 自驾游比喻：一次完整的旅行

    把建立交易系统想象成计划一次自驾游：

  • 选择车型 = 自我定位（我是什么类型的交易者？轿车跑高速，越野车走山路，选错车型全程难受）；
  • 选择目的地 = 选股规则（买什么）；
  • 选路线、定出发时机 = 入场规则（何时买）；
  • 控制油门 = 仓位规则（买多少，油门踩到底=满仓，弯道也全速=重仓追高）；
  • 刹车与停车 = 出场规则（何时卖，没有刹车的车不能上路）；
  • 保养维修 = 复盘规则（系统跑了一段时间，好不好？哪里该修？）。

    • 缺任何一环，自驾游都会出问题。交易也一样。

    2.2 六大组件与闭环

    图 4-2-1｜交易系统六组件闭环（示意图）

    六个组件首尾相连：每个环节的输出是下一个环节的输入；复盘的输出又反哺定位与规则优化，形成循环。示例数据。

    闭环（Closed Loop）的定义：执行 → 记录 → 复盘 → 优化 → 再执行。这是系统化交易的生命线。优化时只修改有缺陷的规则，且每次只改一个变量（第17章展开）。

    三种最常见的"断环"：

  • 断环1：只有买入没有卖出规则。买了再说，跌了不知道怎么办——这是新手账户的第一死因。
  • 断环2：只有规则没有复盘机制。从不检查系统是否有效，规则好不好全凭印象。
  • 断环3：有复盘但不改规则。复盘变成自我批评大会，情绪发泄完了，系统原封不动。

    • 不闭环的系统 = 漏水的桶，水（利润）从缺口流走。

    2.3 核心术语速释

    这些术语将贯穿全书，此处先给一句话定义，第10章详细展开：

  • 期望值（Expectancy） = 胜率 × 平均盈利 − 败率 × 平均亏损；每笔交易平均能赚（或亏）多少。
  • 盈亏比（Risk-Reward Ratio） = 平均盈利 ÷ 平均亏损；系统要求 ≥2:1 才入场。
  • R倍数（R Multiple）：以初始风险R为单位衡量盈亏。盈利2R = 赚了2倍初始风险。
  • 利润因子（Profit Factor） = 总盈利 ÷ 总亏损；>1.5 可用，>2.0 优秀。
  • 最大回撤（Maximum Drawdown）：资金曲线从峰值到谷底的最大跌幅。
  • 回测（Backtest）：用历史数据模拟系统的过去表现。
  • 曲线拟合（Curve Fitting，过拟合）：参数被过度优化以迎合历史数据，样本外或实盘表现通常显著衰减。
  • ATR（Average True Range，平均真实波幅）：衡量股票波动率的指标，用于止损与仓位设计。

    • 2.4 交易成本：被忽视的利润杀手

    交易成本由四部分构成，按现行标准（2023年8月28日起印花税减半后）：

    表 4-2-1｜A股交易成本构成（现行标准）

    | 成本项 | 标准 | 收取方式 | |---|---|---| | 佣金 | 约万2.5（0.025%） | 买卖双向 | | 印花税 | 0.05% | 卖出单边（2023年8月28日起由0.1%减半） | | 过户费 | 0.001% | 买卖双向 | | 滑点 | 约0.1%-0.3% | 隐性成本，下单价与实际成交价之差 |

    例 4-2-1｜10万元全仓单次往返成本：
  • 佣金：100000 × 0.025% × 2 = 50元
  • 印花税：100000 × 0.05% = 50元
  • 过户费：100000 × 0.001% × 2 = 2元
  • 不含滑点合计 ≈ 102元（占往返金额约0.102%）
  • 加滑点（按0.15%-0.3%计，150-300元）→ 合计约250-400元，占10万元资金约0.25%-0.40%。
    • 成本敏感性：10万元资金，每月交易10次全仓（按全仓往返口径计算成本率，单次往返约0.25%-0.40%；每月累计往返金额约等于一次全仓，即单笔平均持仓约一成），若滑点控制在0.1%-0.15%，月成本约200-250元，年成本约占资金的2%-3%；若滑点放大到0.3%，年成本将升至约4%-5%。若年化收益预期为10%，仅此一项就吃掉两到五成的利润——减少交易频率 = 直接增加利润，这是最简单的提高收益的方法。更极端的情形：如果每月10次都是真·全仓往返（年往返金额约1200万元），年成本高达资金的30%-48%，任何系统都无法承受——这就是"过度交易是利润头号杀手"的数学依据。 要点小结
  • 六大组件：定位 → 选股 → 入场 → 仓位 → 出场 → 复盘，缺一环即不闭环。
  • 闭环 = 执行 → 记录 → 复盘 → 优化 → 再执行；三种断环各有死法。
  • 期望值、盈亏比、R倍数、利润因子、最大回撤是评估系统的五大核心指标。
  • 现行往返成本（含滑点）约占往返金额的0.25%-0.40%；频率越高，成本侵蚀越狠。
    • 行动判据（If-Then）
  • 如果设计系统时发现六大组件缺一 → 那么先补上再谈其他；没有复盘机制就先停下，设计复盘规则。
  • 如果计算期望值时未扣除交易成本 → 那么重新计算；名义期望值为正但扣成本后为负的系统不可行。
  • 如果每月交易超过10次 → 那么先核算年成本占资金比例，再问自己：这些交易是系统信号，还是手痒？

    第二篇 系统设计——六大组件逐个构建

    第3章 组件一：自我定位——系统的地基（四维定位法）

    本章一句话：系统必须匹配你自己的资金、时间、性格、风险承受力——照搬别人的系统，是系统崩盘的第一大原因。
    学习目标：
    1. 能用四维定位法（资金、时间、性格、风险偏好）写出自己的定位表；
    2. 能说出四种交易风格（日内/短线/中线/长线）在持仓周期、盯盘时间、单笔风险、止损宽度上的参数差异；
    3. 能解释"半年锁定规则"的理由并承诺执行。

    3.1 为什么定位是第一步

    两个真实感很强的失败场景：

  • 上班族照搬全职交易者的短线系统：白天开会没法盯盘，止损总比计划慢半拍，每次实际亏损都比计划大20%以上。
  • 50万资金照搬10万资金的高频打法：部分标的流动性不够，冲击成本和滑点吃掉利润，同样的信号，小资金赚钱他亏钱。

    • 结论：系统参数是"人"的函数。资金不同、时间不同、性格不同，同一套规则的参数就应该不同。定位错了，后面五个组件全部建立在错误的地基上。

    3.2 四维定位法

  • 资金量：决定选股范围（大资金只能选流动性好的）、仓位分散度、交易频率上限。
  • 可用时间：决定交易风格。日内交易需要全天盯盘；中线波段只需每天收盘后30分钟。
  • 性格特征：决定持仓周期和信号敏感度。急性子拿不住长线，慢性子做不了日内；让慢性子盯盘做日内会焦虑，让急性子拿三个月会失控。
  • 风险偏好：最大单笔亏损承受度（用占总资金百分比表示），直接决定仓位算法的风险比例和止损宽度参数。

  • 频繁切换 = 永远在"试错期"，"这周学趋势、下周学波段"是最昂贵的学费缴纳方式。

  • 单笔风险 ≤2% 是铁律，新手期 1%。
  • 半年锁定：6个月只调参数不换方向；样本清零是最贵的学费。

    第4章 组件二：选股规则——买什么（选股漏斗）

    本章一句话：选股规则是一个漏斗——从5000余只股票逐层过滤到10-30只观察池，并且只在池内操作；选择越少，决策质量越高。
    学习目标：
    1. 能写出基础排除层的五条排雷规则；
    2. 能说出三种主流选股风格（主线赛道/基本面/技术面）并选定一种；
    3. 能建立观察池管理纪律（每日盘后筛选、池内操作、容量上限）。

    4.1 漏斗总览：从5000只到10只

    A股上市公司已超过5000家（注册制全面实施、退市常态化，数量仍在动态变化）。没有人能研究所有股票，也不应该试图研究所有股票。选股漏斗分三层：

    全市场 5000+ 只
   ↓ 第一层：基础排除（排雷）
可交易池 约 2000-3000 只
   ↓ 第二层：风格筛选（按你的系统类型）
候选池 约 50-100 只
   ↓ 第三层：观察池管理（每日盘后精选）
自选池 10-30 只 ← 只在这里面交易

    4.2 第一层：基础排除（先排雷）

    五条排除规则，任何一条触发即剔除：

  • ST/*ST：退市风险警示股，退市常态化背景下权重上升，一律排除；
  • 低流动性：日均成交额 <3000万元——滑点大、进出难，成本侵蚀严重；
  • 暴雷风险：审计意见非标、被立案调查、重大违规（详见《财报与基本面》第18章十项排雷清单中的"一票否决"项）；
  • 高管大额减持：近3个月减持合计 >1% 股本——内部人在看空，你没有理由比内部人更乐观；
  • 次新股：上市不足6个月，缺乏历史数据，无法回测，形态参考系不全。

    • 这一层不产生"买入理由"，只负责"排除危险"。排雷永远优先于择优。

    4.3 第二层：风格筛选（三种主流选股风格）

    按你在第3章选定的系统类型，三选一为主（可少量交叉）：

  • 主线赛道法：跟踪当前市场主线（如人工智能、新能源、消费等），从主线板块中选龙头或弹性标的。适合短线/趋势风格。调用《宏观经济分析》行业轮动部分判断主线。
  • 基本面筛选法：硬指标过滤，如 ROE>15%、毛利率>30%、营收增速>15%、资产负债率<60%（具体筛选方法见《财报与基本面》第8-11章与第21章）。适合中长线与价值风格。
  • 技术面筛选法：趋势向上（20日均线上方且均线上行）+ 量价配合 + 形态完成（调用《裸K与价格行为》势位形分析）。适合波段风格。

    • 三种风格不是对立关系：稳健的做法是"基本面选池子、技术面选时机"——用基本面筛选缩小范围，用技术信号决定入场时点。第8章瑞景食品案例即此路径。

    4.4 第三层：观察池管理

  • 每日盘后筛选：收盘后用选股规则扫描一遍，符合条件的加入自选池；
  • 只在自选池内操作：杜绝盘中临时选股。这是铁律。
  • 容量上限：自选池超过30只时，按信号强度排序剔除最弱的10只，保持池子精简。

    • 为什么"不在自选池里就不买"是铁律？盘中看到一只股票突然拉升就追，但你没研究过它——不知道基本面有没有雷，不知道合理入场位在哪，不知道该把止损设在哪里。这笔交易从一开始就是赌博。错过的机会永远比做错的交易便宜：错过损失为零，做错损失真金白银。

    要点小结
  • 选股漏斗三层：排雷 → 风格筛选 → 观察池精选。
  • 基础排除五条：ST、日均成交额<3000万、暴雷风险、高管减持>1%、上市不足6个月。
  • 三种选股风格分别适配短线、价值、波段系统；可组合使用。
  • 观察池纪律：每日盘后筛选、只在池内操作、上限30只。
    • 行动判据（If-Then）
  • 如果一只股票不在自选池内 → 那么无论它涨得多诱人，今天不买。
  • 如果想盘中临时选股 → 那么关闭交易软件（盘中选股 = 赌博）。
  • 如果自选池超过30只 → 那么当天盘后按信号强度剔除至30只以内。

    第5章 组件三：入场规则——什么时候买（AND逻辑与大盘三态过滤）

    本章一句话：好的入场规则是多条件AND逻辑——趋势、形态、量能、大盘环境少一条就放弃；大盘三态决定允不允许开新仓。
    学习目标：
    1. 能写出"趋势回踩低吸"与"突破入场"各自的五个条件；
    2. 能按沪深300与20日均线的关系判别大盘三态，并说出各态的仓位上限与操作权限；
    3. 能在每次下单前完成"入场四问"检查。

    5.1 入场铁律：AND逻辑，不是OR逻辑

    好的入场规则是多条件同时满足才开仓：

    趋势 AND 形态 AND 量能 AND 大盘环境 → 全部满足才入场，少一条就放弃。

    差的入场规则是OR逻辑："均线金叉 或 放量 或 感觉不错"——条件越松，越容易买到假信号。

    宁可错过100个机会，也不做1个条件不全的交易。错过不亏钱，做错才亏钱。 图 4-5-1｜入场条件AND逻辑漏斗（示例数据）

    5.2 两种主流入场模式

    模式一：趋势回踩低吸（五个条件）
  • 趋势向上：20日均线向上，且价格在20日均线上方；
  • 回踩支撑：价格回踩20日均线或前期筹码密集区（支撑区域）；
  • 缩量回调：回调期间成交量萎缩至近期均量的50%-70%（缩量=抛压衰竭）；
  • 放量收阳：支撑位附近出现放量阳线确认（当日量比≥1.5，量比=当日每分钟均量÷过去5日每分钟均量）；
  • 大盘环境：大盘非单边暴跌（三态判断见下节）。
    • 模式二：突破入场（五个条件）
  • 箱体形成：横盘整理 >15个交易日，支撑阻力明确；
  • 放量突破：突破日成交量 >均量1.5倍（量比≥1.5为真突破，<1.2存疑）；
  • 收盘确认：突破日收盘价在箱体上沿之上——A股盘中信号不算数，收盘前15分钟的决策价值最高；
  • 板块配合：同板块至少2只个股同步走强，非孤狼行情；
  • 大盘环境：多头或震荡偏多。

    • 两种模式的详细技术细节（回调分级、真假突破、信号ABC分级）见《裸K与价格行为》第13-16章，此处只给出系统层的条件清单。

    5.3 大盘环境过滤：三态判断

    以沪深300指数与20日均线的关系判断（全系列统一口径）：

    表 4-5-1｜大盘三态与操作权限

    | 状态 | 判定标准 | 允许操作 | 总仓位上限 | |---|---|---|---| | 多头 | 指数在20日均线上方且均线上行 | 全部规则可用 | ≤80% | | 震荡 | 20日均线附近反复穿越 | 仅低吸、不做突破 | ≤50% | | 空头 | 指数在20日均线下方且均线下行 | 不开新仓，仅管理现有持仓 | ≤20% |

    5.4 入场前"四问检查"

    每次下单前，逐项自问：

  • 这只股票在我的自选池里吗？——不在就不买。
  • 入场条件全部满足了吗？——少一条就放弃。
  • 大盘环境允许吗？——空头市不开新仓。
  • 盈亏比≥2:1吗？——计算（目标价−入场价）÷（入场价−止损价），<2 就放弃。

    • 四问全过，才允许进入第6章的仓位计算环节。任何一问不过，本次交易终止——不需要任何补偿性动作。

  • 突破五条件：箱体>15天、放量>1.5倍、收盘确认、板块配合、大盘允许。
  • 大盘三态：多头≤80%、震荡≤50%只做低吸、空头≤20%不开新仓；新手任何环境≤50%。
  • 入场四问：池内、条件全、大盘允许、盈亏比≥2:1。

  • 如果大盘处于空头状态 → 那么不开任何新仓，只管理现有持仓。
  • 如果盈亏比<2:1 → 那么放弃入场，哪怕其他条件全部满足。

    第6章 组件四：仓位规则——买多少（仓位算法）

    本章一句话：仓位不是"感觉不错买三成"，而是由单笔风险预算反推出来的算法结果——股数 = 风险金额 ÷ 每股风险，且实际仓位必须受上限约束。
    学习目标：
    1. 能用单笔风险上限法完整算出一次买入的股数、金额与占比；
    2. 能说明"实际仓位 = min(风险反推仓位, 上限约束仓位)"的含义与方向性意义；
    3. 能复述仓位上限矩阵、金字塔加仓规则与三条资金红线。

    6.1 从感觉仓位到算法仓位

    散户最常见的仓位决策是："这只看起来不错，买个三分之一仓吧。"这是感觉仓位——没有数学依据，风险敞口完全随机。系统化仓位是算法仓位：先确定这笔交易"最多允许亏多少钱"，再用公式反推买多少股。每笔交易的风险在下单前就被精确锁定。

    这个思路来自一个朴素的问题：你愿意为这次机会支付多少"保险费"？答案就是单笔风险预算。

    6.2 单笔风险上限法（固定分数法）

    全系列统一口径：单笔风险上限 ≤2%（铁律），新手期 1%。

    核心公式：

    买入股数 = (总资金 × 单笔风险比例) ÷ (入场价 − 止损价)
    例 4-6-1｜10万元资金的一笔完整计算：总资金10万元，单笔风险预算1.5% = 1500元；入场价30元，止损价28元，每股风险 = 30 − 28 = 2元。
  • 风险反推股数 = 1500 ÷ 2 = 750股，对应金额22500元，占总资金22.5%；
  • 上限检查：单票仓位上限 ≤20%（新手期 ≤15%）。22.5% > 20%，触发上限；
  • 上限约束仓位 = 100000 × 20% ÷ 30元 ≈ 666股，A股按100股整数倍向下取整 = 600股，金额18000元，占18%；
  • 实际仓位 = min(22.5%, 20%) = 18%（600股）；
  • 实际单笔风险 = 600股 × 2元 = 1200元，占1.2% < 1.5%。
    • 上限约束让实际风险低于风险预算——这是安全的方向。风险预算是"最多亏多少"，上限约束只会让实际风险更小，永远不会放大风险。 图 4-6-1｜单笔风险法仓位计算示意（示例数据）

    对比风险反推仓位与上限约束仓位，实际取两者较小值。示例数据，对应例4-6-1。

    注意：公式里的分母是"入场价−止损价"，所以止损位没定好之前根本无法算仓位。这就是"出场规则必须先于仓位计算"的原因（第7章）。

    6.3 波动率仓位法（ATR法）

    当入场依据的止损位没有明确技术位时，可用ATR（14周期）设计止损与仓位：

  • 止损位 = 入场价 − N × ATR（N通常取2-3）；
  • 再代入单笔风险公式计算股数。

    • 效果是波动大的股票自动少买，波动小的股票自动多买，使每笔交易面对的波动风险一致。选择建议：已有明确技术位止损 → 用固定分数法；没有明确技术位 → 用ATR法；新手建议先用固定分数法（止损价直观），进阶后再用ATR法。止损宽度的统一口径：宽度1-1.5个ATR，且绝不设在锚点价位（前高/前低、影线端点、整数位）上——锚点位置是止损猎取的高发区，应偏离锚点 ± 1个ATR 设置（详见《裸K与价格行为》第17章）。

    6.4 仓位上限矩阵（大盘状态 × 信号强度）

    总仓位上限由大盘三态决定（统一口径）：多头 ≤80%、震荡 ≤50%、空头 ≤20%且不开新仓；新手期任何环境 ≤50%。单笔规模再由信号分级调整：C级 = 标准仓的1/3，B级 = 1/2，A级 = 标准仓（信号ABC分级的定义见《裸K与价格行为》第11章）。

  • 单票 ≤20%（新手期 ≤15%）；

  • 现金 ≥30%（保留机动与抗回撤能力）；
  • 每笔风险 ≤2%（新手1%）。

    • 6.5 分批建仓与金字塔加仓

    分批建仓（控制单次判断错误的代价）：底仓50% → 确认后加仓30% → 趋势延续再加20%，每次加仓都有独立的止损位。 金字塔加仓（只在盈利后加仓，每次递减）：
  • 盈利后才能加仓——亏损加仓摊平被绝对禁止；
  • 每次加仓量递减，如底仓1000股 → 加仓600股 → 再加仓300股；
  • 加仓后止损统一上移至保本位，保证整笔交易"最坏也不亏"。
    • 绝对禁止马丁格尔（Martingale，亏损后加倍下注）：短期可能"解套"，但在有限资金与连续亏损的现实下，会显著放大极端回撤乃至爆仓风险。盈利后加仓叫反马丁格尔（趋势跟踪的标准做法），且必须预先限定总风险。 凯利公式（Kelly Criterion）供了解：f* = (bp − q) / b，其中b为盈亏比、p为胜率、q为败率，给出理论最优仓位比例。由于胜率与盈亏比的估计本身有误差，实盘通常使用半凯利（结果再除以2）甚至更低。凯利公式的意义在于说明：即使系统是正期望值，仓位过大一样会破产。

    6.6 三条不可违反的资金红线

    与《风险管理与交易心理》第6章完全一致：

  • 不借钱炒股（杠杆资金放大波动与情绪，且有时间成本逼迫决策）；
  • 不用生活必需资金炒股（房租、房贷、孩子学费的钱不入市）；
  • 月亏损超过月收入10%必须暂停（暂停期只复盘不开仓）。
    • 要点小结
  • 股数 = (总资金 × 风险比例) ÷ (入场价 − 止损价)；单笔风险 ≤2% 铁律、新手1%。
  • 实际仓位 = min(风险反推仓位, 上限约束仓位)；上限约束只会让风险更小，方向安全。
  • 上限四条：单票 ≤20%（新手 ≤15%）、单板块 ≤20%、现金 ≥30%、总仓位按大盘三态 80/50/20%。
  • 金字塔加仓：盈利后、递减、止损上移保本；马丁格尔绝对禁止。
  • 三条资金红线不可违反。
    • 行动判据（If-Then）

  • 如果风险反推仓位超过单票20%上限 → 那么按20%上限买入，接受实际风险低于预算。
  • 如果持仓亏损且想加仓摊平 → 那么立即停止操作并离开屏幕（这是马丁格尔冲动）。
  • 如果是新手期 → 那么单笔风险按1%、单票按 ≤15%、总仓位按 ≤50% 执行。

    第7章 组件五：出场规则——什么时候卖

    本章一句话：出场规则必须在买入前写好——止损是保险不是惩罚，盈亏比≥2:1是入场前提，盈利保护与分批止盈决定你能否把纸面盈利变成真实盈利。
    学习目标：
    1. 能说出五种止损类型的适用场景，并按"入场逻辑失效位 ± 1个ATR"设置止损；
    2. 能用期望值公式说明为什么盈亏比<2:1不值得入场；
    3. 能完整写出一笔交易的止损、目标1、目标2、移动止盈与时间止损。

    7.1 铁律：出场规则必须在买入前写好

    买入前大脑最冷静，买入后持仓盈亏会扭曲判断——赚了舍不得卖，亏了不愿止损。所以：没有出场规则就不开仓。止损价、止盈目标、移动止盈规则，全部写在交易计划单上（第8章模板）才算数。

    7.2 止损设计：五种类型

  • 固定比例止损：入场价 × (1 − 止损%)。新手首选，简单，但忽略了个股波动差异；
  • 技术位止损：设在支撑位/均线/供需区域下方。最合理，需要技术判断能力；
  • ATR止损：入场价 − N × ATR（N取2-3）。自适应波动率，进阶选择；
  • 时间止损：持有N天未达预期 → 退出。防止"不死不活"的死扛，占用资金与注意力；
  • 基本面止损：买入逻辑被证伪（业绩暴雷、逻辑破坏）→ 立即退出。最根本，但反应慢。

    • 全系列统一口径：止损 = 入场逻辑失效位 ± 1个ATR（14周期）；宽度控制在1-1.5个ATR；绝不设在锚点价位（前高/前低、影线端点、整数位）上——锚点是市场共识位，也是止损猎取的高发区。

    7.3 止盈设计：三种方式与盈利保护

  • 分批止盈（适合中线波段，统一口径）：目标1（盈亏比≥2:1处）减仓50% → 目标2 减仓25% → 剩余25%移动止盈；
  • 移动止盈（适合趋势跟踪）：盈利后止损线持续上移跟随价格；
  • 信号止盈：出现明确的反向信号（如放量滞涨、均线死叉）时退出。
    • 盈利保护阶梯（统一口径）：

    | 浮盈幅度 | 动作 | |---|---| | +3% | 止损上移至保本位 | | +5% | 止损上移至+2% | | +10% | 止损上移至+5% | | +20%以上 | 转入移动止盈 |

    阶梯的意义：浮盈是市场给的"期权"，保护阶梯保证期权不会白白过期——任何一笔曾经浮盈10%的交易，最差结局也是锁定+5%。

    7.4 盈亏比设计：为什么 ≥2:1 是入场前提

    定义 R = 初始风险 = 入场价 − 止损价。盈亏比 = 目标盈利 ÷ 初始风险。

    例 4-7-1｜期望值对比：假设胜率40%（示意校准，需自行回测验证）：
  • 盈亏比2:1：期望值 = 40% × 2R − 60% × 1R = +0.2R（正期望值）；
  • 盈亏比1:1：期望值 = 40% × 1R − 60% × 1R = −0.2R（负期望值）。

    • 同样的胜率，仅仅因为盈亏比从2:1降到1:1，系统就从赚钱变成亏钱。这就是"盈亏比 ≥2:1 才入场"的数学根源——它是在胜率不确定时保护期望值的护栏。

    横轴为胜率，纵轴为盈亏比，色块值为期望值（单位R，未扣交易成本）。示例数据，可按公式 p×b − (1−p) 手工验算。

    7.5 止损触发后：执行，然后区分情况

    止损被触发，立即执行，不犹豫。止损是保险，不是惩罚——交了保费才能继续在市场上活着。

    执行之后，复盘时要区分两种情况：

  • 假突破：价格短暂跌破支撑后快速回升，趋势逻辑没变 → 该位置可以再入场（重新满足入场条件后），下次可考虑把止损再放宽一些（远离锚点）；
  • 趋势反转：跌破支撑后持续下行，趋势逻辑被证伪 → 不再入场，等待新的趋势信号。

    • 7.6 连亏阶梯：把情绪管理写进规则

    亏损 → "我要赢回来" → 加大仓位/频繁交易 → 亏得更快 → 更想报复——这是报复性交易的恶性循环。系统级阻断方案不靠意志力，靠阶梯规则（全系列统一口径）：

    表 4-7-1｜连亏阶梯

    | 连续亏损 | 强制动作 | |---|---| | 3笔 | 仓位减半 | | 5笔 | 暂停1-3天 | | 7笔 | 暂停1周 | | 10笔 | 全面停止 + 系统评估（第16章） |

    要点小结
  • 出场规则买入前写好：止损价、目标1、目标2、移动止盈、时间止损。
  • 止损 = 入场逻辑失效位 ± 1个ATR，宽度1-1.5个ATR，不设在锚点价位上。
  • 盈亏比 ≥2:1 是入场前提；40%胜率下 2:1 = +0.2R，1:1 = −0.2R。
  • 分批止盈 50%/25%/25%；盈利保护阶梯 +3%保本、+5%移+2%、+10%移+5%、+20%以上移动止盈。
  • 连亏阶梯：3笔减半、5笔停1-3天、7笔停1周、10笔全面停止。
    • 行动判据（If-Then）
  • 如果准备买入 → 那么先在计划单上写好止损价、目标价、移动止盈规则，缺一不可。
  • 如果止损被触发 → 那么立即执行，不犹豫、不等反弹。
  • 如果连续亏损达到3笔 → 那么仓位减半；达到5笔 → 暂停1-3天并复盘最近5笔的执行率。
  • 如果浮盈达到+3% → 那么止损上移至保本位（之后按阶梯继续上移）。

    背景：2025年三季度，投资者小王，总资金20万元，已完成八轮学习中的前四轮，处于小仓位实盘阶段，单笔风险预算按1.5%（其自我定位表允许值，未超过2%铁律）。 第①步 宏观环境（调用《宏观经济分析》第21章五步法）：

    第9章 回测——用历史数据验证系统

    本章一句话：回测不能保证实盘赚钱，但回测差一定说明系统有缺陷——用手动翻图法先跑50笔，把明显不行的系统挡在实盘门外。
    学习目标：
    1. 能独立完成手动翻图回测的五步流程；
    2. 能说出五项回测核心指标的健康值与警告值；
    3. 能识别曲线拟合（过拟合）并用样本外测试检验；
    4. 能正确解读"实盘通常为回测的60%-80%"的含义。

    9.1 为什么要回测

    不经验证就上实盘的系统 = 未经测试就起飞的飞机。回测不是万能的，但"回测差 = 系统有缺陷"是确定的：如果一套规则在历史数据（没有滑点、没有情绪、完美执行）上都不赚钱，实盘只会更差。

    回测的三个作用：①过滤掉明显负期望值的规则；②让你在实盘前就见过系统的连亏期长什么样（心理建设）；③为第10章的评估指标提供第一组数据。

    9.2 手动翻图回测五步法（新手不需要昂贵软件）

  • 选标的与区间：选一只流动性好的股票（最好是你自选池里的），时间跨度2-3年，覆盖至少一段上涨、一段下跌、一段震荡；
  • 逐日浏览：打开K线图从左到右浏览，模拟时间流逝——只看"今天及之前"，不许偷看右边；
  • 记录信号：每次入场条件全部满足时，记录入场价、止损价、目标价；
  • 推演结果：继续往右翻，看这笔交易先触及止损还是先触及目标，记录出场价与盈亏；
  • 统计汇总：累计50笔后，统计胜率、盈亏比、期望值（公式见第10章）。

    • 手动回测的核心价值是建立直觉：你会亲眼看到哪些条件经常产生假信号、哪些过滤条件最有效、连亏6笔时资金曲线是什么样子——这是自动回测软件给不了的体验。

    9.4 曲线拟合（过拟合）陷阱

    曲线拟合（Curve Fitting）：反复调整参数，让回测结果"完美"——本质是把历史数据中的噪音当成了信号。过拟合的系统在样本外或实盘表现通常显著衰减。

    警惕信号：回测胜率>70% 且利润因子>3 且最大回撤<10%——三者同时出现时，"运气好"的概率远小于"参数拟合"的概率。

    检验方法：样本外测试（Out-of-Sample Test）——保留一段回测未使用的数据（如最近1年），用定稿的规则跑一遍。若样本外表现大幅下降（如利润因子从2.5掉到1.1），即为过拟合，参数需要简化。

    9.5 回测结论的正确解读

  • 回测好 ≠ 实盘好：回测没有滑点、没有情绪、没有流动性问题，实盘三项全有；
  • 回测差 = 系统有缺陷：负期望值系统坚决不进实盘，修改规则后重新回测；
  • 合理预期：实盘表现通常是回测的60%-80%。回测期望值0.3R，实盘预期按0.18-0.24R规划；按回测上限规划资金与预期，是新手失望情绪的主要来源。
    • 要点小结
  • 手动翻图五步：选标的区间→逐日浏览→记录信号→推演结果→统计汇总（≥50笔）。
  • 五项指标健康值：胜率>35%、盈亏比>2.0、利润因子>1.5、最大回撤<20%、期望值>0。
  • 过拟合检验靠样本外测试；"三项全优"的回测结果优先怀疑拟合。
  • 实盘按回测的60%-80%预期规划。
    • 行动判据（If-Then）
  • 如果系统未经回测 → 那么不进入实盘，先完成至少50笔手动回测。
  • 如果回测结果"过于完美"（胜率>70%且利润因子>3）→ 那么怀疑过拟合，用样本外数据验证。
  • 如果回测期望值为负 → 那么修改规则后重新回测，负期望值系统坚决不进实盘。

  • 选定一只自选池股票，完成20笔手动回测记录（入场价/止损价/目标价/结果），先跑通流程。

    第10章 系统评估指标——期望值、R倍数、利润因子

    本章一句话：评估系统只看一组数字——期望值（必须扣除交易成本）、胜率、盈亏比、利润因子、最大回撤，其中期望值是唯一的"总开关"。
    学习目标：
    1. 能用期望值公式计算并解释一套系统的长期盈利能力；
    2. 能用R倍数标准化记录每笔盈亏，并识别-2R异常；
    3. 能计算成本调整后的实际期望值，并据此判断系统是否可行。

    10.1 期望值：系统的"总开关"

    期望值 = 胜率 × 平均盈利 − 败率 × 平均亏损

    期望值回答一个问题：这套系统每交易一笔，平均赚（或亏）多少。期望值 ≤ 0 的系统，交易得越多亏得越多——执行率再高、心态再好，都改变不了这个数学事实。

    例 4-10-1｜两个系统的期望值对比（胜率与盈亏比为示意校准，需自行回测验证）：
  • 系统甲：胜率40%，平均盈利2.5R，平均亏损1R → 期望值 = 40%×2.5 − 60%×1 = +0.4R；
  • 系统乙：胜率60%，平均盈利0.8R，平均亏损1R → 期望值 = 60%×0.8 − 40%×1 = +0.08R。

    • 高胜率的系统乙期望值反而更低。高胜率 ≠ 好系统，胜率只是期望值方程的一半；评估系统必须胜率与盈亏比一起看，单独谈胜率没有意义。

    10.2 R倍数：统一标尺

    R倍数（R Multiple）：以初始风险R为单位的盈亏度量，R = 入场价 − 止损价（做多）。 例 4-10-2：入场30元、止损28元，R = 2元。盈利4元出场 → +2R；止损28元出场 → −1R；若亏到26元才卖 → −2R。

    R倍数的好处是标准化：不同股票、不同仓位大小的盈亏，都可以放在同一标尺下比较。10万元账户赚4000元和100万元账户赚4万元，只要都是+2R，就是同样质量的交易。

    表 4-10-1｜R倍数评价表

    | R倍数 | 评价 | |---|---| | +3R及以上 | 优秀交易 | | +2R | 好交易（达成盈亏比2:1） | | +1R | 刚好达标 | | −1R | 正常止损，执行合格 | | −2R及以上 | 止损未执行！必须复盘 |

    −2R是系统断环的信号：它说明止损没有被执行，风险敞口脱离了预算。任何一笔−2R都值得单独复盘（见第13章）。

    10.3 利润因子与最大回撤

  • 利润因子 = 总盈利 ÷ 总亏损：>1.5 可用，>2.0 优秀，<1.2 警告。例：总盈利18000元、总亏损10000元 → 利润因子1.8。
  • 最大回撤：资金曲线从峰值到谷底的最大跌幅。它衡量的是"你最难熬的一段路有多长"，直接决定你能否坚持到系统兑现期望值。健康 <20%，警告 >30%。回本不对称：回撤20%需要上涨25%回本，回撤50%需要上涨100%回本（详见《风险管理与交易心理》附录A回本不对称表）。

    • 10.4 成本调整后的实际期望值

    统一口径：期望值必须扣除交易成本后再判断。

    实际期望值 = 名义期望值 − 每笔交易成本
    例 4-10-3：某笔交易仓位占总资金约30%（往返金额约为总资金的30%），按第2章成本口径，单次往返成本率约0.25%-0.40%，折合占总资金约0.08%-0.12%；若名义期望值0.2R（R = 3%总资金，即0.6%），扣除约0.1%成本后实际期望值约0.5%——仍为正，但被削掉六分之一。若名义期望值只有0.1R（0.3%），同样成本下实际只剩约0.2%，滑点稍大（0.3%成本率）就逼近归零。 交易成本敏感性：高频风格（每月>20笔）对成本极敏感，成本可能吞掉全部名义利润；中线风格（每月2-4笔）影响较小。在系统设计阶段就把成本算进去——扣除成本后期望值为负，只有两条出路：提高盈亏比（放大R），或降低交易频率（减少成本次数）。 图 4-10-1｜交易成本侵蚀示意（示例数据）

    10.5 评估节奏

  • 每笔：记录R倍数与执行情况（第13章日志）；
  • 每周：统计胜率、平均R、利润因子、执行率（第13章周复盘）；
  • 每季：完整输出系统健康报告（附录A模板），滚动100笔期望值是核心观察项。
    • 要点小结
  • 期望值 = 胜率×平均盈利 − 败率×平均亏损；≤0 的系统越交易越亏。
  • 高胜率 ≠ 好系统；40%胜率+2.5:1 盈亏比优于 60%胜率+0.8:1。
  • R倍数是统一标尺；−2R = 止损未执行 = 必须复盘。
  • 利润因子>1.5 可用；最大回撤<20% 健康；回本不对称让回撤代价大于同等涨幅。
  • 期望值必须扣成本后再判断；成本敏感时只有两条出路：提高盈亏比或降低频率。
    • 行动判据（If-Then）
  • 如果实际期望值（扣除成本后）为负 → 那么暂停系统，提高盈亏比或降低频率后重新评估。
  • 如果出现−2R以上的亏损 → 那么立即复盘止损执行情况。
  • 如果滚动100笔期望值转负 → 那么进入第16章的系统失效评估流程。
  • 如果只看胜率就下结论"系统不错" → 那么补算盈亏比与期望值再说话。
    • 本章练习
  • 用你的回测或实盘数据（至少20笔），计算胜率、平均盈利（R）、平均亏损（R）、期望值、利润因子五项指标。
  • 估算你的平均单笔成本占总资金比例，从名义期望值中扣除，判断实际期望值是否仍为正。

    第四篇 从模拟到实盘——系统落地的成长路径

    第11章 模拟盘练习（第0-50笔）

    本章一句话：模拟盘不是用来"赚模拟钱"的，而是用来验证"规则是否清晰到无歧义、可执行"——毕业标准是50笔执行率>90%且期望值为正。
    学习目标：
    1. 能说出模拟盘的真正目标与最大局限；
    2. 能执行模拟期四项关键任务；
    3. 能按毕业标准判断自己是否可以进入小仓位实盘。

    11.1 模拟盘的真正目标

    模拟钱毫无意义。模拟盘的目标只有一个：验证系统的可执行性——

  • 规则是否清晰到无歧义？（如果在模拟盘里都在犹豫"这算不算信号"，实盘只会更犹豫）
  • 条件是否太多导致信号太少？（一个月连一个信号都没有的系统不实用）
  • 止损/止盈规则是否可操作？（到了止损位，你真的会按下"卖出"吗？）

    • 模拟盘铁律：完全按真实系统操作——用真实的资金规模、真实的仓位计算、真实的止损止盈规则，唯一区别是钱是虚拟的。如果在模拟盘里"随便玩玩"，验证价值为零。

    11.2 模拟盘的最大局限

    模拟盘没有真实亏损的恐惧。模拟止损只是点一下按钮，没有"真金白银没了"的心理冲击。所以模拟盘能验证系统的"逻辑可行性"，但无法验证"心理可承受性"——这正是必须经过小仓位实盘的原因（第12章）。

    11.3 模拟期（第0-50笔）四项关键任务

  • 发现规则漏洞：记录每次"规则不够清晰"的时刻（如"缩量回调——到底缩到多少算缩量？"）；
  • 修正模糊条件：把所有模糊描述改为可量化标准（"缩量"→"回调期间成交量萎缩至近5日均量的50%-70%"）；
  • 统计核心指标：50笔后统计胜率、盈亏比、期望值，判断是否为正；
  • 记录执行率：每笔交易记录是否100%按规则执行，偏离即记一笔。
    • 执行率（Execution Rate） = 完全按规则执行的笔数 ÷ 总笔数。目标 ≥85%，底线80%。注意：执行率衡量的是过程，不是结果——按规则亏损的交易算"执行合格"，不按规则赚钱的交易算"执行不合格"（过程导向，详见《风险管理与交易心理》第18章）。

    11.4 模拟盘毕业标准（两个条件同时满足，缺一不可）

  • 连续50笔执行率 >90%（偏离规则的笔数 ≤5笔）；
  • 期望值为正（胜率 × 平均盈利 − 败率 × 平均亏损 >0，未扣成本为正、扣成本后也应为正或接近正）。

    • 两种不毕业的情况各有含义：

  • 执行率高但期望值为负 = 系统有缺陷，回去改规则重新回测；
  • 期望值为正但执行率低 = 心理或规则清晰度问题，先把模糊条件量化，再解决执行。
    • 要点小结
  • 模拟盘验证可执行性，不验证心理；必须完全按真实系统操作。
  • 四项任务：找漏洞、量化模糊条件、统计指标、记录执行率。
  • 毕业标准：50笔执行率>90% 且 期望值为正。
  • 执行率看过程不看结果；按规则亏损也算合格。
    • 行动判据（If-Then）
  • 如果模拟盘50笔后执行率<90% → 那么不进入实盘，先解决规则模糊问题。
  • 如果模拟盘期望值为负 → 那么修改规则后重新回测与模拟，负期望值系统绝不进实盘。
  • 如果在模拟盘中出现"规则不够清晰"的犹豫 → 那么当场记录，当天把该条件量化成可判断的数字。
    • 本章练习
  • 建立模拟账户（或用纸面记录），按一页纸计划模板执行第一笔模拟交易，完整填写15字段日志的前7项。
  • 列出你当前系统中所有含"适当、大概、感觉"字样的规则，逐条改写为可量化表述。

    第12章 小仓位实盘（第51-100笔）

    本章一句话：只有真金白银的亏损才能验证心理承受力——用"亏了不心疼"的小仓位跑完第51-100笔，把模拟期的规则执行力迁移到实盘。
    学习目标：
    1. 能按"亏了不心疼"原则确定自己的小仓位规模；
    2. 能识别四种常见"实盘冲击"并说出各自应对；
    3. 能按三条毕业标准判断是否可以加大仓位。

    12.1 为什么必须经过实盘

    模拟盘中执行完美的规则，到实盘经常变形：止损下不去手、盈利急着跑、亏损后想加仓摊平——这些都是心理问题，不是系统问题，而心理问题只能在真实盈亏中暴露和训练。

    "亏了不心疼"原则：小仓位的标准是即使全部亏损，生活质量也不受影响。建议用总资金的5%-10%做小仓位期：10万元资金用5000-10000元验证，每笔亏损控制在100-200元——亏了不心疼，但又能感受到真实的"痛"，这个痛感正是训练材料。

    12.2 四种常见"实盘冲击"及应对

  • 手抖不敢买（信号出现却犹豫）→ 回到规则清单逐项打钩，条件全满足就买；犹豫 = 不信任系统，而不信任来自样本不足，继续积累。
  • 止损下不去手（到了止损价想"再等等"）→ 用条件单代替手动执行，提前把止损委托给系统。
  • 盈利急着跑（小赚就走，拿不到目标）→ 对照盈亏比：没到目标1不减仓；提前兑现等于系统性地把盈亏比压到1:1以下。
  • 亏损后报复性交易 → 触发连亏阶梯（第7章）：3笔仓位减半，5笔暂停1-3天。

    • 12.3 小仓位期（第51-100笔）毕业标准（三条同时满足）

  • 执行率 >80%（100笔中偏离规则的笔数 ≤20笔；目标值≥85%）；
  • 情绪干扰记录减半：日志中标记为"冲动/恐慌"的交易笔数，后半段（第76-100笔）比前半段（第51-75笔）减少50%以上；
  • 期望值仍然为正：扣除交易成本后的实际期望值 >0。
    • 要点小结
  • 小仓位 = 亏了不心疼的资金（总资金5%-10%），用于验证心理承受力。
  • 四种实盘冲击：不敢买、不敢止损、急着兑现、报复交易，各有系统级对策。
  • 毕业三标准：执行率>80%、情绪干扰减半、扣成本后期望值为正。
  • 条件单是"不靠意志力止损"的硬件方案。
    • 行动判据（If-Then）
  • 如果止损想手动执行但开始犹豫 → 那么改用条件单自动执行。
  • 如果小仓位100笔后执行率<80% → 那么退回模拟盘，心理准备不足时不可加大仓位。
  • 如果某笔亏损让你明显影响睡眠或情绪 → 那么说明仓位仍偏大，下一笔再减半。
    • 本章练习
  • 计算你的小仓位资金池规模（总资金×5%-10%），并算出该池子内单笔风险1%对应的最大亏损金额。
  • 开通条件单功能（多数券商App支持），练习设置一笔"到价止损"委托（可先撤单）。

    第13章 交易日志——系统的"黑匣子"（15字段）

    本章一句话：没有记录就没有复盘，没有复盘就没有迭代——交易日志是把"执行"与"复盘"连起来的黑匣子，15个字段一个都不能少。
    学习目标：
    1. 能默写交易日志15个必填字段；
    2. 能用R倍数记录法把每笔盈亏标准化；
    3. 能执行周复盘与月度健康报告的固定流程。

    13.1 为什么必须有交易日志

    不写日志 = 闭着眼开车。公司不做账，年底不知道赚了还是亏了；交易者不记日志，一年下来只剩模糊的感觉。交易日志就是你的"财务报表"，也是系统闭环的关键连接器——它把执行和复盘连起来，让第2章的闭环（执行→记录→复盘→优化）真正转得动。

    13.2 15个必填字段（当天记，绝不拖延）

  • 日期；
  • 标的（代码+名称）；
  • 方向（A股现货仅做多，记录"买入/卖出"动作亦可）；
  • 入场价（实际成交价）；
  • 止损价；
  • 目标价；
  • 仓位（股数/金额/占总资金%）；
  • 入场理由（对照规则清单逐项打钩）；
  • 出场价；
  • 出场理由（止损/止盈/信号/情绪——"情绪"要如实写）；
  • 盈亏金额；
  • R倍数（盈亏 ÷ 初始风险）；
  • 情绪标记（冷静/犹豫/冲动/恐慌，入场前、持仓中、出场后各标一次更佳）；
  • 执行率（本笔是否100%按规则执行）；
  • 复盘备注（做对了什么/做错了什么/规则修正建议）。

    • 13.3 R倍数记录法

    R = 入场价 − 止损价（做多）。每笔出场后：盈亏金额 ÷ (R × 股数) = R倍数。

    例 4-13-1：入场30元、止损28元、买入500股，R = 2元，初始风险 = 1000元。
  • 34元止盈出场：盈利2000元 → +2R（好交易，达成2:1）；
  • 28元止损出场：亏损1000元 → −1R（正常止损，执行合格）;
  • 26元才卖出：亏损2000元 → −2R（止损未执行，必须复盘）。

    • 13.4 周复盘与月度健康报告

    周复盘（每周日30分钟，雷打不动）：
  • 本周交易笔数、胜率、平均盈亏R、利润因子；
  • 执行率：本周几笔偏离规则，偏离原因各是什么；
  • 异常交易标记：是否有情绪化交易、报复性交易。
    • 月度系统健康报告的健康区间（逐项对比上月值并标注趋势↑↓→）：

    | 指标 | 健康区间 | |---|---| | 胜率 | >35% | | 盈亏比 | >2.0 | | 利润因子 | >1.5 | | 执行率 | >85% | | 最大回撤 | <20% | | 情绪干扰笔数 | <3笔/月 |

    要点小结
  • 15字段当天记；情绪与执行率与价格同等重要。
  • R倍数统一标尺；−2R = 止损未执行 = 系统断环信号。
  • 周复盘30分钟固定流程；月度健康报告六项指标标注趋势。
  • 日志是闭环的连接器：没有它，优化无从谈起。
    • 行动判据（If-Then）
  • 如果完成一笔交易 → 那么当天填写完整15字段日志，不隔夜。
  • 如果发现−2R以上的亏损 → 那么立即复盘止损执行情况，并检查当时是否有条件单。
  • 如果周复盘连续两周执行率<80% → 那么下周降低交易频率，先修执行再加仓。
    • 本章练习
  • 用Excel建立日志表：15个字段作列头，每笔一行；再建一个"周统计"页汇总胜率/平均R/利润因子/执行率。
  • 回填你已有的交易记录（哪怕只有5笔），练习计算R倍数与执行率。

    第14章 正常仓位实盘（第101-300笔）

    本章一句话：从小仓位到正常仓位要走5%→10%→15%→正常的台阶，每台阶至少20笔确认执行率不下降；101-300笔的核心任务是积累统计样本，最大敌人是过度自信。
    学习目标：
    1. 能说出过渡到正常仓位的三个条件与仓位台阶规则；
    2. 能基于100笔以上数据做单变量参数微调；
    3. 能识别"赚钱时偏离规则"的危险信号。

    14.1 过渡标准与仓位台阶

    从小仓位到正常仓位，三个条件同时满足：

  • 小仓位期（第51-100笔）执行率 >80%；
  • 实际期望值（扣除成本后）为正；
  • 情绪干扰记录后半段比前半段减少50%以上。
    • 加仓走台阶（统一口径）：5% → 10% → 15% → 按系统规则正常仓位，每增加一个台阶至少运行20笔，确认执行率不下降才上下一级。这里的百分比指该阶段单笔风险预算与持仓规模相对正常仓位的比例；新手期单票上限 ≤15%，因此台阶期间单票仓位天然受此约束。 图 4-14-1｜仓位台阶成长路径（示例数据）

    横轴为台阶，纵轴为仓位规模（相对正常仓位的百分比）与该台阶要求的最低交易笔数（累计）。示例数据，按统一口径。

    14.2 正常仓位期（第101-300笔）的核心目标：积累统计样本

  • 100笔才能初步判断系统的统计特征（胜率、盈亏比的稳定性）；
  • 300笔才能形成较可靠的结论，开始有意义的参数微调。

    • 基于统计的参数微调（需100笔以上数据，且每次只改一个变量）：

  • 胜率低于预期 → 检查入场条件是否太松，考虑增加1个过滤条件；
  • 盈亏比低于预期 → 止盈目标是否太保守？或止损太紧被频繁震出？
  • 执行率下降 → 规则是否太复杂？考虑简化。

    • 迭代流程：改 → 回测 → 模拟 → 小仓位确认 → 推广（第17章展开）。

    14.3 信心建立：看数据，不看感觉

    从"怀疑系统"到"信任系统"的唯一依据是数据：

  • 100笔中连续亏损5笔，但滚动期望值仍为正 → 继续执行（连亏是概率波动的正常结果）；
  • 滚动期望值从正转负 → 暂停，进入第16章的系统失效评估。

    • 实盘 vs 回测对比判据：偏差在20%以内 → 正常；偏差>40% → 系统需要调整；同时找出执行率最低的10笔，分析偏离原因——很多"实盘衰减"其实是执行衰减，不是系统衰减。

    14.4 正常仓位期的最大风险：过度自信

    连续盈利几笔后最容易放松纪律："今天规则不满足但感觉不错，买吧"、"止损不用那么紧，再等等"。赚钱时的偏离规则比亏钱时更危险——亏钱时的偏离立刻有痛感反馈，赚钱时的偏离却会奖励坏习惯，制造"我比系统更聪明"的错觉，直到某次大亏把累积的越界利润一次性收回。

    对策：把"连续盈利后是否想灵活操作"本身作为周复盘的固定检查项；连续盈利≥5笔时，下一笔仓位主动降一档。

    要点小结
  • 过渡三条件：执行率>80%、扣成本期望值为正、情绪干扰减半。
  • 仓位台阶 5%→10%→15%→正常，每台阶≥20笔且执行率不下降。
  • 100笔初步判断、300笔可靠结论；参数微调必须单变量。
  • 实盘与回测偏差>40%才需调整系统；先查执行率再查规则。
  • 赚钱时的越界最危险；连赢5笔后主动降一档。
    • 行动判据（If-Then）
  • 如果想从小仓位升到正常仓位 → 那么走3-4个台阶，每台阶至少20笔验证。
  • 如果想同时修改多个参数 → 那么只改一个变量，其余排队。
  • 如果连续盈利后想"灵活操作" → 那么回到规则清单逐项打钩；打不满钩就不做。
    • 本章练习
  • 制定你的台阶计划表：写下每一级的仓位规模、最低笔数、晋级条件，贴在系统文档里。
  • 若你已有≥30笔记录：找出执行率最低的5笔，逐笔写下偏离原因，归类为"规则模糊"还是"情绪干扰"。

    第15章 复盘机制——系统的"维修保养"

    本章一句话：复盘分三个层次——每笔、每周、每季；复盘是修补系统，不是自我批评；同一条件连续3次失效就要停用并回测验证。
    学习目标：
    1. 能执行三个层次的复盘并说出各自的核心问题与输出；
    2. 能用"每笔复盘三问"完成一次完整复盘；
    3. 能应用"连续3次失效"规则并理解它的边界。

    15.1 复盘的三个层次

    表 4-15-1｜三级复盘节奏

    | 层次 | 频率与时长 | 核心问题 | 输出 | |---|---|---|---| | 每笔复盘 | 每笔交易当天 | 做对了什么/做错了什么 | 经验教训 + 规则修正建议 | | 每周复盘 | 每周日30分钟 | 本周执行率/胜率/异常 | 周统计 + 异常交易标记 | | 每季系统评估 | 每季度2小时 | 系统是否仍适应当前市场 | 系统健康报告 + 是否迭代 |

    15.2 每笔复盘三问

  • 我做对了什么？——哪些决策符合规则且产生了好结果（注意：符合规则但亏损，同样可能"做对了"）；
  • 我做错了什么？——哪些决策偏离了规则，偏离的触发点是什么（情绪？规则模糊？）；
  • 规则需要修改吗？——个例不改规则；如果同一条件连续3次失败，该条件可能需要修改。
    • 注意：复盘是修补系统，不是自我批评。"我做错了"的正确解读不是"我很蠢"，而是"这条规则不够清晰"或"我在这类行情下容易偏离"。自我批评只产生情绪，修补系统才产生改进。找出问题 → 修改系统 → 下次不再犯。

    15.3 "连续3次失效"规则

    同一条件在3笔交易中连续失效，说明该条件可能有问题：
  • 止损连续3次被震出（止损后价格立刻收复）→ 止损可能设太紧，考虑加宽1个ATR，或把止损移离锚点价位；
  • 入场信号连续3次假突破 → 入场条件可能太松，增加1个过滤条件（如量比门槛、板块配合）；
  • 某板块连续3笔亏损 → 该板块可能已过气，暂时从观察池移除。

    • 边界：连续3次失效 ≠ 立即推翻系统。它是"提示信号"，不是"死刑判决"。先分析原因——是规则问题，还是市场环境变化（第16章判别）？再决定是调参数还是换规则。切忌一次亏损就推翻系统，也切忌攒够十次失效还装看不见。

    要点小结
  • 三级复盘：每笔（三问）、每周（30分钟统计）、每季（2小时健康报告）。
  • 复盘 = 修补系统，不是自我批评。
  • 连续3次失效 → 停用该条件 → 回测验证修改方案 → 重新启用。
  • 个例不改规则，模式才改规则。
    • 行动判据（If-Then）
  • 如果完成一笔交易 → 那么当天完成复盘三问并写入日志第15字段。
  • 如果同一条件连续3次失效 → 那么暂停使用该条件，回测验证修改方案后再启用。
  • 如果复盘时开始自我批评 → 那么把句子改写为"规则问题"或"流程问题"的表述。
    • 本章练习
  • 选你最近一笔已完成的交易，严格按三问写一份复盘（每问至少一条具体事实，不接受"感觉"类描述）。
  • 检查你的日志：有没有任何一个条件已经出现过2次连续失效？若有，预先写下第3次失效时的处置动作。

    第16章 系统失效——什么时候该坚持，什么时候该改变

    本章一句话：正常回撤要扛住，系统失效要停住——用持续时间、回撤幅度、滚动期望值等五个维度判别，触发五红灯之一立即暂停评估，动作是"暂停"而不是"放弃"。
    学习目标：
    1. 能用判别表区分正常回撤与系统失效；
    2. 能复述系统失效的五个红灯信号；
    3. 能说出"执行率>胜率"的过程导向原则及理由。

    16.1 正常回撤 vs 系统失效

    任何正期望值系统都有回撤期——概率的连续不利分布是数学必然。把正常回撤误判为失效而放弃，是最常见的"黎明前离场"；反之，把真失效硬扛成信仰，则会把本金磨掉大半。判别表如下：

    表 4-16-1｜正常回撤与系统失效判别（统一口径）

    | 维度 | 正常回撤 | 系统失效 | |---|---|---| | 持续时间 | 1-3个月 | >6个月 | | 亏损幅度 | 在历史最大回撤范围内 | 超过历史最大回撤50%以上 | | 原因 | 正常概率波动，连亏随机出现 | 市场结构变化导致逻辑失效 | | 滚动100笔期望值 | 仍为正 | 转为负 | | 应对 | 继续执行，可适当降低仓位 | 暂停，评估系统逻辑是否仍成立 |

    两条资金曲线：A为正常回撤（回撤在历史范围内、期望值恢复上行），B为系统失效（回撤超历史范围、持续阴跌）。示例数据，用于形态识别，非真实绩效。

    A曲线在第4-6个月回撤约6%（在历史最大回撤范围内），随后创新高；B曲线自第4个月起连续9个月阴跌，回撤超过历史范围且滚动期望值转负——后者应触发暂停评估，而不是"再扛扛"。

    16.2 系统失效的五个红灯信号

  • 连续亏损超过历史最大连亏 ×1.5（如历史最大连亏6笔，现在连亏10笔仍未止住）；
  • 滚动100笔期望值转负——不是偶尔亏损，而是持续性亏损；
  • 胜率和盈亏比同时大幅下降——双降才是逻辑问题；单降（如胜率低但盈亏比更高）可能只是风格波动；
  • 市场状态发生根本性变化——如从趋势市转入长期震荡市，趋势系统的表现通常会系统性恶化；
  • 最大回撤超过预设上限——如预设20%，实际已亏25%以上。

    • 与附录C"五红灯"的关系：本条是运行中的定性判别，附录C是季度体检的一票否决清单，两者互相印证，任一触发都先暂停。

    16.3 "暂停"而不是"放弃"

    触及失效信号时的正确动作：暂停操作 → 评估系统，而不是立即放弃换新系统。很多交易者在正常回撤期就放弃，结果刚放弃系统就恢复表现——暂停给你保留"回来看数据"的资格，放弃则把样本与经验一起扔掉。

    过程导向：执行率 > 胜率。按规则做了，即使亏了也是对的；没按规则做，即使赚了也是错的。理由：按规则亏损是系统成本（概率波动的正常结果）；不按规则赚钱是运气（不可复制，且会强化坏习惯）。 系统验证期铁律：给系统至少3-6个月的实盘验证期，期间只做小仓位、不做大调整。频繁切换 = 永远在试错期 = 永远无法积累统计样本。 要点小结
  • 判别五维度：持续时间、亏损幅度、原因、滚动期望值、应对。
  • 五红灯：连亏超历史×1.5、滚动100笔期望转负、胜率盈亏比双降、市场状态根本变化、回撤超预设上限。
  • 暂停 ≠ 放弃；暂停保留样本与回归资格。
  • 执行率>胜率；按规则亏损是成本，不按规则赚钱是运气。
  • 新系统至少3-6个月验证期，期间小仓位、不做大调整。
    • 行动判据（If-Then）
  • 如果连续亏损超过历史最大连亏×1.5 → 那么暂停操作，用2-3天评估系统逻辑是否仍成立。
  • 如果滚动100笔期望值转负 → 那么暂停系统，走"回测+归因→修改→重新验证"流程。
  • 如果处于正常回撤期想放弃 → 那么先检查执行率与滚动期望值：执行率高+期望值仍正 = 继续执行。
  • 如果系统运行不满3个月 → 那么不做大调整（数据不够，判断不准）。
    • 本章练习
  • 计算你回测或实盘数据的"历史最大连亏"，写下你的红灯阈值（×1.5后的笔数）。
  • 对照表4-16-1，复盘你经历过（或见证过）的一次放弃系统的决定：当时属于正常回撤还是真失效？证据是什么？

    第17章 系统迭代——怎么改才不会越改越差

    本章一句话：迭代第一铁律是每次只改一个变量，改完走"回测→模拟→小仓位→推广"全流程；任何系统都有半衰期，短线6-12个月、中线1-2年、长线2-5年。
    学习目标：
    1. 能解释为什么必须单变量迭代，并说出五步迭代流程；
    2. 能区分参数优化、规则优化、推翻重建三级改动；
    3. 能识别过度优化的四个特征并用样本量标准检验；
    4. 能按系统切换决策树处理失效系统。

    17.1 迭代第一铁律：每次只改一个变量

    同时改了入场条件和止损参数，效果变好——你不知道是哪个改动的贡献；效果变差——你不知道该撤回哪个。多变量迭代的结局是：系统变成一堆"感觉有用"的规则拼盘，无法归因、无法回退。一次一个变量，改完验证，再动下一个。

    迭代五步流程：改 → 回测 → 模拟 → 小仓位实盘 → 确认后推广到正常仓位。每一步都是验证：回测验证逻辑、模拟验证可执行性、小仓位验证心理。跳步 = 未经验证的修改直接进入实盘 = 危险。

    17.2 三级改动分级

    | 级别 | 内容举例 | 风险 | 频率 | |---|---|---|---| | 参数优化 | 止损5%改6%、均线20日改30日 | 低（逻辑不变） | 可较多 | | 规则优化 | 增加1个入场过滤条件、更换止损类型 | 中（逻辑部分改变） | 谨慎 | | 推翻重建 | 放弃趋势系统改用均值回归 | 高（全新系统） | 极少 |

    样本量标准：若系统有N个可调参数，验证样本至少需要 N × 50笔 交易（3个参数的系统至少150笔）。样本不够时，任何参数优化的结论都不可靠。

    17.3 过度优化的四个特征

  • 参数精度过高：止损5.73%而不是5%或6%——精确到小数点后两位的参数，几乎必然是拟合出来的；
  • 参数数量过多：5个以上可调参数；
  • 回测结果异常优秀：利润因子>3、胜率>60%、最大回撤<10% 同时出现；
  • 样本外表现大幅下降。

    • 17.4 系统的"半衰期"

    任何系统都会随市场变化而衰减：趋势系统在震荡市中衰减，价值系统在泡沫期衰减。系统不是一劳永逸的。典型半衰期（统一口径）：

  • 短线系统：6-12个月；
  • 中线系统：1-2年；
  • 长线系统：2-5年。

    • 半衰期不是"到期报废"，而是"到期必须体检"：到了半衰期窗口，用季度评估检查指标趋势，提前准备应对方案。

    17.5 系统切换决策树

  • 逻辑是否仍然有效？是 → 调参数（降低仓位/收紧条件），不换系统；
  • 市场状态是否已根本性改变？是 → 考虑切换到适配当前状态的系统；否 → 暂停等待市场回归；
  • 切换前提：新系统必须经过完整回测+模拟盘验证，不能直接实盘切换；
  • 切换节奏：旧系统逐步减仓 → 新系统逐步建仓 → 过渡期至少1-2个月。

    • 并行数量约束：一个交易者最多同时有效运行两套系统。超过两套 = 管理不过来 = 每套的执行率都下降。先做好一套，再考虑第二套（第20章展开）。

    要点小结
  • 单变量迭代；五步流程不可跳步。
  • 三级改动：参数（低风险多）、规则（谨慎）、重建（极少）。
  • 样本量 ≥ 参数个数 × 50笔。
  • 过拟合四特征：精度过高、参数过多、回测异常优秀、样本外骤降。
  • 半衰期：短线6-12个月、中线1-2年、长线2-5年；最多并行2套系统。
    • 行动判据（If-Then）
  • 如果想同时改两个参数 → 那么只改一个，另一个写进"待验证队列"。
  • 如果样本不足（<参数个数×50笔）→ 那么不做参数优化，继续积累样本。
  • 如果系统到了半衰期窗口 → 那么安排一次完整的季度评估，而不是凭感觉判断"还好"。
  • 如果想运行第三套系统 → 那么先问自己：前两套的执行率都≥85%了吗？
    • 本章练习
  • 为你当前系统列一张"可调参数清单"，标注每个参数属于"参数/规则"哪一级，并算出该系统所需的最小验证样本量（参数个数×50）。
  • 写一份"待验证队列"：把你想改但暂时不该改的想法全部写下来，注明每项的验证前提（需要多少笔数据）。

    第18章 常见系统设计误区（八大误区）

    本章一句话：八个误区覆盖了绝大多数系统死亡的原因——堆指标、没出场、盈利改规则、忽略大盘、止损太紧、不止损、频繁切换、把运气当能力，逐条对照自查。
    学习目标：
    1. 能逐条说出八大误区的表现与危害；
    2. 能对照自己的系统找出至少一个潜在误区并给出修正方案。

    18.1 误区一：堆砌指标

    均线、MACD、KDJ、RSI、布林带全加上——指标越多，条件越难同时满足，信号越少；即使满足了，也不知道哪个指标真正有效。正确做法：每类功能只选1个指标（趋势类1个，如均线；动量类1个，如RSI；量能类1个，如成交量/量比），3个指标足矣。过滤能力来自"势位形"的结构判断，而不是指标数量。

    18.2 误区二：只有买入没有卖出

    "会买的是徒弟，会卖的是师傅。"只有买入规则没有出场规则，系统只转半环，买入之后的一切都是即兴发挥。检验方法：你的系统文档里，出场部分的字数是否不少于入场部分？

    18.3 误区三：盈利后随意修改规则

    "短期赚钱就放宽条件"是最隐蔽的误区——看似更灵活，实际是拆掉系统的保护屏障。宽松条件在顺风期看不出代价，遇到亏损期会让你亏得更多。规则只能在盘后、按单变量流程修改，永远不能因为"最近赚得顺"而放宽。

    18.4 误区四：忽略大盘环境

    个股信号再好，大盘单边暴跌时胜率也会系统性下降。系统必须包含大盘环境过滤（第5章三态）——这是"天气判断"，决定你今天出不出门。没有天气判断的系统，等于只在晴天验证过的航海计划。

    18.5 误区五：止损设太紧

    止损太紧 = 被正常波动频繁震出。经常"刚止损就涨回来"，说明止损设在了太拥挤的位置（锚点价位）。正确做法：止损设在关键支撑位下方，并留 ±1个ATR 的空间，避开整数位、前低等共识价位。

    18.6 误区六：不止损死扛

    把"投资"变成"赌博"。不止损的唯一理由是"我相信它会回来"——但它可能不回来，注册制与退市常态化下，"回不来"的概率比历史上更高。止损是保险，不是惩罚：交了保费，你才能继续在市场上活着。

    18.7 误区七：频繁切换系统

    "这周学趋势，下周学波段" = 永远在试错期 = 永远没有统计样本。任何系统至少需要100笔实盘数据才能初步评估。切换前先问：我是拿到了100笔的证据证明它不行，还是只挨了5笔的痛？

    18.8 误区八：把运气当能力

    牛市赚钱不等于系统有效。检验系统的唯一标准是：扣除交易成本后的长期期望值是否为正（≥100笔样本）。行情给的利润，行情也会收回；只有系统留下的期望值才是你的。

    八大误区一句话总结：堆指标 = 信号枯竭｜没出场 = 半环系统｜盈利改规则 = 拆保护罩｜忽略大盘 = 逆天而行｜止损太紧 = 频繁被猎｜不止损 = 赌徒｜频繁切换 = 永远试错｜牛市赚钱 = 运气非能力。 要点小结
  • 每类功能1个指标，3个足矣；出场规则字数不少于入场。
  • 规则修改只能在盘后、单变量、有验证流程。
  • 大盘三态过滤是必选项，不是可选项。
  • 止损留ATR余量、避开锚点；不止损 = 赌博。
  • 100笔样本是评判系统与评判自己的最低门槛。
    • 行动判据（If-Then）
  • 如果你的系统指标超过3个 → 那么每类只留1个，其余移入观察。
  • 如果你刚经历盈利期且想放宽条件 → 那么冻结修改冲动至少2周，只看数据。
  • 如果你想换系统但样本不足100笔 → 那么继续执行并积累样本。
  • 如果牛市里你的收益率远超系统回测水平 → 那么把超出部分记为"行情红利"，不作为能力证据。
    • 本章练习
  • 按八大误区逐条自查你的系统（或你的交易习惯），对每条写"符合/不符合/不确定"，不符合与不确定的各写一句理由。
  • 统计你最近20笔交易中，有几笔的持仓标的在下单时处于大盘空头状态；若超过3笔，把"大盘过滤"写进下周重点检查项。

    第六篇 长期实战——从"有系统"到"靠系统吃饭"

    第19章 经典交易系统案例拆解

    本章一句话：拆解海龟、双均线、突破回踩三套经典系统的"逻辑骨架"，再看一个趋势系统失效的真实感案例——学逻辑，不照搬参数。
    学习目标：
    1. 能完整复述海龟交易法的入场、仓位、止损、止盈、加仓规则；
    2. 能说出双均线与突破回踩系统的完整规则链；
    3. 能解释"趋势系统在震荡市失效"的机理与五步应对；
    4. 能区分"可迁移的逻辑"与"必须本地化的参数"。

    19.1 海龟交易法：最著名的系统化交易案例

    1983年，交易员理查德·丹尼斯（Richard Dennis）与威廉·埃克哈特（William Eckhardt）打赌"交易能力能否被教授"，公开招募并培训了一批普通人（"海龟"），给他们一套完全系统化的规则。结果证明：交易可以被系统化教授。

    核心规则（原为期货市场，此处作逻辑演示）：

  • 选股/选品种：流动性好的品种；
  • 入场：20日突破——价格突破近20日最高价时做多；
  • 仓位：ATR法——波动大的少买、波动小的多买（每个"单位"承担相同波动风险）；
  • 止损：入场价 − 2 × ATR；
  • 止盈/退出：10日反向突破（跌破近10日最低价）退出；
  • 加仓：每盈利0.5 × ATR 加1个单位，最多4个单位（金字塔加仓）。

    • 历史绩效与优缺点：1983-1988年海龟团队年化收益率约80%（历史公开报道口径，示意参考），但最大回撤超过30%。优点：逻辑清晰、完全系统化、长期正期望值。缺点：胜率低（约35%-40%，示意校准），需要极大心理承受力——连续亏损7-10笔是常态；震荡市中表现差（频繁假突破）。

    A股本土化的经验（以沪深300成分股回测的普遍结论）：在2007、2015等大趋势年份表现优异，但在2016-2018震荡市中频繁假突破，年化收益仅3%-5%（示意校准，需自行回测验证）。海龟系统在A股趋势市有效，震荡市水土不服——这正是第20章多系统并行的动机。

    19.2 双均线交叉系统：最简单的趋势跟踪

  • 入场：短期均线（5日）上穿长期均线（20日）时做多（金叉）；
  • 出场：短期均线下穿长期均线时平仓（死叉）；
  • 止损：入场价 − 3% 或死叉退出（先到先执行）；
  • 仓位：固定分数法（第6章）。
    • 优点：极简、新手友好、规则零歧义。缺点：均线本身滞后，信号慢半拍；震荡市频繁假信号（金叉后很快死叉，来回打脸）。适合趋势明显的行情，常作为新手的第一套"练手系统"——它的价值不在赚钱效率，而在训练完整的闭环流程。

    19.3 突破回踩系统：中线波段经典

  • 选股：趋势向上 + 箱体整理 >15个交易日；
  • 入场：突破箱体上沿 → 缩量回踩箱体上沿 → 放量收阳时入场（对应第5章突破入场的稳健变体："不追突破，等回踩"）；
  • 止损：箱体中轨下方（加1个ATR余量）；
  • 止盈：目标1 = 突破幅度 × 1，目标2 = 突破幅度 × 1.5。

    • 这套系统是第8章瑞景食品案例的结构原型——回踩关键位 + 收盘确认 + 分批止盈，适合每天只有30分钟的上班族。

    19.4 失败案例：2019-2021的趋势系统在2022-2024失效

    一套"均线金叉 + 放量突破 + ATR止损"的趋势跟踪系统（示例校准数据）：

  • 2019-2021（核心资产牛市）：年化约25%、胜率48%、盈亏比2.8:1 → 期望值 = 48%×2.8 − 52%×1 = +0.82R，表现优异；
  • 2022-2024（长期震荡+外部冲击）：趋势信号频繁假突破，胜率降至28%、盈亏比降至1.2:1 → 期望值 = 28%×1.2 − 72%×1 = −0.38R，转负。

    • 原因：趋势系统在趋势市赚钱、在震荡市亏钱，这是系统本质决定的，不是参数问题——把20日改成15日或30日，改变不了"震荡市没有趋势可追"的事实。

    五步应对（与第16-17章流程一致）：①识别市场状态变化（趋势 → 震荡）→ ②降低仓位 → ③暂停系统 → ④评估切换到均值回归/区间类系统 → ⑤新系统完整验证（回测+模拟+小仓位）后过渡切换，过渡期1-2个月。

    19.5 从经典系统中学习的正确姿势

    学逻辑，不照搬参数。海龟的20日突破在A股可能需要改成15日或30日，参数必须匹配你的市场、你的风格、你的资金量；但"趋势突破 + ATR仓位 + 金字塔加仓"的逻辑框架是通用的。拆解任何经典系统时问三个问题：它赚的是什么钱（趋势/震荡/估值回归）？它必然在哪里亏钱？它的仓位与退出规则如何控制风险？ 要点小结
  • 海龟：20日突破入场、ATR仓位、−2ATR止损、10日反向退出、0.5ATR步进加仓；胜率35%-40%，连亏7-10笔是常态。
  • 双均线：极简但滞后，震荡市频繁打脸；适合新手练闭环。
  • 突破回踩：箱体>15天、等回踩、中轨下止损、1倍/1.5倍箱体高度分批止盈。
  • 趋势系统震荡市失效是本质使然，不是参数问题；应对五步：识别→降仓→暂停→评估切换→验证后过渡。
  • 学逻辑不抄参数；先问它"必然在哪里亏钱"。
    • 行动判据（If-Then）
  • 如果想直接照搬某经典系统的参数 → 那么先在自己的市场与标的上回测50笔以上再决定。
  • 如果你的趋势系统连续在震荡市亏损且滚动期望值转负 → 那么按五步应对处理，不要只调参数。
  • 如果你接受不了30%级别的回撤 → 那么不选择趋势跟踪类系统，改选中线波段或价值类。

    第20章 多系统并行——从单一系统到投资组合化

    本章一句话：单一系统只适应一种市场状态，多系统并行是为了分散"市场状态风险"——但一个交易者最多同时运行两套，且第一套不满300笔不考虑第二套。
    学习目标：
    1. 能说出多系统并行的三个互补维度；
    2. 能按市场状态给出系统间资金分配方案；
    3. 能解释"交易者→系统管理者"的角色转变意味着什么。

    20.1 为什么要多系统

    单一系统只适应一种市场状态：趋势系统在震荡市失效，震荡系统在趋势市跑输。多系统并行 = 分散市场状态风险——趋势系统与震荡系统同时运行，无论市场处于什么状态，总有一套在正常工作。这与资产组合分散"个股风险"是同一个思想，只不过分散的对象从股票换成了"策略"。

    20.2 组合逻辑：三个互补维度

  • 风格互补：趋势跟踪 + 均值回归 → 趋势市赚前者、震荡市赚后者；
  • 周期互补：短线（2-10天）+ 中线（2-8周）→ 不同节奏的信号互不干扰；
  • 市场状态覆盖：趋势市强势系统 + 震荡/弱市防御系统 → 全天候覆盖。

    表 4-20-1｜两系统资金分配示意

    20.4 管理复杂度与数量上限

    多系统的风险不是"系统冲突"，而是管理不过来：每套系统都需要独立的选股、入场、出场、复盘，两套系统的工作量不止两倍（还有切换判断与资金调配）。因此统一口径：最多同时运行两套系统。前提条件：

  • 第一套系统实盘满300笔、季度评估健康；
  • 两套系统的执行率都能保持≥85%；
  • 你每天可支配的交易时间翻倍后仍有余量。

    • 任何一条不满足，就先只做一套。

    20.5 从"交易者"到"系统管理者"

    运行两套以上系统时，你的角色发生变化：不再执着于每一笔交易的输赢，而是管理系统的运行状态、资金分配与定期评估——像一个管理两条产线的厂长。这是一个重要的认知跃迁：关注的对象从"这笔单"上升为"这套系统"，再上升为"这组系统"。第21章的长期盈利公式，在这个层面上展开。

    要点小结
  • 多系统分散的是"市场状态风险"，不是个股风险。
  • 三个互补维度：风格、周期、市场状态覆盖。
  • 分配随状态：趋势市70/30、震荡市30/70、不确定50/50；风控口径不因多系统放宽。
  • 最多两套；第一套不满300笔不考虑第二套。
  • 角色从交易者升级为系统管理者。
    • 行动判据（If-Then）
  • 如果第一套系统运行不满300笔 → 那么不考虑第二套。
  • 如果想同时运行超过2套系统 → 那么拒绝自己（管理不过来 = 每套执行率都下降）。
  • 如果市场状态从趋势转入震荡 → 那么按表4-20-1把配额向震荡系统倾斜，而不是关掉趋势系统。
  • 如果两套系统的执行率都跌破85% → 那么暂停弱势的一套，先保执行质量。
    • 本章练习

  • 估算运行两套系统的每日时间开销（选股/盯盘/复盘各多少分钟），对照你的可用时间判断是否现实。

    第21章 长期盈利的终极秘密

    本章一句话：长期盈利 = 正期望值系统 + 严格执行 + 足够时间，三者缺一不可；从100笔到10000笔的四个里程碑，是每个系统化交易者必经的路。
    学习目标：
    1. 能解释长期盈利公式三要素各自的不可替代理由；
    2. 能说出"系统代替意志力"的两个硬件手段；
    3. 能复述八轮学习路径与四个里程碑的含义。

    21.1 长期盈利公式

    长期盈利 = 正期望值系统 + 严格执行 + 足够时间

    三者缺一不可：

  • 正期望值系统：扣除交易成本后，胜率×平均盈利 − 败率×平均亏损 > 0。没有它，执行得再好也是确定亏损——只是亏得更整齐；
  • 严格执行：执行率≥85%（底线80%）。正期望值系统 + 0%执行率 = 确定亏损；
  • 足够时间：概率需要大样本才能显现——100笔初步判断，300笔可靠结论。短期亏损不代表系统无效，短期盈利也不代表系统有效。

    • 21.2 为什么大多数人知道却做不到

    知道"该止损"和"真的止损"之间，隔着一个杏仁核——约0.3秒的恐惧反应就能让你放弃规则。这就是为什么必须用系统代替意志力：

  • 条件单自动止损（把止损交给硬件，不给犹豫留时间）；
  • 连亏阶梯自动暂停（3笔减半、5笔停1-3天，规则先行于情绪）；
  • 盘后修改规则纪律（盘中永远不改规则）。

    • 把规则写进"硬件"，不依赖"软件"（意志力）——意志力是会耗尽的资源，规则不会。

    21.3 生存优先于盈利

    "第一条规则：不要亏钱；第二条规则：记住第一条。"系统化交易的终极价值不是让你赚多少，而是让你在市场上活着——活着才有机会等到属于你的概率兑现。死扛不止损的人可能在牛市赚很多，但一次大熊市就可能清零；系统保证你的任何单笔、单日、单周、单月亏损都被限制在预设范围内（分层风控详见《风险管理与交易心理》第三篇）。

    21.4 向市场学习的具体方法

    市场是活的，系统也要是活的。方法是固定的四步循环：观察 → 记录 → 验证 → 纳入或排除。

  • 例1："最近总有资金尾盘拉升" → 观察记录10次 → 验证出现频率与次日表现是否可量化 → 若稳定有效，纳入入场/出场条件；否则排除；
  • 例2："某板块龙头总是先于板块启动" → 观察 → 验证 → 若成立，纳入选股规则（观察池排序）。

    • 迭代必须有纪律：每次只改一个变量，改后走完整验证流程（第17章）。

    B.3 R倍数记录法说明

    R = 入场价 − 止损价（做多）。例：入场30元、止损28元、500股：R = 2元，初始风险 = 1000元。

  • 34元出场：盈利2000元 ÷ 1000元 = +2R（好交易）；
  • 28元出场：亏损1000元 ÷ 1000元 = −1R（正常止损，执行合格）；
  • 26元才出场：亏损2000元 ÷ 1000元 = −2R（止损未执行，必须复盘）。

    • R倍数让不同标的、不同仓位的盈亏可以在同一标尺下比较与汇总。

    G.2 Python绩效统计脚本（示例）

    输入交易日志CSV（列名：date, pnl, r_multiple, executed），输出核心统计。示例代码，可按日志格式自行调整：

    import csv

    rows = list(csv.DictReader(open("trading_log.csv", encoding="utf-8")))
pnl = [float(r["pnl"]) for r in rows]
rs = [float(r["r_multiple"]) for r in rows]
execs = [r["executed"] == "1" for r in rows]
    

    wins = [x for x in rs if x > 0]
losses = [x for x in rs if x < 0]
    

    win_rate = len(wins) / len(rs)
profit_factor = sum(wins) / abs(sum(losses)) if losses else float("inf")
expectancy_r = sum(rs) / len(rs)
    

    最大连续亏损
    
max_streak = streak = 0
for x in rs:
    streak = streak + 1 if x < 0 else 0
    max_streak = max(max_streak, streak)

    print(f"笔数: {len(rs)}")
print(f"胜率: {win_rate:.1%}")
print(f"盈亏比: {sum(wins)/len(wins) / (abs(sum(losses))/len(losses)):.2f}" if losses else "无亏损样本")
print(f"利润因子: {profit_factor:.2f}")
print(f"期望值: {expectancy_r:+.3f}R")
print(f"最大连续亏损: {max_streak}笔")
print(f"执行率: {sum(execs)/len(execs):.1%}")
