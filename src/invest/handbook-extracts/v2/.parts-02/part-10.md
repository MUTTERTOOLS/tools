## 第六篇 从财报到投资决策

### 第20章 预期差——财报真正的投资价值

> **本章一句话**：股价反应的不是财报好坏，而是财报与市场预期的差——预期差的方向×幅度才是投资价值。
> **学习目标**：
> 1. 能写出预期差公式并解释三种情形（超预期/符合预期/不及预期）的股价反应；
> 2. 能说出预期差的三个来源；
> 3. 能批判性阅读卖方研报，只取数据不取结论。

#### 20.1 什么是预期差

**预期差＝实际数据－市场预期**。股价已经把"市场以为的"提前消化（price in），财报发布时，只有"与预期不同的部分"才会驱动股价：

- 数据好，但市场预期更好 → **不及预期 → 股价跌**；
- 数据差，但市场预期更差 → **超预期 → 股价涨**；
- 数据与预期一致 → **符合预期 → 股价反应平淡，看管理层指引**。

这就是"好消息出尽是利空"的机制：好消息在预期形成阶段已经涨完了。

#### 20.2 预期差的三个来源

1. **方向**：增长还是下滑——市场以为会继续增长，实际下滑，方向性预期差最大；
2. **幅度**：多好或多差——同样超预期，超10%与超50%的股价反应不同；
3. **节奏**：什么时候发生——拐点提前或推迟一个季度，也会形成预期差。

#### 20.3 市场预期在哪看

- **券商一致预期**：财经数据终端（Wind、同花顺iFinD、东方财富Choice等）汇总的营收/净利润预测均值；
- **卖方研报盈利预测**：单家券商的预测，注意其立场。

**必须知道的偏差**：卖方预测系统性偏乐观——"买入"评级占比通常超过80%，盈利预测普遍偏乐观（经验校准：约10%-20%，需自行验证），"卖出"评级极其罕见。所以一致预期本身要打折扣使用。

#### 20.4 批判性阅读卖方研报

券商同时经营投行与研究业务，存在天然利益关联。正确用法：

- **看数据不看结论**：研报中的行业数据、公司经营数据、同业对比是客观信息，最值钱；
- **看逻辑不看目标价**：论证链条可以检验，目标价是主观产物；
- **重点看风险提示**：这是研报里最诚实的部分。

#### 20.5 指引重于当季

**财报指引（Guidance）＝管理层对下一期/全年的业绩展望**。股价反映的是未来6-12个月的预期，所以：本季度超预期但指引下季度下滑 → 股价可能跌；本季度平淡但指引大幅上调 → 股价可能涨。**读财报的最后一问永远是：管理层对下阶段怎么说？**

**例2-20-1｜预期差判断（示例数据）**：某公司Q3实际净利润8亿元。情形甲：一致预期10亿元 → 预期差-2亿元（不及预期，即使同比去年6亿元增长33%，仍可能下跌）；情形乙：一致预期7亿元 → 预期差+1亿元（超预期）；情形丙：一致预期8亿元 → 符合预期，看业绩说明会指引。结论：**不看"比去年好"，要看"比市场以为的如何"。**

**要点小结**
- 股价反应＝财报数据－市场预期；好消息出尽是利空。
- 预期差三来源：方向、幅度、节奏。
- 一致预期偏乐观，批判性使用；研报看数据、逻辑与风险提示。
- 指引重于当季数据。

**行动判据（If-Then）**
- 如果财报发布前 → 那么先查一致预期（营收/净利润），发布后只按预期差判断反应方向。
- 如果阅读卖方研报 → 那么只提取数据与逻辑，自己形成结论，不看目标价。
- 如果公司本季度超预期但指引下调 → 那么按利空对待，不追涨。

**本章练习**
1. 选一家即将发布财报的公司，记录发布前的一致预期，发布后对比实际数据，写下预期差判断。
2. 找一份该公司研报，分别摘录"数据部分"与"结论部分"，体会两者的信息价值差异。

### 第21章 财报阅读实战——从打开年报到形成判断

> **本章一句话**：年报200页不必通读——按"摘要→三表→管理层讨论→附注"的顺序48分钟读完，再用五步法形成判断。
> **学习目标**：
> 1. 能按阅读顺序在1小时内完成年报速读；
> 2. 能在附注中定位五类关键信息；
> 3. 能执行五步判断流程并输出一页纸报告。

#### 21.1 阅读顺序（约48分钟速读）

年报动辄200页，从头读到尾是效率陷阱。推荐顺序：

1. **摘要与重要提示（3分钟）**：核心数字、审计意见类型（非标直接出局）；
2. **三张报表（10分钟）**：一分钟速读三数字＋勾稽验证（第2章、第6章）；
3. **管理层讨论与分析（15分钟）**：管理层如何解释经营成果，与数字是否一致；
4. **附注（20分钟）**：关键附注项——收入确认政策、折旧政策、关联交易、或有事项。

深读（排雷、估值）在此基础上按需展开，但速读48分钟足以决定"值不值得深读"。

#### 21.2 附注是"宝藏"

大多数人跳过附注，但最有价值的信息在这里：

- **收入确认政策**：总额法还是净额法（收入规模差10倍）；确认时点是否激进；
- **应收账款账龄**：1年内占比多少，1年以上坏账计提是否充分；
- **关联交易明细**：关联方是谁、交易什么、定价是否公允；
- **或有事项**：未决诉讼、对外担保承诺；
- **会计政策变更**：今年改了什么规则、对利润影响多大。

#### 21.3 五步形成判断

1. **看趋势**：核心指标（营收、扣非利润、经营现金流、毛利率、ROE）3-5年走向——改善还是恶化？
2. **比同业**：与2-3家可比公司对比——是行业问题还是公司问题？
3. **查勾稽**：三条勾稽线验证（第6章）——对不对得上？
4. **排雷**：十项清单（第18章）——有没有红旗？
5. **定预期差**：一致预期是什么？我的判断是什么？预期差的方向与幅度？

#### 21.4 一页纸报告模板

每次分析固定输出同一张表，形成肌肉记忆：

```
公司名称 / 报告期 / 分析日期
一、趋势：营收____ 扣非____ 现金流____ 毛利率____ ROE____
二、同业对比：本公司__ vs 可比A__ vs 可比B__（关键指标）
三、勾稽验证：利润去向✓/✗  现金落点✓/✗  差额构成✓/✗
四、排雷结论：通过 / 存疑（____项）/ 排除（触发____）
五、预期差：一致预期____ 我的判断____ 方向____ 幅度____
六、一句话结论与跟踪指标：
```

#### 21.5 财报阅读10条军规

1. 先看审计意见，非标直接排除；
2. 先看现金流，再看利润——现金比利润可靠；
3. 趋势比绝对值重要，3年比1年重要；
4. 毛利率是竞争力的最直接证据；
5. 杜邦分析拆ROE——知道"怎么赚的"比"赚了多少"重要；
6. 应收＋存货＝造假温床，永远重点关注；
7. 跨行业不比绝对值，先建行业基准；
8. 排雷清单强制执行，不完成不买入；
9. 预期差>绝对好坏——不是"好不好"而是"比预期如何"；
10. 从数字读生意——终极目标不是会算指标，是理解公司靠什么赚钱。

**例2-21-1｜一页纸报告示例（虚构公司，示例数据）**：
```
清源家电（虚构）/ 年报 / 分析日期示例
一、趋势：营收+12%/+14%/+15%；扣非+15%/+16%/+18%；经营现金流增速同步；毛利率31%→32.5%→33%；ROE 16%→17%→18%
二、同业对比：毛利率33% vs 可比A 30%、可比B 29%（偏高但<+15pp，有品牌溢价解释）
三、勾稽验证：✓ ✓ ✓
四、排雷结论：通过（十项全过）
五、预期差：一致预期扣非+12%，我的判断+18%（新品放量）→ 正向预期差约6pp
六、结论：基本面通过，等待价格位置与入场信号；跟踪指标：季度同店/渠道库存、毛利率
```

**要点小结**
- 阅读顺序：摘要→三表→管理层讨论→附注，48分钟速读。
- 附注五类关键信息：收入确认、应收账龄、关联交易、或有事项、政策变更。
- 五步判断：看趋势→比同业→查勾稽→排雷→定预期差。
- 一页纸报告固定输出，10条军规无条件执行。

**行动判据（If-Then）**
- 如果分析一家公司 → 那么按五步流程执行并写出一页纸报告，不写完不买入。
- 如果附注关键信息（收入确认/关联交易/或有事项）无法获取 → 那么标记"信息不充分"，仓位限制在标准仓的1/3。
- 如果审计意见为非标 → 那么不再继续后续步骤，直接排除。

**本章练习**
1. 选一家公司年报，按本章顺序计时速读，记录每步实际用时。
2. 用一页纸模板完成该公司的完整分析输出。
