# MUTTER TOOLS

一个直接部署到 GitHub Pages 的纯静态站点。页面按主题归档，不需要安装依赖或执行构建。

## 目录结构

```text
.
├── index.html       # 根入口，仅负责主题导航
├── src/
│   ├── tools/       # 文件与图像工具主题及其入口
│   └── invest/      # 投资阅读主题及其入口
├── cdn/             # 随站点托管的第三方静态依赖
├── .nojekyll        # 跳过 Jekyll，按原样发布静态文件
└── LICENSE
```

每个主题目录都有自己的 `index.html`，用于组织该主题下的页面。新增主题时，在 `src/<topic>/` 中创建主题入口，并在根 `index.html` 增加导航项。

`src/` 根目录保留少量旧 URL 的兼容跳转页；实际内容只放在对应主题目录中。已有链接因此仍可访问，同时新页面应直接使用主题路径。

## 本地预览

在仓库根目录启动任意静态文件服务器，例如：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。不要直接双击 HTML 文件预览；部分浏览器能力在 `file://` 协议下会受到限制。

## 发布

GitHub Pages 的发布源应设置为 `main` 分支的仓库根目录（`/`）。推送后无需额外构建步骤。
